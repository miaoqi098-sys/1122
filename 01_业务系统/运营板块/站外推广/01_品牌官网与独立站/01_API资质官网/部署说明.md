# API资质官网部署说明

## 推荐上线方式

优先级建议：

1. 自有域名 + Cloudflare Pages；
2. 自有域名 + GitHub Pages；
3. 自有域名 + Vercel；
4. 临时使用平台二级域名仅用于内部测试，不建议直接拿去做正式 Amazon API 资质审核。

## 正式审核前门禁

- 网站必须可通过 `https://` 访问；
- 公司法定名称与 Amazon Ads API / SP-API 申请主体一致；
- 首页、公司介绍、隐私政策、数据使用说明、联系方式均可直接访问；
- 公开联系邮箱应为公司长期可用邮箱；
- 不出现 `[公司法定名称]` 等占位符；
- 不公开 Client Secret、Refresh Token、Access Token、密码等敏感凭证；
- 页面描述必须与实际数据使用方式一致；
- 若未来使用第三方云服务或 AI 服务处理 Amazon 原始数据，应按真实数据流更新隐私政策和数据使用说明。

## 当前源代码目录

`site/`

这是纯静态 HTML/CSS 网站，无数据库、无登录、无表单收集敏感信息，适合作为 API 资质审核第一版官网。

## 后续运营扩展

通过 API 审核后可在同一官网继续增加：

- SEO 与关键词内容；
- 产品与品牌页面；
- 博客/知识内容中心；
- 广告落地页；
- 邮件订阅；
- 独立站商城；
- 流量与转化分析；
- 站外推广数据接入。
