# API资质官网部署说明

## 当前正式目标

- 正式域名：`https://sorilo-uk.com`
- 推荐托管：Cloudflare Pages
- 源代码分支：`website/api-qualification-v1`
- 网站源目录：`01_业务系统/运营板块/站外推广/01_品牌官网与独立站/01_API资质官网/site`

## Cloudflare Pages 推荐配置

若通过 GitHub 连接 Cloudflare Pages：

- 仓库：`miaoqi098-sys/-`
- 生产分支：`website/api-qualification-v1`
- 根目录：`01_业务系统/运营板块/站外推广/01_品牌官网与独立站/01_API资质官网/site`
- 构建命令：留空
- 构建输出目录：`.`
- Framework preset：None / 无框架

项目创建成功后，先取得 Cloudflare Pages 提供的 `*.pages.dev` 临时地址并确认页面可访问，再在 Custom domains / 自定义域名中绑定：

1. `sorilo-uk.com`
2. `www.sorilo-uk.com`（可选，建议最终 301 跳转到根域名）

Cloudflare Pages 会为已验证的自定义域名自动签发并续期 HTTPS 证书。

## DNS 目标状态

正式上线后应满足：

- `sorilo-uk.com` 可解析；
- `https://sorilo-uk.com` 返回网站首页；
- HTTP 自动跳转到 HTTPS；
- SSL/TLS 证书有效；
- `www.sorilo-uk.com` 如启用，应统一跳转到主域名；
- 不使用临时 IP 作为长期网站入口。

## 已加入的站点安全配置

`site/_headers` 已配置基础安全响应头，包括：

- HSTS；
- 禁止 MIME 嗅探；
- 禁止页面被第三方 iframe 嵌入；
- Referrer Policy；
- Permissions Policy；
- 静态站点 Content Security Policy。

同时已加入：

- `robots.txt`
- `sitemap.xml`

两者均以 `https://sorilo-uk.com` 作为正式域名。

## 正式审核前门禁

- 网站必须可通过 `https://` 访问；
- 公司法定名称与 Amazon Ads API / SP-API 申请主体一致；
- 首页、公司介绍、隐私政策、数据使用说明、联系方式均可直接访问；
- 公开联系邮箱应为公司长期可用邮箱；
- 不出现 `[公司法定名称]` 等占位符；
- 不公开 Client Secret、Refresh Token、Access Token、密码等敏感凭证；
- 页面描述必须与实际数据使用方式一致；
- 若未来使用第三方云服务或 AI 服务处理 Amazon 原始数据，应按真实数据流更新隐私政策和数据使用说明。

## 当前上线阻塞

当前页面仍存在 `[公司法定名称]` 等上线占位符，因此即使 Cloudflare Pages 已能部署，也暂不应将其提交给 Amazon 作为正式资质官网。

在正式上线前还需要确认并替换：

1. 公司法定中文全称；
2. 如使用，公司的正式英文名称；
3. 公开联系邮箱；
4. 对外展示的公司地址或地区信息；
5. 网站页脚中的公司主体信息。
