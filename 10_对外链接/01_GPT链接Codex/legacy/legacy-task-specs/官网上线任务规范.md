# 官网上线 Codex 任务规范

## 目标

只处理让 `https://sorilo-uk.com` 能在公网正常打开所需的部署、DNS 与 HTTPS 工作。

## Codex 允许执行

1. 检查本地仓库中的现有官网部署源。
2. 检查本机已经配置好的 Cloudflare CLI / API 认证是否可用，但不得输出凭证明文。
3. 检查或创建用于该官网的 Cloudflare Pages 项目。
4. 部署现有官网文件。
5. 绑定自定义域名 `sorilo-uk.com`。
6. 配置该站点上线所必需的 DNS 记录。
7. 验证 HTTPS/TLS 是否生效。
8. 验证公网首页是否可访问并记录 HTTP 状态。

## Codex 禁止执行

- 不重写官网业务文案；
- 不修改无关 DNS / 邮件记录；
- 不转移或删除域名；
- 不关闭安全控制；
- 不输出 Token、Secret、密码或刷新令牌明文；
- 不修改 Amazon 账户配置；
- 不修改其他项目。

## 返回给 GPT 的结果

执行完成后仅返回：

- Pages 项目名称；
- 部署结果；
- 与官网有关的 DNS 类型、主机名、目标值；
- 自定义域名状态；
- HTTPS/TLS 状态；
- `https://sorilo-uk.com` 最终 HTTP 状态；
- 如果未完成，准确说明仍然阻塞在哪一步以及需要什么人工动作。

## 成功标准

`https://sorilo-uk.com` 可以从公网通过 HTTPS 正常打开。
