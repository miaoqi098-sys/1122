# 价格与促销指标口径

## 核心指标
- `discount_depth`：相对明确参考基准的折扣深度；
- `effective_price`：特定资格/活动条件下的有效价格；
- `realized_order_price`：订单层实际成交价格；
- `reference_price_gap`：当前报价与参考价/历史展示价的差距；
- `promotion_uplift`：活动期间订单/销量/转化相对基线变化；
- `promotion_cost`：卖家承担的促销让利/费用；
- `eligibility_status`：活动资格状态；
- `stacking_risk`：多个促销可能叠加的风险；
- `price_stability`：价格在观察窗口内的变化频率和幅度。

## 口径规则
1. 折扣深度必须明确分母基准，禁止只写“30% off”而不说明相对什么价格；
2. 理论有效价与实际订单成交价分开；
3. 前台参考价/划线价是展示事实，不与后台字段机械等同；
4. 活动提升需比较可比基线，排除季节、广告、库存和内容变化；
5. 促销成本最终利润影响由Agent-6核算；
6. eligibility必须绑定规则版本与检查时间。

## 参考基准
可用基准包括：当前常规报价、历史常规价格、平台认可的参考价展示事实、活动前稳定价格等。具体采用哪个基准必须记录 `baseline_type` 与 `baseline_ref`。

## 数据不足
参考基准不可靠、订单成交价不可得或规则版本不明时，不得输出确定性“折扣合规/资格通过”结论。
