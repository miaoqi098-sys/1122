# 历史基线与观察窗口

## 目的
价格和促销判断必须保留历史上下文，避免高频改价、活动叠加和参考价变化导致错误结论。

## 基线类型
- 当前常规价格基线；
- 活动前稳定价格基线；
- 订单实际成交价基线；
- 前台参考价/划线展示历史；
- 促销前/中/后转化与销量基线；
- 同比/季节性价格与促销窗口；
- 竞品/市场价格带基线。

## 观察窗口
平台规则可能涉及不同历史窗口，系统允许维护30/60/90日等多个窗口，但任何窗口只有在关联具体 `rule_version_ref` 后才具有规则意义。

## 促销后观察
促销结束后至少观察：
- 价格展示是否恢复；
- 参考价/划线是否变化；
- 转化/销量是否回落；
- 广告效率是否变化；
- 库存是否形成新约束；
- 退款/VOC是否异常；
- 后续活动资格是否受影响。

## 历史失效
平台规则、价格口径、marketplace或促销类型发生变化时，旧经验不能机械套用。

## 原则
历史用于判断风险和可比性，不自动得出“长期维持某个价格一定能获得某种展示”的确定性结论。
