# 历史基线与观察窗口

## 目的
评价与体验变化必须结合评论量、销量背景、退货成熟窗口和历史主题结构，避免对短期波动作出过度结论。

## 基线类型
- 评分与星级分布：7/14/30/90日及长期基线；
- 评论速度：按订单/销量背景标准化；
- VOC主题：主题占比、主题速度、首次出现时间；
- 退货/退款：按成熟窗口观察；
- 变体基线：不同子体分开；
- 内容/产品变更前后基线：用于判断预期差异是否改善。

## 观察窗口
新品少量评论阶段应使用更长观察与更低置信度；大促后评论/退货可能滞后，不能只看活动当天。

## 主题生命周期
`new → emerging → persistent → worsening/improving → resolved/dormant`

## 基线失效
- 产品结构/材料/配件版本变化；
- 变体合并/拆分；
- Listing内容大改；
- 物流/包装方式改变；
- 评分/评论展示机制变化；
- 数据源采集口径变化。

## 历史复用边界
过去某主题曾出现并不等于当前同一原因；必须比较产品版本、变体、内容和履约条件。
