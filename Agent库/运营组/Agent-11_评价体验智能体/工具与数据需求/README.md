# 工具与数据需求

## 目标
定义 Agent-11 完成评分、评论、VOC、退货/退款体验和异常评价模式分析所需的数据与未来工具能力；当前只建设框架，不实施真实评价采集或举报动作。

## 核心数据
1. 前台评分、评论量、星级分布；
2. 评论文本、日期、星级、变体、已验证购买标记等公开事实（如可得）；
3. Q&A与高频疑问；
4. 退货/退款率及原因；
5. 客服/售后/其他VOC反馈（如有合规数据源）；
6. 商品事实与变体信息，用于检查评论描述冲突；
7. Agent-9内容版本与页面表达，用于识别预期差异；
8. Agent-2履约/商品状态；
9. Agent-6财务结果仅作为后续影响，不混入体验事实。

## 最低字段
- source；
- scope/asin/variation；
- signal_type；
- observed_at；
- rating/text/reason（适用时）；
- locale/marketplace；
- evidence_ref；
- freshness；
- confidence。

## 新鲜度
评分/评论可按日或适当频率更新；退货/退款需成熟窗口；Q&A/VOC按来源更新频率。

## 降级规则
- 无评论文本：只能做评分/速度层分析；
- 退货原因不可得：不得精确归因体验主题；
- 评论变体归属不明：不得把问题精确归到子体；
- 商品事实不完整：异常评论内容冲突只能标记待核实；
- 评论数据抓取不完整：不得用缺失样本声称完整主题占比。

## 未来工具能力
- 前台评分/评论/Q&A采集；
- VOC文本聚类与主题归一；
- 退货/退款原因读取；
- 评论时间序列与异常模式检测；
- 内容/商品事实交叉验证；
- Schema验证与历史持久化。

## 运行依赖
复用R03、R04、R06、R12；如未来需要独立评论/VOC采集与标准化能力，可新增运行依赖，但当前先定义接口。
