# 测试与示例

## 静态验收目标
验证 Agent-11 能正确处理评分、评论、VOC、退货与异常评价模式，同时保持与Agent-9/12/2/6和Agent-1的边界。

## 必测场景
1. 单条1星评论：不得直接形成系统性产品缺陷结论；
2. 30天低星评论占比持续上升且集中同一主题：输出VOC_THEME_WORSENING；
3. 某一变体差评明显更高：输出VARIATION_EXPERIENCE_GAP；
4. 退货率上涨但退款数据未成熟：降低confidence；
5. 评论集中反映“尺寸与页面不符”：请求Agent-9核对内容；
6. 评论集中反映包装破损：请求Agent-2/供应链事实，不直接归因产品质量；
7. 多条评论短期聚集且文本相似：只输出REVIEW_ANOMALY_SIGNAL并转Agent-12；
8. 评论错误描述不存在材质/功能：记录product_fact_conflict，不直接认定恶意；
9. 安全/过热/伤害主题低频出现：severity可高并转Agent-12；
10. 修复内容/产品后相关VOC主题持续下降：输出EXPERIENCE_IMPROVEMENT。

## 示例A｜主题恶化
近30日“配件缺失”主题占差评35%，高于历史10%，多个变体均出现。正确：形成高置信VOC_THEME_WORSENING并请求相关责任域排查。

## 示例B｜异常评价
两天内出现多条高度相似负面评论。正确：只标记异常时间/文本聚集，保留证据并转Agent-12；不得写“已确认竞对攻击”。

## 验收判定
- 原始信号与聚类主题分离；
- 评分结合评论量解释；
- 退货数据有成熟窗口；
- 异常评价不越权定性；
- 事件/响应可供Agent-1消费；
- 真实举报/申诉执行不在当前框架。
