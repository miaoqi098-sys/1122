# 机会指标与评分口径

## 核心维度
- `impact`：潜在业务影响；
- `confidence`：证据支持程度；
- `feasibility`：当前资源/能力下可行性；
- `urgency`：机会窗口时效；
- `effort`：验证与实施成本；
- `risk`：风险与不确定性；
- `dependency_load`：跨Agent/工具/审批依赖；
- `reversibility`：失败后能否低成本撤回；
- `learning_value`：即使失败是否能获得重要信息。

## 评分原则
允许形成综合机会分，但必须保留所有子维度，不得用一个黑箱总分替代证据。总分只用于Agent-13内部比较，不等于Agent-1最终优先级。

## 影响口径
impact应说明影响对象：流量、订单、收入、贡献利润、库存效率、体验恢复或风险降低。不同单位不得直接相加，应先标准化或保持多维输出。

## 置信度
建议按证据层级：
- 单一弱信号：低；
- 多源同向/历史可比：中；
- 专业Agent多证据支持：中高；
- 实验/清晰自然实验支持：高。

## 时效性
季节、竞品窗口、库存窗口、活动窗口等机会必须记录 `window_open_at / window_close_at` 或相对时效；无明确窗口则标记长期型。

## effort与feasibility
必须把需要的广告预算、内容制作、库存、价格权限、审批、数据/工具依赖等明确列出。

## 边界
Agent-13评分不能突破Agent-12的prohibited资格，也不能把利润/库存硬约束“用高impact抵消”。最终经营优先级进入Agent-1目标系统和S04。
