# Agent-1｜运营总控智能体

所属：运营组  
版本：V1.0 工程骨架  
角色：运营组唯一总控决策中枢。

## 核心职责
汇总 Agent-2 至 Agent-13 的智能事件，结合产品历史、活动状态、库存、利润、风险、流量与市场上下文进行交叉判断，解决策略冲突，形成运营决策，下发任务并跟踪执行结果，负责复盘与迭代。

## 核心运行链路
智能事件包 → 事件校验 → 上下文装载 → 冲突检测 → 决策排序 → 候选方案 → 风险分级 → 决策指令 → 任务调度 → 结果验证 → 复盘写回。

## 当前目录
- 身份与权限：定义 Agent-1 是谁、能做什么、哪些动作必须审批。
- 输入规范：规定 Agent-2 至 Agent-13 如何向 Agent-1 上报标准智能事件包。
- 输出规范：规定 Agent-1 如何输出标准决策指令和任务。
- 决策规则：规定决策顺序、冲突处理和禁止项。
- 事件处理：定义 P0-P3 事件优先级。
- 任务调度：定义任务从创建到验证、回滚的生命周期。
- 历史记忆：规定产品历史、策略和结果如何被长期保存和调用。
- Skill：列出 Agent-1 V1.0 的 10 个核心能力模块。
- 工作流：定义总控主流程和关键分支。
- 配置：保存 Agent-1 的机器可读基础配置。
- 日志规范：保证每个决策可追溯、可复盘。
- 测试：定义进入下一阶段前必须通过的验收场景。
- 示例：提供标准智能事件包示例。

## V1.0 核心原则
1. 不允许仅凭单一 Agent 的结论直接做重大决策。
2. 决策前必须读取产品历史和当前活动上下文。
3. 风险合规优先于增长，库存与利润约束优先于单纯放量。
4. 每个决策必须包含观察窗口、成功标准与回滚条件。
5. 执行完成不等于策略成功，必须经过结果验证。
6. 重大或不可逆动作必须进入人工审批。
7. 所有决策、任务、结果和复盘必须可追溯。

S01 事件校验 → S02 上下文装载 → S03 冲突检测 → S04 决策排序 → S06 风险分级 → S07 任务拆解 → S08 结果验证 → S09 复盘写回 → S10 策略防抖。
