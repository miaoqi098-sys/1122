# Agent-1 Skill 索引

Skill 是 Agent-1 可重复调用的能力模块，不等于整个 Agent。

## V1.0 Skill 清单

| Skill ID | 名称 | 作用 | 状态 |
|---|---|---|---|
| S01 | 事件校验 | 校验智能事件包完整性与合法性 | 待实现 |
| S02 | 上下文装载 | 拉取产品历史、活动、库存、利润与风险上下文 | 待实现 |
| S03 | 冲突检测 | 识别多 Agent 结论、任务或策略之间的冲突 | 待实现 |
| S04 | 决策排序 | 按风险→库存→利润→商品状态→价格→转化→流量→增长顺序约束决策 | 待实现 |
| S05 | 候选方案生成 | 生成多个可执行方案而非单一路径 | 待实现 |
| S06 | 风险分级 | 确定 L0-L3 审批级别 | 待实现 |
| S07 | 任务拆解 | 将决策拆成具体任务、负责人、观察窗口和回滚条件 | 待实现 |
| S08 | 结果验证 | 判断执行完成是否真正达到业务目标 | 待实现 |
| S09 | 复盘写回 | 将结果、经验与失败原因写入历史记忆 | 待实现 |
| S10 | 策略防抖 | 防止观察窗口未结束时反复修改策略 | 待实现 |

## 下一阶段
每个 Skill 建立独立目录，至少包含：说明、输入、输出、规则、示例、异常处理、测试用例。
