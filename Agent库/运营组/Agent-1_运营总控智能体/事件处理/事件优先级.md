# Agent-1 事件优先级

## P0｜紧急
影响账户安全、商品可售、重大合规、严重价格错误、库存完全中断等，需要立即进入总控判断。

处理要求：
- 暂停与风险冲突的普通任务。
- 立即拉取相关 Agent 的补充信息。
- 默认进入 L2/L3 审批。

## P1｜高优先级
明显影响销售、利润、库存或核心广告表现，若延迟处理会产生实质损失。

处理要求：
- 当日进入决策队列。
- 检查是否与现有促销、库存、预算计划冲突。

## P2｜常规
需要优化，但短期内不会造成严重损失，例如广告结构调整、内容转化测试、竞品变化。

处理要求：
- 进入正常计划队列。
- 必须定义测试周期和复盘时间。

## P3｜观察
趋势、机会、弱信号、尚未达到行动阈值的变化。

处理要求：
- 记录并持续观察。
- 达到阈值后升级为 P2/P1。

## 升降级
任何 Agent 都可以建议升级；只有 Agent-1 或风险合规规则可以确认优先级变化。事件处理后必须记录最终级别与原因。
