# Agent-1 任务生命周期

## 状态
待创建 → 待审批 → 待执行 → 执行中 → 待验证 → 已完成 / 已回滚 / 已取消

## 每个任务必须包含
- task_id
- 来源 decision_id
- 产品/ASIN
- 负责人
- 具体动作
- 优先级
- 审批级别
- 截止时间或观察窗口
- 成功标准
- 止损/回滚条件
- 验证责任人

## 调度规则
1. P0 优先于所有普通任务。
2. 同一产品存在互斥任务时，Agent-1 必须冻结低优先级任务并记录冲突原因。
3. BD、LD、Coupon、站外活动期间，涉及价格、广告、转化判断的任务必须标记活动上下文。
4. 未到观察窗口，不因短期波动重复下发相反任务。
5. 任务结束后必须进入验证，不允许“执行完成=结果成功”。
6. 验证失败时，根据回滚条件自动生成回滚建议或新的诊断任务。
