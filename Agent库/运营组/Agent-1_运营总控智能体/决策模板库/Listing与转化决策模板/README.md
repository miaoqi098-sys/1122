# Listing与转化决策模板

## 定位
本目录承载 Agent-1 对 Listing 内容、页面表达、转化下降与内容优化相关经营问题的标准决策结构。

Agent-9 负责标题、五点、图片、A+、视频、关键词布局与页面转化分析；Agent-1 结合广告流量质量、价格、评价、库存、竞争环境与当前目标决定是否以及如何实施内容优化。

## 典型问题
- 流量稳定但转化下降；
- 新品页面是否需要重构；
- 图片/A+/标题/五点/视频是否需要调整；
- 页面内容与目标关键词/消费者需求错配；
- 广告高点击低转化是否由Listing承接不足造成；
- 内容优化与品牌、合规、变体结构发生冲突。

## 原则
- 转化问题先区分流量质量、价格、评价、内容、库存和活动因素，不能把CVR变化全部归因于Listing；
- 内容变更必须有明确假设、主变量和观察窗口；
- 大规模同时改标题、图片、A+会削弱因果判断，优先分阶段测试；
- 合规边界优先于文案表现；
- Agent-9建议不直接成为最终执行指令。
