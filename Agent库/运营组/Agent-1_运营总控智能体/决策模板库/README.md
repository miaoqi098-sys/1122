# 决策模板库

本目录定义不同经营问题的标准分析与决策结构，减少 Agent-1 每次从零组织判断。

## 规划模板
- 广告问题决策模板.md
- 库存问题决策模板.md
- 价格问题决策模板.md
- Listing与转化问题模板.md
- 促销活动决策模板.md
- 风险事件决策模板.md
- 新品增长决策模板.md
- 多问题联合决策模板.md

## 每个模板至少包含
当前目标、关键事实、经营状态、相关指标、主要假设、缺失信息、相关Agent、候选方案、方案比较、推荐方案、风险与审批、任务、观察窗口、成功标准、止损与回滚条件。

## 原则
模板是分析结构，不是固定答案；Agent-1 必须根据当前产品、阶段和约束动态判断。
