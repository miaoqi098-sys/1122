# 多Agent冲突决策模板

## 定位
本目录承载 Agent-1 在多个专业Agent建议互斥、证据冲突、目标冲突或时间窗口不一致时的标准决策结构。

该模板不替代 S03 冲突检测。S03 负责识别冲突；本模板负责规定 Agent-1 面对已确认冲突时如何组织证据、目标、约束和方案，并收敛到唯一 FinalDecision。

## 典型场景
- Agent-4建议放量，但Agent-7提示断货风险；
- Agent-10建议降价，但Agent-6提示利润底线；
- Agent-9建议大改Listing，但Agent-12提示合规风险；
- 多Agent使用不同时间窗口或证据版本得出相反建议；
- 同一动作改善短期增长但损害长期价格/利润/库存。

## 原则
- 冲突必须保留来源、证据和时间窗口，不把“谁优先”写死成固定Agent等级；
- 先识别硬约束与资格，再比较可行方案；
- 无法解释的证据冲突优先补证据；
- 只允许一个最终决策出口；
- 若冲突实际涉及多个经营目标和多个DecisionItem，可升级综合经营模板。
