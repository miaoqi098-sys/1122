# 库存决策模板

## 1. 定位

本目录承载 Agent-1 对库存、补货、断货、库龄和供应链约束相关经营问题的标准决策结构。

Agent-7 负责库存与供应链监控、风险识别和专业建议；Agent-1 使用本模板把库存问题与广告、价格、利润、促销、增长目标及商品状态联合判断，形成最终经营决策。

---

## 2. 典型适用问题

- 断货风险上升，需要控制销售速度或调整补货节奏；
- 在途库存延迟，现有促销/广告策略是否需要调整；
- 库龄上升，需要清库存、降采买或改变促销策略；
- 库存过量与利润/仓储成本冲突；
- 新品备货不足或补货节奏不确定；
- 多SKU/变体之间库存不均衡；
- 库存风险与BD/LD/Coupon/广告放量计划冲突；
- 补货、周转、现金流和销售目标之间需要取舍。

---

## 3. 不适用/升级

- 纯供应链事实监控 → Agent-7处理并上报，不需要Agent-1模板闭环；
- 主要问题是利润结构 → 利润模板为主；
- 主要问题是价格/促销资格 → 价格促销模板为主；
- 多域联动明显 → 综合经营模板；
- 多Agent建议互斥 → 多Agent冲突模板。

---

## 4. 决策原则

- 库存安全不是简单“越多越好”，要同时考虑周转、现金流和库龄；
- 断货风险判断必须区分可售、在途、补货周期与需求速度；
- 活动/广告放量前必须检查库存承载能力；
- 清库存动作不能忽略价格体系、利润与品牌长期影响；
- 库存决策必须定义观察窗口和重新评估触发；
- Agent-7建议不是最终指令，最终由Agent-1收敛。
