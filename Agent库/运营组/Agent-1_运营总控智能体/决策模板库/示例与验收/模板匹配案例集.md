# 决策模板匹配案例集

> 用于验证模板选择不是按单一指标机械套用，而是依据 DecisionItem、Scope、经营状态、证据与约束进行匹配。

## 1. 广告模板 DT-A1-ADV-001
- 强匹配：某关键词连续获得稳定点击和花费，转化显著低于同组，Listing与价格无明显异常，Agent-4建议降价/否定/隔离测试 → 广告模板主导。
- 条件匹配：ACOS上升，但同期Coupon结束导致转化回落 → 广告模板可用，但价格促销状态为必补上下文。
- 禁用/降级：广告点击高但Listing主图错误、页面被抑制 → 不应直接做广告动作，转Listing/风险模板或 request_more_evidence。
- 邻近边界：广告放量与库存断货风险冲突 → 库存模板为主或进入多Agent冲突模板。

## 2. 库存模板 DT-A1-INV-001
- 强匹配：覆盖天数下降、在途延迟、活动即将开始，需要控制销售速度 → 库存模板主导。
- 条件匹配：库存偏高但利润很好且仓储压力未知 → 先补库龄/仓储证据。
- 禁用/降级：库存正常，问题只是广告效率差 → 不使用库存模板主导。
- 邻近边界：清库存需要大幅降价 → 库存为目标源，价格促销/利润作为约束模板。

## 3. 价格促销模板 DT-A1-PPR-001
- 强匹配：准备BD，需判断折扣、活动期售价与活动后恢复价 → 价格促销模板主导。
- 条件匹配：竞品降价，自身是否跟价尚取决于利润和库存 → 价格模板条件匹配，需利润/库存输入。
- 禁用/降级：当前参考价/促销资格事实无法确认 → request_more_evidence / hold_for_review。
- 邻近边界：降价主要为了清库存 → 库存模板可作为主模板。

## 4. 利润模板 DT-A1-PFT-001
- 强匹配：单位贡献利润连续为负，需要在广告、售价和促销中选择止损方案 → 利润模板主导。
- 条件匹配：新品短期亏损但增长目标明确 → 可用，但必须有投资期限和退出条件。
- 禁用/降级：成本口径和售价版本不一致 → request_more_evidence。
- 邻近边界：利润下降主要由库存仓储费导致 → 利润主导，库存为重要约束。

## 5. Listing与转化模板 DT-A1-LCV-001
- 强匹配：流量稳定、价格评价稳定，但转化持续下降且页面表达存在明显缺口 → Listing模板主导。
- 条件匹配：广告高点击低转化，但流量意图不确定 → 需Agent-4补流量质量证据。
- 禁用/降级：页面被政策抑制 → 风险合规模板优先。
- 邻近边界：转化下降由差评主题集中爆发导致 → 评价体验模板主导，Listing为辅。

## 6. 风险合规模板 DT-A1-RCO-001
- 强匹配：ASIN因资质审核被冻结，有平台通知和截止时间 → 风险合规模板主导。
- 条件匹配：疑似知识产权风险但证据不全 → 先调查/人工复核。
- 禁用/降级：纯经营效率问题无合规影响 → 不使用风险模板主导。
- 邻近边界：Listing文案优化涉及高风险宣称 → Listing与风险模板组合，风险资格限制候选方案。

## 7. 评价体验模板 DT-A1-REV-001
- 强匹配：差评主题、退货原因、QA均集中指向同一使用痛点 → 评价体验模板主导。
- 条件匹配：Rating下降但样本量小 → 继续观察并补证据。
- 禁用/降级：只有一条孤立差评且无交叉证据 → 不形成系统整改决策。
- 邻近边界：负面评价主要源于页面尺寸误导 → 评价模板识别根因，Listing模板执行表达修正。

## 8. 竞品与市场模板 DT-A1-CMT-001
- 强匹配：多个核心竞品同步降价并持续数周，自身流量份额下降 → 竞品市场模板主导。
- 条件匹配：单一竞品短期促销 → 观察持续性后再响应。
- 禁用/降级：自身转化问题明显且竞品无结构性变化 → 不使用竞品模板主导。
- 邻近边界：市场变化引发价格响应 → 竞品模板提供外部依据，价格促销模板负责动作结构。

## 9. 多Agent冲突模板 DT-A1-MAC-001
- 强匹配：Agent-4建议加预算，Agent-7判断两周内断货，双方证据有效 → 冲突模板主导。
- 条件匹配：Agent建议相反但数据窗口不同 → 先统一窗口/补证据。
- 禁用/降级：只是建议措辞不同、实质动作不冲突 → 不需要冲突模板。
- 邻近边界：同时存在多个独立DecisionItem而非单一冲突 → 综合经营模板。

## 10. 综合经营模板 DT-A1-INT-001
- 强匹配：新品启动需要广告、价格、Listing、库存与利润联动，并有阶段性目标 → 综合模板主导。
- 条件匹配：两个域关联但单一主问题仍清晰 → 优先主模板+辅助模板，不必升级综合模板。
- 禁用/降级：问题定义本身不清，只是“销量不好” → 先构建DecisionItem/调查，不使用综合模板掩盖模糊问题。
- 邻近边界：只是两个专业Agent对同一动作意见相反 → 多Agent冲突模板更合适。

## 总体验收观察
这组案例验证：
1. 同一指标可以落入不同模板，取决于根因和目标；
2. 单模板、主辅模板、冲突升级、综合升级四种模式边界可区分；
3. 缺关键证据时存在明确降级路径；
4. 没有任何模板通过固定阈值直接决定动作；
5. 最终输出仍需收敛到 canonical FinalDecision。
