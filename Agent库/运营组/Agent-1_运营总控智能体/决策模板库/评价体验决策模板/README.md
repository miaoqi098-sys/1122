# 评价体验决策模板

## 定位
本目录承载 Agent-1 对 Review、Rating、VOC、退货原因、QA、消费者痛点与产品体验问题的标准决策结构。

Agent-11 负责评价与体验事实分析；Agent-1 结合Listing、产品状态、库存、利润、风险与增长目标决定内容修正、产品改善、客服/QA动作或进一步调查。

## 原则
- 单条差评不能自动代表系统性体验问题；
- 必须区分产品缺陷、预期管理、使用方式、物流/包装、虚假/异常评价等不同根因；
- 评价问题可能影响Listing转化，也可能需要产品/供应链修复，不能只做文案掩盖；
- 涉及评论操纵、政策风险时升级风险合规模板；
- Agent-11建议不直接成为最终经营指令。
