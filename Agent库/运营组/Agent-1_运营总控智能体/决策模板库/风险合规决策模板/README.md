# 风险合规决策模板

## 定位
本目录承载 Agent-1 对平台政策、商品合规、可售资格、知识产权、危险品、绩效通知、资质审核与申诉等高风险问题的标准决策结构。

Agent-12 负责风险监控、事实识别和专业建议；Agent-1 使用本模板决定经营动作是否具备资格、是否需要暂停其他增长动作、是否进入审批/人工复核或申诉任务。

## 原则
- 风险模板优先判断“能不能做”，再讨论“值不值得做”；
- 不把不确定政策解释为确定结论；
- 涉及账户/可售/知识产权等高影响事项时，低置信度应升级复核而非自动冒险；
- 风险事件可以限制其他模板的候选方案，但最终决策仍由Agent-1统一输出；
- 模板不替代最新平台政策事实或法律意见。
