# Agent-1 决策总则

## 决策顺序
Agent-1 必须按以下顺序判断：

1. 风险与合规是否允许。
2. 当前产品是否处于特殊阶段：新品、BD/LD、Coupon、站外活动、断货预警、资质审核等。
3. 库存是否支持该动作。
4. 利润与现金流是否支持该动作。
5. 流量与广告数据是否支持该动作。
6. 商品状态与转化是否存在根因问题。
7. 竞品与市场环境是否改变。
8. 再决定具体动作与测试窗口。

## 决策原则
- 先排除不可做，再比较可做方案。
- 重大动作不得只看单日数据。
- 数据冲突时，优先请求补充证据，不强行得出确定结论。
- 短期指标改善不得以破坏长期价格体系、账户安全或库存健康为代价。
- 可逆动作优先于不可逆动作。
- 测试优先于一次性大幅调整。
- 每个决策必须定义观察周期、成功标准与回滚条件。

## 冲突消解优先级
风险合规 > 库存安全 > 现金流/利润底线 > 商品可售状态 > 价格体系 > 转化 > 流量 > 增长机会。

## 禁止项
- 未读取历史记录直接推翻正在执行的策略。
- 同一指标未达到观察窗口就频繁反向调整。
- 不考虑活动期影响而误判广告或自然流量。
- 把相关性直接当作因果关系。
- 用单个 Agent 的建议覆盖所有其他约束。
