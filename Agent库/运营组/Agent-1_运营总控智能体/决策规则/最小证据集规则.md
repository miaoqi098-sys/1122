# 最小证据集规则

## 1. 定位
本规则定义不同决策类型在进入正常 FinalDecision 前至少需要什么证据。它不规定所有业务指标的具体阈值，具体字段可由决策模板库补充。

## 2. Minimum Evidence Set 结构
每个 `decision_type` 至少定义：
- `required_facts[]`：必须事实；
- `required_time_window`：最低观察时间/数据窗口；
- `required_comparisons[]`：必须比较对象；
- `freshness_requirement`：数据新鲜度；
- `source_reliability_requirement`：来源可信要求；
- `history_requirement`：是否必须读取历史决策/策略；
- `risk_evidence_requirement`：风险资格所需证据；
- `missing_behavior`：缺失时的降级路径。

## 3. 通用最低证据
任何正常执行型 FinalDecision 至少应具备：
- 当前 scope 与对象身份；
- 当前 ContextPackage；
- 与 DecisionItem 直接相关的事实；
- 至少一个时间窗口，而非孤立单点；
- 对应 Option 的成本/收益/风险信息；
- RiskAssessment；
- 关键 constraint_refs；
- 如涉及在运行策略，则必须读取 StrategyChain 与相关历史。

## 4. 典型决策类型示例
### 广告调价
通常至少包括：当前 bid、点击、花费、订单/销售、转化表现、时间窗口、搜索词/关键词对象、最近一次调价及观察期；涉及排名目标时应补排名/流量证据。

### 广告否词/暂停
至少包括搜索词相关性、点击/花费、转化、目标词价值、历史表现，以及是否会误伤核心流量资产。

### 价格/促销
至少包括当前售价、参考价格体系、毛利/贡献利润、库存状态、活动窗口、历史促销结果和价格保护约束。

### 库存补货/保护
至少包括可售库存、在途、销量速度、覆盖天数、补货周期、最坏销售情景和现金约束。

### Listing/内容调整
至少包括当前转化、流量结构、目标关键词、内容缺口、历史改动和观察窗口；不得仅凭审美偏好形成确定结论。

## 5. 证据等级与动作幅度
- 证据完整且一致：允许正常方案比较。
- 局部缺失但风险可控：缩小动作或试验。
- 关键字段缺失：`requires_more_evidence`。
- 来源冲突影响资格/主导风险：停止正常选择。

## 6. 与决策模板库关系
- 本规则提供通用 Minimum Evidence Set 治理框架；
- `决策模板库/` 可按具体场景增加字段；
- 模板不得降低本规则的通用证据底线；
- 若模板与本规则冲突，以本规则为准。

## 7. 禁止
- 用模型常识替代 required_fact；
- 用单日/单点数据满足需要趋势判断的决策；
- 缺少历史策略仍直接反转现行策略；
- 为了快速决策降低模板规定的最低证据；
- 把“暂时拿不到数据”解释成“数据默认正常”。
