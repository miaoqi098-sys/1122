# 决策规则示例与静态验收

## 1. 目的
通过典型经营冲突验证本模块不会退化为固定排序表，并能正确衔接目标系统、S04、S06、S10、DecisionSelector、FinalDecision，以及新增的并发裁决、目标牺牲边界、最小证据集和决策生命周期规则。

## 2. 示例A｜库存紧张但广告增长良好

### 输入特征
- growth_expansion 目标表现良好；
- 库存覆盖天数进入风险区；
- 当前广告扩量 Option 仍可能继续增长；
- 库存属于 survival_operations 层级约束。

### 正确处理
1. 资格门确认是否触发库存 conditional_block / temporary_protection；
2. S04 将库存保护相关 DecisionItem 提升；
3. 广告扩量事项可能从 P1 降至 P2/P3 或进入 protected；
4. 不要求“库存永远高于利润”，而是解释本次变化来自库存风险窗口；
5. 最终方案优先可逆降速、提高单位产出或等待补货，不机械停止所有广告。

### 验收
- [x] 不使用永久固定排序。
- [x] 有 goal_layer / state / risk window 解释。
- [x] 允许保留不冲突的流量资产动作。

## 3. 示例B｜高收益方案被合规禁止

### 输入特征
- Option-A 预计收益最高；
- S06 eligibility = prohibited；
- Option-B 收益较低但 eligible。

### 正确处理
DecisionSelector 必须排除 A，不能用收益覆盖 prohibited；在 B 与其他合格方案之间比较。

### 验收
- [x] eligibility 先于收益比较。
- [x] dominant-risk 不被平均稀释。

## 4. 示例C｜已有策略未完成观察窗口

### 输入特征
- 当前 StrategyChain 正在执行；
- 新一天数据变差；
- 没有 stop_condition / guardrail / critical_new_fact。

### 正确处理
应路由 S10。若结果为 hold，则不得创建冲突 Task，保留 release_conditions 与 review_trigger。

### 验收
- [x] 无新证据不频繁 full_reverse。
- [x] S10 不直接取消旧任务。

## 5. 示例D｜关键证据冲突

### 输入特征
- 两个来源对库存可售量给出冲突结果；
- 冲突会直接影响促销资格与风险判断。

### 正确处理
保留双方 evidence_refs，比较 freshness/source reliability；无法消解时 request_more_evidence 或回 S02 补上下文，不形成高置信执行决策。

### 验收
- [x] 不静默覆盖冲突值。
- [x] 证据不足可降级而非强行确定。

## 6. 示例E｜eligible_with_controls

### 输入特征
- Option 风险可控；
- eligibility = eligible_with_controls；
- required_controls 包括预算上限和复核触发器。

### 正确处理
若被选中，required_controls 必须进入 FinalDecision，并由 S07 转为前置/伴随/验证任务。

### 验收
- [x] controls 不在选择阶段丢失。
- [x] S07 不重新改变业务方向。

## 7. 示例F｜利润 vs 排名

### 输入特征
- 新品处于学习/排名爬升期；
- 广告 TACOS 高于稳定期目标；
- 核心词自然位仍在改善；
- 现金和账户安全仍在允许区间。

### 正确处理
必须建立 Trade-off Boundary：明确允许牺牲的利润范围、最长窗口、排名/自然流量学习目标、提前停止条件和毕业条件。不能只用“新品要冲排名”作为无限亏损理由。

### 验收
- [x] 有 max_sacrifice。
- [x] 有 sacrifice_window。
- [x] 有 recovery_target / stop_condition。

## 8. 示例G｜大促 vs 价格体系

### 输入特征
- 大促临近；
- 深折扣预计提高销量；
- 但可能伤害参考价/长期价格带。

### 正确处理
价格体系属于 protected_goals。促销方案必须定义折扣边界、持续时间、活动后恢复策略和 reference-price 风险；若平台规则形成 absolute/conditional block，则先过资格门。

### 验收
- [x] 促销收益不能无限覆盖长期价格资产。
- [x] 目标冲突通过 Trade-off Boundary 表达。

## 9. 示例H｜多个 P0 同时发生

### 输入特征
- ASIN 库存风险进入 P0；
- 同时存在高花费广告异常 P0；
- 两者争用有限运营/预算调整资源。

### 正确处理
不得按事件到达时间先处理。调用 `多决策并发裁决规则.md`，比较 impact_scope、delay_cost、time_to_irreversibility、dependency_impact 与资源争用，决定并行/串行/合并或显式资源分配。

### 验收
- [x] 多 P0 不默认全并行。
- [x] 不按创建时间或 Agent 编号裁决。

## 10. 示例I｜多个 Agent 结论互相矛盾

### 输入特征
- Agent-4 建议扩广告；
- Agent-6 判断利润压力上升；
- Agent-7 判断库存偏紧。

### 正确处理
三个结论均作为证据/DecisionItem 来源，不允许任一专业 Agent 直接形成最终跨域决策。Agent-1 通过目标层级、资格、Trade-off Boundary 和并发裁决形成 FinalDecision。

### 验收
- [x] Agent-2至13不越权形成跨域 FinalDecision。
- [x] 冲突来源保留。

## 11. 示例J｜一个动作解决多个 DecisionItem

### 输入特征
- 广告 ACOS 高；
- 库存偏紧；
- 两个 DecisionItem 都指向削减低效广泛流量。

### 正确处理
识别为 `same_action`，允许合并成联合方案，但必须保留所有 source decision_item_ids，避免重复创建互相覆盖的 Task。

### 验收
- [x] 能合并同动作事项。
- [x] 原始问题追溯不丢失。

## 12. 示例K｜部分执行后出现新事实

### 输入特征
- FinalDecision 已 active，部分 Task 已执行；
- 新库存事实使原放量策略不再成立。

### 正确处理
原决策进入 invalidated 或 superseded，不原地改写。保留 executed_task_ids/remaining_task_ids，新决策必须把已发生动作纳入 ContextPackage，并由 S07 处理剩余 Task 的 continue/pause/cancel/replace/rollback。

### 验收
- [x] 决策生命周期完整。
- [x] 部分执行历史不被抹掉。

## 13. 示例L｜审批被拒绝

### 输入特征
- 高影响动作 requires_approval；
- 审批结果为拒绝。

### 正确处理
原 pending_approval 决策不得进入 active。根据拒绝原因转 cancelled、regenerate_options 或降级为低影响替代方案；不得把拒绝当普通备注继续执行。

### 验收
- [x] 审批门是真门禁。
- [x] 有拒绝后的降级路径。

## 14. 示例M｜决策超时未执行

### 输入特征
- FinalDecision 已 approved/active；
- 超过 valid_until；
- 上下文可能已变化。

### 正确处理
标记 expired；不得直接继续执行。重新读取 ContextPackage 和 Minimum Evidence Set，必要时生成新 Decision。

### 验收
- [x] expired 不原地复活。
- [x] 重新评估后才允许继续。

## 15. 示例N｜没有可行 Option

### 输入特征
- 一个 Option prohibited；
- 其他 Option 均 requires_more_evidence。

### 正确处理
不得为了产生“答案”强选一个方案。输出 request_more_evidence / hold_for_review / regenerate_options，保持未决状态。

### 验收
- [x] 无可行方案时允许不决策。
- [x] requires_more_evidence 不被包装成 eligible。

## 16. 示例O｜机会窗口即将消失

### 输入特征
- 竞品核心 ASIN 断货；
- 当前自身库存健康；
- 关键词自然位接近首页；
- 机会预计只持续 48 小时。

### 正确处理
S04 必须考虑 delay_cost、window_decay 和 time_to_irreversibility，而不能因为当前没有“严重风险”就排到低优先级。增长动作仍需服从预算、利润和库存保护边界。

### 验收
- [x] 机会窗口进入动态优先级。
- [x] 机会不覆盖硬约束。

## 17. 示例P｜连续小幅调参累积成重大变化

### 输入特征
- 同一广告策略连续多次每次降低 10% bid；
- 单次都像 tune；
- 累计已改变原策略方向和规模。

### 正确处理
S10 应识别累计变化，升级为 scale_down/replace 级重新评估，禁止通过切成多个小动作绕过稳定性门禁。

### 验收
- [x] 微调与重大变化可区分。
- [x] 不允许“小步绕门禁”。
