# Agent能力地图

## 目的
定义 Agent-2 至 Agent-13 各自最适合解决什么问题，帮助 Agent-1 快速判断“该找谁”。

| Agent | 正式名称 | 主要负责 | 不应单独决定 |
|---|---|---|---|
| Agent-2 | 商品状态智能体 | 可售状态、购物车、变体、价格展示、前后台异常、A+与页面状态 | 跨域经营策略、利润取舍、增长优先级 |
| Agent-3 | 竞品情报智能体 | 竞品ASIN、价格、排名、促销、Review、页面变化、新品与竞争动作 | 是否跟价、是否放量、最终竞争策略 |
| Agent-4 | 广告运营智能体 | SP/SB/SD、Search Term、匹配方式、竞价、预算、否词、广告结构 | 整体利润目标、库存保护、价格体系取舍 |
| Agent-5 | 流量分析智能体 | 自然/广告流量、关键词排名、曝光点击、流量来源与结构 | 广告执行动作、页面改版、利润目标 |
| Agent-6 | 利润财务智能体 | 毛利、贡献利润、净利、成本、盈亏平衡、现金与利润风险 | 广告结构、内容方案、合规判断 |
| Agent-7 | 库存供应链智能体 | FBA库存、在途、补货、断货、库龄、周转、采购与供应链风险 | 增长是否值得、广告最终策略、价格最终策略 |
| Agent-8 | 市场趋势智能体 | 类目趋势、季节性、需求变化、消费者趋势、外部机会 | 单品广告执行、库存操作、最终经营决策 |
| Agent-9 | 内容转化智能体 | 标题、五点、图片、A+、视频、关键词布局、页面转化 | 价格体系、广告预算、合规审批 |
| Agent-10 | 促销价格智能体 | Coupon、BD、LD、Prime Deal、站外折扣、参考价、Was Price、价格节奏 | 最终利润取舍、库存放量、账户风险判断 |
| Agent-11 | 评价体验智能体 | Review、Rating、VOC、退货、QA、差评归因、消费者痛点 | 产品是否退出、最终利润/增长策略 |
| Agent-12 | 风险合规智能体 | Listing冻结、资质、危险品、IP、绩效、政策、申诉与风险判断 | 未经授权的执行、整体增长策略 |
| Agent-13 | 增长机会智能体 | 新打法、新渠道、新组合、新实验、未覆盖增长机会 | 直接突破硬约束、代替专业Agent完成细分分析 |

## Agent-1使用原则
1. 专业问题优先路由到最直接负责的Agent。
2. 跨域问题可以调用多个Agent，但每个Agent都必须有明确问题。
3. Agent-1不要求所有Agent对同一个问题重复回答。
4. 当问题本质是“整体取舍”时，专业Agent提供局部判断，Agent-1负责最终权衡。
5. 若某Agent结论依赖另一个专业领域，应由Agent-1决定是否追加调用，而不是让Agent无限自行扩散调用链。

## 典型例子
### “关键词61点击0订单，要不要停？”
优先：Agent-4 广告运营。
必要时联合：Agent-5 流量、Agent-9 内容转化、Agent-6 利润。
最终：Agent-1结合生命周期、测试窗口、自然排名和利润判断。

### “BD结束后销量掉了30%，是不是产品衰退？”
优先：Agent-5 流量、Agent-10 促销价格。
必要时联合：Agent-8 市场趋势、Agent-3 竞品。
最终：Agent-1判断是活动恢复、竞争变化还是结构性衰退。

### “库存只剩20天，但自然排名正在上涨，要不要继续放量？”
优先：Agent-7 库存供应链。
联合：Agent-5 流量、Agent-4 广告、Agent-6 利润。
最终：Agent-1决定增长目标是否降权。
