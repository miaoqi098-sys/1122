# 协作机制

本目录定义 Agent-1 如何向 Agent-2 至 Agent-13 请求信息、组合专业结论并处理跨 Agent 冲突。

## 规划文件
- Agent能力地图.md
- 问题到Agent路由表.md
- 必须联合分析场景.md
- Agent冲突处理.md
- Agent追问规则.md

## 核心目标
让 Agent-1 不只是说“需要更多信息”，而是能够明确判断：缺什么信息、应该向哪个 Agent 请求、请求哪些字段、拿到结果后如何与其他证据合并。

## 原则
- 保留每条专业结论的来源。
- 重大决策不得只依赖单一 Agent。
- 发现结论冲突时，优先补证据而不是强行平均。
- Agent-1 是最终经营决策出口，但不替代专业 Agent 的专业分析职责。
