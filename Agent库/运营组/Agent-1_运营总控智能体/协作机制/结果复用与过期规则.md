# Agent结果复用与过期规则

## 目的
定义 Agent-1 什么时候可以直接复用已有专业 Agent 结论，什么时候必须重新分析，减少重复调用和无意义成本。

## 一、结果可复用条件
已有结论原则上只有同时满足以下条件时才可直接复用：
- 分析对象相同或适用范围明确覆盖当前对象；
- 当前问题与原问题一致或高度相近；
- 数据时间窗口仍然有效；
- 经营状态没有发生实质变化；
- 没有新的高优先级事件；
- 关键输入数据没有显著变化；
- 原结论证据质量和置信度足够；
- 当前决策影响等级没有明显提高。

## 二、强制重新分析条件
出现以下任一情况，旧结果原则上失效或需要复核：
- 商品从可售变为受限/不可售；
- 进入或退出BD、LD、Prime Deal等重要活动；
- 库存风险等级明显变化；
- 价格、Coupon或参考价状态发生重大变化；
- 主要竞品出现结构性动作；
- 核心关键词排名、流量或CVR发生明显变化；
- Rating、退货或VOC进入新风险级别；
- 平台规则或账户状态变化；
- 原分析所依赖的数据源、口径或假设失效；
- 当前计划动作比原分析对应动作风险更高或更不可逆。

## 三、有效期不是固定天数
不同类型结论应有不同新鲜度要求。

### 高时效结论
例如：
- 当前价格；
- Buy Box；
- 库存；
- Listing可售状态；
- 广告预算状态；
- 合规通知。

应使用最新数据，旧结论很快过期。

### 中时效结论
例如：
- 广告结构诊断；
- 流量趋势；
- CVR异常；
- 竞品促销趋势。

可在经营状态稳定且数据未明显变化时复用一段观察窗口。

### 长时效结论
例如：
- 产品主要使用场景；
- 核心消费者痛点；
- 已验证的结构性产品差异；
- 长期经营原则。

可以较长时间复用，但遇到产品改版或市场结构变化时仍需复核。

## 四、valid_until
专业 Agent 返回结果时，建议附：
- `valid_until`：明确有效期；或
- `review_trigger`：触发复核的条件。

例如：
```text
valid_until: 2026-09-05
review_trigger:
- 库存覆盖跌破安全区
- 核心词自然排名跌出首页
- CPC变化超过当前配置阈值
```

## 五、部分复用
旧结论不一定整体失效。

例如：
- 原广告诊断中的Search Term意图判断仍有效；
- 但CPC、ACOS、库存和价格数据已经过期。

Agent-1可以保留仍有效的事实/知识，只重新请求变化部分。

## 六、结果版本
未来运行器应为专业结论保留：
- analysis_id；
- source_agent；
- created_at；
- data_window；
- business_state；
- input_version；
- confidence；
- valid_until；
- supersedes；
- superseded_by。

避免多个旧结论同时存在但无法判断哪个是当前版本。

## 七、复用前检查
```text
对象一致？
↓
问题一致？
↓
经营状态没变？
↓
关键数据没变？
↓
结论仍在有效窗口？
↓
当前决策风险没有升高？
↓
是 → 复用
否 → 局部更新或重新分析
```

## 核心原则
Agent协作不是每次从零开始。真正成熟的系统应该记得之前已经分析过什么，同时也知道什么时候旧答案已经不能再信。
