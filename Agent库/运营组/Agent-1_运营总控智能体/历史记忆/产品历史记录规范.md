# 产品历史记录规范

Agent-1 每次做决策前，必须读取与当前问题相关的产品历史记录。

## 必须记录的历史事件
- 价格与参考价变化
- Coupon、BD、LD、站外活动时间段
- 广告重大调整
- Listing 内容重大调整
- 变体关系变化
- 库存断货、补货、入仓异常
- 合规/资质/绩效异常
- 评价与退货异常
- 重大竞品动作
- 已执行的策略、观察窗口、结果与结论

## 每条记录字段
- history_id
- product_id / ASIN
- timestamp
- category
- action_or_event
- reason
- related_decision_id
- before_state
- after_state
- result
- lesson
- valid_until（若结论具有时效性）

## 使用原则
1. 历史记录是决策上下文，不是永久真理。
2. 有时效性的结论必须检查 valid_until。
3. 新决策与历史策略冲突时，必须说明为什么推翻旧结论。
4. 活动期数据必须与正常期数据区分。
5. 不允许删除失败记录；失败记录是后续防重复试错的重要依据。
