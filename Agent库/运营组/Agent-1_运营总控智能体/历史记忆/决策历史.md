# 决策历史

## 1. 定位
决策历史保存每个正式FinalDecision及其版本、替代关系、策略链和决策依据。历史决策被新决策替代后仍保留，不覆盖、不删除。

## 2. 最低引用
每条决策历史至少应保留：
- decision_id
- decision_item_id
- scope
- business_priority
- selected_option / option_id
- risk_assessment引用
- decision_basis引用
- approval状态/引用
- decision_confidence
- source_event_ids[]
- strategy_chain_id（适用时）
- supersedes_decision_id（适用时）
- created_at / valid_until / review_trigger
- status / historical_status

## 3. 版本与替代
新决策改变旧方向时：
- 新Decision使用新的decision_id；
- 通过supersedes_decision_id或StrategyChain建立关系；
- 旧Decision不得被原地改写成新内容；
- 保留为何改变的trigger/evidence refs。

## 4. StrategyChain
一个StrategyChain可以包含多个Decision版本。决策历史应保留：
- strategy_chain_id；
- previous/current direction关系；
- 对应S10 stabilization/override引用；
- adjustment/reversal历史（未来由R11真实维护）。

## 5. 读取原则
S02装载历史Decision时应判断：
- 是否仍是active/current；
- 是否已superseded；
- valid_until是否过期；
- 当前scope/目标/状态是否仍可比；
- 是否存在新的ValidationResult/LearningRecord推翻或修正旧判断。

## 6. 禁止
- 只保存最新Decision；
- 覆盖旧decision_id；
- 把旧Decision当当前强约束而不检查状态；
- 没有新证据说明就频繁反转策略。
