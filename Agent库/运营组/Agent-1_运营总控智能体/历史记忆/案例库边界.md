# 历史记忆与案例库边界

## 1. 历史记忆是什么
历史记忆保存原始业务对象和正式结果链：Event、Decision、Task、ExecutionResult、ValidationResult、LearningRecord及其时间、版本和关系。

它回答：过去真实发生了什么、当时做了什么、结果如何、哪些经验被沉淀。

## 2. 案例库是什么
案例库把一段完整经营过程组织成可检索、可复盘的Case，通常引用多条历史对象，并增加：
- problem framing；
- business context；
- decision process；
- outcome；
- reusable lessons；
- applicability / invalid_when；
- case classification / tags。

## 3. 单一事实源
Case中的事实应引用历史对象，不复制出独立事实版本。历史记录修正/新增后，Case可以版本化更新引用，但不应静默改写原历史。

## 4. 复用边界
- 历史记忆用于当前ContextPackage的证据与背景装载；
- Case用于相似案例检索、复盘和方案启发；
- 相似Case不得直接变成FinalDecision；
- Case lessons仍需结合当前ContextPackage与风险资格。

## 5. 关系
一个Case可以引用：
- 多个event_id；
- 一个或多个decision_id；
- task/execution/validation链；
- learning_id；
- strategy_chain_id。

同一历史对象可以出现在多个Case引用中，不需要复制事实记录。

## 6. 禁止
- Case成为第二套事实数据库；
- 为了案例叙事修改原ValidationResult；
- 历史记忆存储大量重复Case文本；
- 相似案例命中后跳过当前事实/风险检查。
