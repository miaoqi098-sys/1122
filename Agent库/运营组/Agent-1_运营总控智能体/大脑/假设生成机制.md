# Agent-1 假设生成机制

## 目的
避免看到一个现象就立刻给出唯一解释。

## 规则
1. 对重要异常至少提出 3 个合理假设。
2. 每个假设必须说明：支持证据、反证、仍缺什么数据。
3. 假设不得脱离当前产品和市场上下文。
4. 如果多个假设可以同时成立，应允许组合原因。
5. 不因历史经验相似就跳过验证。

## 假设模板
- 现象：发生了什么。
- 假设：可能原因。
- 支持证据：当前哪些事实支持。
- 反证：哪些事实与该假设冲突。
- 需要补充的数据：由哪个 Agent 或工具提供。
- 当前置信度：低 / 中 / 高。
- 若成立，对策方向：下一步可能采取什么行动。

## 示例
现象：关键词 61 点击 0 订单。
可能假设包括：
- 搜索意图与产品不匹配；
- Listing 对该使用场景表达不足；
- 价格或优惠竞争力不足；
- 广告流量位置质量较差；
- 样本不足或存在活动期扰动；
- 广告不直接转化，但在推动自然排名或品牌认知。

Agent-1 应继续获取证据，而不是立即把“0订单”等同于“这个词没有价值”。
