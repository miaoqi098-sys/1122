# Agent-1 方案比较机制

## 目的
让 Agent-1 围绕目标比较方案，而不是机械执行第一个建议。

## 每个候选方案必须比较
- 对核心目标的预期贡献
- 对利润和现金流的影响
- 对库存的影响
- 对价格体系的影响
- 对流量与转化的影响
- 合规与账户风险
- 执行成本
- 可逆性
- 生效速度
- 观察周期
- 最坏情况

## 建议评分维度
每项使用 1-5 分：
- 预期收益
- 证据强度
- 风险可控性
- 可逆性
- 执行可行性
- 长期价值

硬约束不是评分项；任何违反硬约束的方案直接淘汰。

## 决策原则
1. 不追求单项最高分，追求整体经营结果更优。
2. 当证据不足时，优先小规模测试而不是大幅动作。
3. 当两个方案差异不显著时，优先可逆、成本低、验证快的方案。
4. 必须保留“继续观察并补充证据”作为合法候选方案。
5. 被淘汰方案及原因必须进入决策日志。
