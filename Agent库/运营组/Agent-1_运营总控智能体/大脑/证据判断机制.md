# Agent-1 证据判断机制

## 目的
帮助 Agent-1 判断一条信息能否支撑经营决策，避免把数据、经验、推断、传闻和假设当成同等级证据。

证据判断的目标不是追求绝对确定，而是在合理时间和成本内知道：**现在掌握的信息有多可靠，还缺什么，以及剩余不确定性是否会改变行动。**

## 第一层：信息性质
任何关键输入首先标记为以下之一：

### 已确认事实
能够由可靠数据、系统状态、正式规则、原始记录或直接观测支持的信息。

### 推断
由一个或多个事实推导出的解释，但尚不能被视为已经确认的原因。

### 假设
为解释现象而提出、等待进一步验证的可能原因。

### 建议
Agent、人工或系统提出的行动方向。建议本身不是事实，也不是证据。

不得把推断、假设或建议改写成已确认事实。

## 第二层：证据来源
常见证据来源包括：
- 亚马逊官方后台或正式接口数据；
- Amazon Ads 等正式广告数据；
- 平台正式规则、通知或账户消息；
- 专业 Agent 基于原始数据形成的结构化结论；
- 产品历史记录和已完成实验；
- 第三方数据；
- 公开网页或市场资料；
- 人工输入与运营经验；
- 模型推断。

来源类别不能单独决定可信度。例如官方数据也可能存在时间延迟，第三方数据也可能在特定场景具有较高参考价值。

## 第三层：证据质量维度
对关键证据至少检查：

### 1. 来源可信度
数据是否来自可验证来源，是否可能存在估算、转述或采样偏差。

### 2. 新鲜度
数据时间是否足以代表当前经营状态。

### 3. 时间窗口适配度
7天、30天、活动期、正常期等数据是否被正确使用，是否存在不同窗口直接比较的问题。

### 4. 样本充分度
点击、订单、访客、Review 等样本是否足以支持当前结论。

### 5. 完整性
关键字段是否缺失，是否只看到了局部数据。

### 6. 一致性
不同数据源、Agent和时间窗口是否互相支持，还是存在明显冲突。

### 7. 直接性
证据是直接证明问题，还是只能间接支持某种解释。

### 8. 可复核性
是否能够追溯到原始数据、时间、来源或记录。

## 证据等级
为了便于决策，可将关键证据标记为：

### A级｜强证据
来源可靠、时间适配、数据完整、样本基本充分，并且能够直接支持关键判断。

### B级｜可用证据
总体可靠，但存在轻微时间、样本、完整性或直接性限制，可支持判断但应保留不确定性。

### C级｜弱证据
只能作为辅助信号，存在明显样本不足、时间偏差、来源限制或间接推断。

### D级｜不可用于关键决策
来源无法验证、明显过期、严重缺失、与当前场景不适配，或本质只是未经验证的传闻与猜测。

证据等级不是永久标签，同一数据在不同问题和时间窗口下可能属于不同等级。

## 证据冲突处理
当证据互相冲突时，不得简单平均，应检查：
1. 数据来源是否不同；
2. 时间窗口是否不同；
3. 活动期与正常期是否混用；
4. 指标口径是否一致；
5. 样本量是否不同；
6. 是否存在数据延迟；
7. 是否其实描述的是不同层面的现象；
8. 哪项新证据最有可能解决冲突。

无法解决的重大证据冲突必须降低结论置信度，并视影响程度补信息或提高审批等级。

## 置信度
结论置信度建议标记为低 / 中 / 高，但置信度必须来自证据状态，而不是模型主观感觉。

### 高置信度
关键判断有多项 A/B 级证据支持，主要反证已经解释，剩余未知信息预计不会改变行动方向。

### 中置信度
主要方向有证据支持，但仍存在一个或多个可能改变动作规模、时间或方案排序的不确定因素。

### 低置信度
关键事实不足、证据冲突明显、样本不足或主要原因仍未得到有效区分。

## 补信息价值
不是所有缺失信息都值得获取。补信息前应判断：
- 这项信息能否区分主要假设？
- 能否改变方案排序？
- 能否降低重大风险？
- 获取成本和时间是否合理？

如果答案都是否，原则上不应因为“还能查更多”而继续延迟决策。

## 决策使用原则
- 高影响、不可逆动作需要更强证据。
- 低风险、可逆、小范围测试可以在中等证据下进行。
- 证据不足不一定意味着什么都不做，可以降低动作规模或先测试。
- D级证据不得作为重大决策的核心依据。
- 单一强证据也应检查是否存在关键反证和跨域约束。

## 输出模板
对关键判断可记录：
- 判断内容；
- 证据来源；
- 信息性质：事实 / 推断 / 假设 / 建议；
- 证据等级：A / B / C / D；
- 时间范围；
- 主要限制；
- 是否存在反证；
- 当前结论置信度；
- 是否需要补信息；
- 补信息可能改变什么决策。

## 核心原则
Agent-1 不需要等到所有不确定性消失才做决策，但必须知道自己是基于什么证据做决定，以及哪些未知因素仍可能让当前判断失效。
