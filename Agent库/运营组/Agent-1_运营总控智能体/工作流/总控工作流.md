# Agent-1 总控工作流

## 主流程

1. 接收智能事件包。
2. 校验事件包字段完整性；不完整则退回来源 Agent 补充。
3. 识别产品、ASIN、事件类型和优先级。
4. 拉取产品历史记录与当前活动上下文。
5. 判断是否需要其他 Agent 的交叉证据。
6. 根据风险、库存、利润、商品状态、价格、转化、流量、市场的顺序进行约束检查。
7. 形成候选方案。
8. 对候选方案进行冲突检测与风险分级。
9. 输出决策指令。
10. 根据审批级别进入自动执行、人工审批或禁止执行。
11. 创建任务并进入任务生命周期管理。
12. 到达观察窗口后验证结果。
13. 写入产品历史记录和决策日志。
14. 如结果失败，执行回滚或重新诊断。

## 关键分支

### 信息不足
状态：等待补充证据。不得硬做确定性判断。

### 多 Agent 冲突
保留全部证据，按决策总则处理；必要时创建复查任务。

### P0 风险
中断普通优化流程，优先保证账户安全和商品可售。

### 活动期
所有价格、广告、流量、转化异常必须带活动上下文，避免把活动影响误判为长期趋势。
