# 工具与数据需求

本目录定义 Agent-1 在不同经营判断中需要哪些数据、从哪里获得、何时调用工具，以及缺失哪些信息时不能形成强决策。

## 规划内容
- 数据需求地图.md
- 问题到数据源映射.md
- 工具调用条件.md
- 关键数据缺失规则.md
- 数据新鲜度要求.md
- 数据冲突处理.md

## 数据方向
- 商品状态与前后台状态
- 广告与搜索词数据
- 自然流量与关键词排名
- 竞品与市场数据
- 利润与费用数据
- 库存与补货数据
- 价格与促销历史
- 评价、退货、VOC 与 QA
- 合规与账户风险
- 历史决策、任务与实验结果

## 原则
Agent-1 不直接拥有全部数据能力，而是通过系统运行层和工具层调用统一数据能力。此目录只定义“什么时候需要什么数据，以及数据达到什么条件才足以支撑决策”。
