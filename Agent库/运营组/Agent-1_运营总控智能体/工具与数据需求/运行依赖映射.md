# 运行依赖映射

## 1. 目的

本文件把 Agent-1 已定义的数据/工具需求映射到未来共享层能力，防止 Agent库 为了“现在不能运行”而开始实现基础设施，也防止未来基础设施建设遗漏业务需求。

本文件只引用 `临时建设任务/运行依赖待办.md` 中已登记的运行依赖，不另造重复编号。

## 2. R01｜Skill Runner
支撑：S01-S10 技能调用、路由、统一调用Envelope和中间状态。

Agent-1需求：
- 能按路由执行而非简单固定for-loop；
- 保留run_id/trace_id；
- 支持needs_information/hold等路由；
- S10可横向介入。

## 3. R02｜Agent Runner
支撑：Agent-1调用Agent-2至Agent-13。

Agent-1需求：
- 按协作机制构造请求；
- 返回专业结论的source/scope/window/evidence/confidence；
- 允许复用未过期结果；
- 调用失败不得伪造专业分析。

## 4. R03｜Schema Validator
支撑：canonical业务对象、DecisionTemplate、Case、DataRequirement、ToolRequirement等结构验证。

Agent-1需求：
- 加载/执行前验证；
- 返回明确字段错误；
- 失败状态可进入路由而非仅抛异常；
- 不把“Validator不可用”视作“验证通过”。

## 5. R04｜Amazon SP-API Connector
支撑：商品、库存、订单、价格/报告、费用等可取得能力范围内的数据。

Agent-1需求：
- 标准化Scope和时间；
- 记录来源endpoint/report版本；
- 区分实时状态与延迟报表；
- 数据失败返回标准失败语义。

## 6. R05｜Amazon Ads API Connector
支撑：广告实体、预算/竞价、报表、搜索词数据及未来批准后的广告动作。

Agent-1需求：
- 报表归因窗口可追溯；
- campaign/ad_group/keyword/search term层级清晰；
- 读取与动作能力分离；
- 动作结果进入ExecutionResult。

## 7. R06｜长期记忆数据库
支撑：产品历史、Decision/Task/Validation/Learning、Case、StrategyChain等长期对象。

Agent-1需求：
- 按Scope/时间/对象ID检索；
- Case关系和版本；
- 相似案例候选检索；
- freshness/valid_until/review_trigger；
- 不静默覆盖矛盾历史。

## 8. R07｜调度器
支撑：S07 TaskPlan/TaskGraph、观察窗口和后续复核。

Agent-1需求：
- depends_on/blocks/并行与互斥；
- 定时与事件驱动；
- blocked/approval状态；
- 观察任务到期后重新进入S08或新事件链。

## 9. R08｜执行器
支撑：已批准经营动作的实际执行。

Agent-1需求：
- 只接受合格Task；
- 检查审批/权限；
- 幂等与审计；
- 明确成功、失败、部分完成；
- 不让Agent-1自行宣称执行成功。

## 10. R09｜ExecutionResultNormalizer
支撑：不同工具/人工结果统一为ExecutionResult。

Agent-1需求：
- 保留原始结果引用；
- 区分工具成功与业务成功；
- 部分执行可表达；
- 供S08统一消费。

## 11. R10｜LearningWriteExecutor
支撑：S09 MemoryWritePlan真实写入。

Agent-1需求：
- planned/queued与written严格区分；
- 写入失败有回执；
- Learning关系和版本保持。

## 12. R11｜StrategyChain持久化与更新
支撑：S10策略稳定性。

Agent-1需求：
- 当前策略版本；
- 调整/反转次数；
- supersedes关系；
- 并发更新保护；
- 能检索相关Decision/Task/Validation。

## 13. 当前未单独创建的新依赖

本模块目前没有发现必须新建 R12+ 的独立能力。

数据质量检查、模板检索、案例检索、指标计算等能力可以先作为 R01/R03/R06/共享数据接口及未来工具层的子能力，不为了文档结构重复拆运行编号。

若后续系统设计证明存在独立生命周期、独立部署或独立验收需求，再新增运行依赖。

## 14. 边界原则

Agent库负责说清“需要什么”；共享层负责“怎么提供”。

未来基础设施实现若无法满足本文件需求，应调整基础设施接口，而不是让Agent-1绕过数据质量、权限或canonical对象规则。
