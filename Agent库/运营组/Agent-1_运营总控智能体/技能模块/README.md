# 技能模块

本目录用于逐步替代旧 `Skill/` 目录，统一使用中文名称“技能模块”。

技能模块是 Agent-1 可重复调用的具体能力，不等于整个 Agent。

## 当前规划技能
- S01 事件校验
- S02 上下文装载
- S03 冲突检测
- S04 决策排序
- S05 候选方案生成
- S06 风险分级
- S07 任务拆解
- S08 结果验证
- S09 复盘写回
- S10 策略防抖

## 每个技能模块至少包含
- 技能说明
- 输入规范
- 输出规范
- 判断规则
- 示例
- 异常处理
- 测试用例
- 后续执行程序

## 迁移原则
旧 `Skill/SKILL_INDEX.md` 暂时保留作为历史索引，后续每个技能真正实现后，再逐步迁移并删除旧目录，避免在框架阶段丢失已有定义。
