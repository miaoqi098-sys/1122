# 技能模块

本目录是 Agent-1 唯一正式技能承载目录。知识回答“应该知道什么”，技能回答“面对任务执行哪套标准能力”，工具负责真实数据与系统操作。

## 标准技能结构
每个技能原则上包含：
1. `README.md`：目的、边界、调用位置；
2. `输入规范.json`；
3. `输出规范.json`；
4. `判断规则.md`；
5. `异常处理.md`；
6. `示例/`（需要时逐步补真实案例）；
7. `测试/验收测试.md`；
8. `执行程序/README.md`，后续替换/扩展为真实程序。

## 工程原则
- Skill 不直接硬编码Amazon API；数据读取由数据接口层/工具层负责。
- 业务阈值优先从经营指标库和配置读取。
- Skill允许“信息不足/无法判断”作为合法结果。
- 高风险动作必须经过权限与审批机制。
- 所有决策链应保留证据、时间、版本和可追溯关系。
- 规则层负责稳定边界，大模型负责需要语义理解、假设和方案创造的部分。
- 不把十个Skill做成十个孤岛；它们共同组成Agent-1的标准决策流水线。

## 当前建设状态
S01-S10 均已完成 V1.0 规则与接口骨架。其中S01、S02已包含较完整示例；S03-S10已建立README、输入输出Schema、判断规则、异常处理、验收测试和执行程序边界。

当前十个Skill仍属于“可工程化规格”，尚未等于“可运行程序”。下一阶段应停止继续横向增加Skill，转向：
1. 对齐决策规则与目标系统；
2. 建立Skill统一调用协议；
3. 在系统运行层实现Skill Runner；
4. 先把S01→S02→S03做成第一条真实可运行链；
5. 再逐步接S04-S10。
