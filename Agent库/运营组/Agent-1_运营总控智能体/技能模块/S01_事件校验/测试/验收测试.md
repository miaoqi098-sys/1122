# S01 事件校验验收测试 V1.1

- T01 正常product事件：passed + continue_to_S02。
- T02 product作用域缺product_id：needs_information/rejected，错误码PRODUCT_ID_REQUIRED。
- T03 account作用域product_id=null但scope_id/account信息明确：允许通过，不得要求伪造ASIN。
- T04 store作用域product_id=null且scope_objects明确：允许通过。
- T05 global事件作用域清楚：允许进入后续链。
- T06 缺event_id：rejected。
- T07 缺recommendation：不阻断。
- T08 facts为空但summary明确：needs_information，不直接推导经营结论。
- T09 来源越界：SOURCE_SCOPE_MISMATCH，建议对应专业Agent复核。
- T10 产品无法识别：不得自动绑定其他ASIN。
- T11 occurred_at不可解析：TIME_INVALID。
- T12 severity明显不匹配：保留来源severity并warning。
- T13 相同event_id重复：duplicate_signal=true，不在S01合并。
- T14 近重复事件：POSSIBLE_DUPLICATE。
- T15 summary与facts冲突：不得passed为高质量事件。
- T16 历史事件用于复盘：允许passed_with_warnings。
- T17 外部产品库不可用：不得把“查不到”解释成“产品不存在”。
- T18 account事件中scope_type=account但内容只指向单ASIN：EVENT_SCOPE_MISMATCH并要求澄清。
- T19 product事件中product_id存在但scope_objects指向不同产品：不得静默选择。
- T20 normalized_event必须保留scope_type/scope_id/product_id/scope_objects。
- T21 S01 passed输出必须能被S02 validated_event直接消费。
- T22 rejected输出normalized_event允许null且不得进入S02。

## 验收标准
1. 阻断错误不会误放行；
2. 非阻断字段缺失不会一律拒绝；
3. product/account/store/global作用域均能正确表达；
4. 不为非产品事件伪造product_id；
5. 不修改来源事实来“修好”事件；
6. 所有异常都有明确状态与下一动作；
7. normalized_event与S02接口完全对齐。
