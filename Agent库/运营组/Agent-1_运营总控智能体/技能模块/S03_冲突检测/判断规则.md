# S03 判断规则

1. 先查事实冲突，再查解释和建议冲突；底层事实未统一时不得直接比较方案。
2. 同一指标必须比较来源、口径、对象、时间窗口、as_of和新鲜度。
3. Agent建议不同不自动构成错误；先检查其优化目标是否不同。
4. 新任务与“执行中/待验证/观察窗口内”任务方向相反时标记任务冲突。
5. 新策略推翻旧策略时检查是否出现新证据、状态切换或目标切换；否则标记策略冲突并交S10。
6. 硬约束与增长建议冲突时至少为high；合规/不可售/不可逆风险可升critical。
7. 不采用多数投票、平均值或固定Agent优先。
8. 无法消除的冲突必须保留 unresolved_points，并降低后续决策置信度。
9. 能通过一个关键数据区分两个假设时，优先请求该决定性证据，而不是继续扩大分析范围。
10. 所有已解决冲突仍应保留解决依据，便于复盘。
