# S04｜决策排序

## 定位
当同时存在多个经营问题、目标或待处理方向时，决定先处理什么、什么可以等待、什么暂时暂停。

## 排序维度
- 目标层级；
- 当前经营约束；
- 风险严重度与发生时间；
- 当前经营状态；
- 目标偏离程度；
- 机会窗口时效；
- 动作可逆性；
- 决策依赖关系；
- 证据强度；
- 资源与执行容量。

## 四级优先级
- P0：需要立即处理的安全或经营底线问题；
- P1：当前周期核心问题；
- P2：重要但可以等待；
- P3：观察项或机会池。

## 规则
1. 先确保高层级目标处于可接受区间，再优化下一层目标。
2. 同层目标动态排序，不设置永久固定次序。
3. 存在前置依赖时，先解决前置问题。
4. 机会型任务不能绕过当前经营约束。
5. 排序不是方案选择；S04只确定处理顺序。

## 输出
每个项目输出：priority、rank、reason、blocked_by、must_resolve_before、defer_until。

## 核心原则
优先级服务于整体经营结果，而不是把一张固定排序表机械套在所有产品上。
