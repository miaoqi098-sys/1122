# S05｜方案生成

## 定位
针对S04确定的高优先级问题，生成多个真正可执行的候选方案，而不是直接给单一答案。

## 候选方案至少覆盖
- 保守方案：风险低、可逆性高；
- 平衡方案：兼顾目标与约束；
- 进取方案：在风险可控时追求更高收益；
- 必要时加入“暂不行动/继续观察”作为合法方案。

## 每个方案字段
`option_id`、`objective`、`actions`、`assumptions`、`expected_benefit`、`cost`、`risks`、`reversibility`、`time_to_effect`、`data_needed`、`success_criteria`、`stop_conditions`。

## 生成来源
当前事实 + 状态 + 目标 + 指标 + 经营知识 + 历史经验 + 专业Agent结论 + 当前约束。

## 规则
- 不生成违反硬约束的方案；
- 不把“多方案”做成同一动作的三个措辞；
- 方案必须存在可执行差异；
- 明确假设，不能把假设写成事实；
- 证据不足时优先生成小范围测试方案；
- 方案数量服务于决策质量，通常2-4个即可。

## 核心原则
S05负责把“知道问题”转成“有哪些路可以走”，选择哪条路留给S06风险评估和大脑比较。
