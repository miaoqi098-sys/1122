# S05 验收测试 V1.1

- T01 61点击0订单且数据较完整：生成降竞价/缩小范围测试/暂停或观察等实质不同方案，不直接宣判关键词无价值。
- T02 61点击0订单但缺花费、搜索词和历史CVR：至少允许information_first，说明这些数据如何改变决策。
- T03 7天库存：不得生成无约束广告扩量方案；越界方案进入excluded_options。
- T04 证据弱：至少考虑可逆experiment、information_first或合法observe。
- T05 历史失败策略：复用前必须说明本次条件发生了什么变化。
- T06 每个行动方案必须有假设、成功标准、停止条件。
- T07 所有路径越界：明确no_feasible_option，不偷偷放宽硬约束。
- T08 S04输入为P1库存风险：S05不得擅自改成“先解决广告效率”问题。
- T09 option_type：输出方案必须明确属于conservative/balanced/aggressive/experiment/observe/information_first之一。
- T10 动作原子化：禁止只输出“优化广告结构”；必须明确action_type、target以及适用的change/scope/window。
- T11 重复方案：-10%、-15%、-20%竞价若策略逻辑相同，应合并为同一方案族而不是三个独立方案。
- T12 实质差异：暂停关键词、降低竞价继续测试、先补决定性数据应识别为不同路径。
- T13 observe方案：必须有观察对象、窗口、结束条件和复核触发点，不能只有“继续观察”。
- T14 information_first：必须说明data_needed能区分什么假设或改变哪个方案。
- T15 derived_from：有知识/历史/Agent/冲突依据时必须尽量保留引用；不得伪造不存在的来源。
- T16 S03关键事实blocks_decision：S05不得生成依赖该事实已确定的激进方案，可生成补证据或安全可逆路径。
- T17 S05/S06边界：S05可以列known_tradeoffs，但不得正式给R1-R4、概率、审批等级等S06字段。
- T18 只有一个合法方案：允许single_feasible_option，不为了数量制造无效方案。
- T19 success_criteria需要尚未接入的数据：必须写data_needed/precondition，不假装可验证。
- T20 方案来源相同但动作方向不同：允许作为独立方案，只要difference_dimensions证明存在实质差异。

## 验收总要求
1. 方案必须承接S04 decision_item；
2. 每个方案必须可解释为什么存在；
3. actions必须达到可执行粒度；
4. 多方案必须有实质策略差异；
5. 高不确定性允许先学习而不是强行动；
6. S05不得越权完成S06正式风险评估；
7. 不允许为了凑方案数量制造伪选择。
