# S06｜风险评估

## 定位
对S05候选方案逐一评估经营风险、可逆性和审批需求，为Agent-1方案比较提供风险侧证据。

## 风险维度
合规/账户、可售、库存、现金流、利润、价格体系、广告、流量资产、消费者体验、执行、数据不确定性、不可逆性。

## 评估字段
`risk_id`、`category`、`likelihood`、`impact`、`time_horizon`、`reversibility`、`detectability`、`mitigation`、`residual_risk`。

## 总体等级
`R0低 / R1可控 / R2显著 / R3高 / R4禁止或必须升级审批`。

## 规则
- 风险等级不能只由概率决定；低概率高损失也可高风险；
- 不可逆动作提高风险权重；
- 证据不足本身是风险；
- 有缓解措施后要评估剩余风险；
- 风险高不等于永远不能做，但必须匹配审批和保护措施；
- 触碰明确禁止行为/硬约束的方案不得包装成“高风险可尝试”。

## 输出
每个option返回总风险等级、风险清单、缓解措施、审批级别、是否可进入方案比较。

## 核心原则
S06不是为了让系统胆小，而是让系统知道自己在冒什么险、最坏会怎样、能不能退回来。
