# S08 判断规则

- 先确认任务动作是否真实完成，再判断经营结果。
- 使用任务创建时冻结的baseline和success_criteria，避免事后改标准。
- 检查观察窗口是否完整；未完整通常continue_observation。
- 同时检查主指标和保护指标。
- 出现stop_condition时优先触发停止/回滚流程。
- concurrent_events必须进入归因说明。
- success要求主要标准达成且无不可接受副作用。
- partial_success用于部分目标达成或收益伴随可控代价。
- failed必须说明是执行失败、策略失败还是触发保护条件。
- inconclusive不是失败，表示当前证据不能可靠归因。
