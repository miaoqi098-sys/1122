# S09｜经验沉淀

## 定位
把S08验证后的事实、成功经验、失败原因和适用边界写回长期记忆、案例和知识候选，使Agent-1下一次不从零开始。

## 沉淀对象
- 产品历史事实；
- 决策与任务结果；
- 成功/失败经验；
- 适用条件和失效条件；
- 新诊断模式；
- 待验证知识候选；
- 应避免重复的失败动作。

## 经验等级
- `observation`：单次观察；
- `product_lesson`：对该产品有价值；
- `reusable_pattern`：跨场景可能复用；
- `knowledge_candidate`：值得进入知识治理验证；
- `validated_knowledge`：经过多案例/高质量证据验证后才能升级。

## 规则
- 单次成功不能自动升级成普遍规律；
- 失败记录不能删除；
- 必须保存适用边界、数据窗口和置信度；
- 事实、解释、经验、知识候选分开存；
- 新经验与旧经验冲突时保留版本和证据，不覆盖历史；
- 有时效性的经验必须有valid_until或review_trigger。

## 核心原则
记忆不是“把聊天保存下来”，而是保存未来决策真正能复用、能追溯、知道何时失效的经验。
