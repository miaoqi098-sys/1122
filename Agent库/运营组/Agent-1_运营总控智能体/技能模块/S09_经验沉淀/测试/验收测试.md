# S09 验收测试 V1.1

- T01 单次广告测试成功：最高默认product_lesson，不直接reusable_pattern/validated_knowledge。
- T02 S08 inconclusive：只写observation/fact，promotion hold。
- T03 execution_failure：保存执行失败经验，不得生成“经营策略无效”。
- T04 strategy_failure且执行真实/窗口完整/数据高质量：允许形成产品级失败lesson。
- T05 data_failure：不形成经营因果规律。
- T06 external_confounding：attribution受限，promotion不得高等级通过。
- T07 assumption_failure：可以形成“当前条件下假设被推翻”的lesson。
- T08 premature_evaluation：只记录过早判断事实，不学策略结论。
- T09 fact与interpretation必须分开输出。
- T10 “CPA 30→24”可以是fact；“降竞价导致CPA改善”必须是interpretation/lesson。
- T11 weak attribution：不得生成high confidence强因果reusable_pattern。
- T12 confounded attribution：promotion_gate通常hold/needs_more_evidence。
- T13 high data quality + moderate/strong attribution +重复独立支持：允许考虑reusable_pattern。
- T14 单次结果请求validated_knowledge：必须拒绝越级。
- T15 knowledge_candidate进入validated_knowledge缺知识治理：不得升级。
- T16 缺applicability：经验降级或hold。
- T17 缺invalid_when：可复用经验不得直接升级。
- T18 活动期经验：必须记录活动背景、valid_until或review_trigger。
- T19 新结果支持旧lesson：relationship=supports并合并独立证据。
- T20 重复同一数据再次输入：不得重复增加独立support_count。
- T21 新结果与旧经验冲突：relationship=contradicts，promotion_gate=conflicted。
- T22 新旧经验适用条件不同：允许coexists，不强制supersedes。
- T23 新证据只细化边界：使用refines。
- T24 足够强的新版本真正替代旧经验：可supersedes，但旧记录仍保留。
- T25 重复lesson：learning_action=merge，不无限生成新记录。
- T26 重要反例：contradiction_count保留并影响promotion。
- T27 结果值得记录但不值得学习：learning_action=record_fact/hold。
- T28 memory store写入失败：memory_writes不得标written。
- T29 previous_lessons缺失：不得声称“与历史无冲突”。
- T30 source decision/task/verification不可追溯：不得升级到高层知识。
- T31 learning item必须记录source_decision_id/source_task_ids/source_validation_ids。
- T32 learning item必须记录evidence_quality和attribution_strength。
- T33 knowledge card必须支持version/created_at/last_validated_at等治理字段。
- T34 positive outcome但guardrail breach：经验必须保留代价边界，不能只写“策略有效”。
- T35 failed outcome但归因weak：不得强写strategy_failure lesson。
- T36 S09不得真实模拟数据库写入成功，只生成memory_writes计划。
- T37 deprecate旧经验：保留历史版本和证据，不物理删除。
- T38 learning_action=promote必须有promotion_reasons。
- T39 promotion_gate=needs_more_evidence必须说明blocking_reasons。
- T40 每条可复用经验都必须能回答“适用于什么、什么时候失效、证据从哪里来”。

## 验收总要求
1. 事实、解释、经验、知识候选必须分层；
2. S08数据质量、归因和failure_type必须约束学习等级；
3. 单次结果不能越级成为通用知识；
4. 新旧经验关系必须版本化而不是覆盖；
5. 失败、反例和不确定性必须保留；
6. promotion gate必须阻止低质量证据污染长期知识；
7. S09只生成结构化写回计划，真正持久化由共享记忆与数据层负责；
8. 所有经验必须可追溯到decision/task/verification证据。
