# S10｜策略防抖

## 定位
贯穿计划、执行、观察和验证阶段，防止Agent-1因为短期波动、重复事件或证据不足而频繁反向调整策略。

## 防抖对象
广告竞价/预算、价格与促销、Listing内容、库存放量策略、关键词测试、实验任务及其他需要观察窗口的动作。

## 触发检测
新建议出现时检查：
- 是否存在同对象执行中/待验证任务；
- 观察窗口是否结束；
- 新证据是否达到反转门槛；
- 是否发生经营状态切换；
- 是否触发停止条件；
- 是否出现更高层级风险；
- 新动作是否与旧动作方向相反。

## 输出状态
`allow / hold / merge / escalate / override`。

- allow：允许新策略；
- hold：继续原观察窗口；
- merge：与现有任务合并；
- escalate：需要更高审批/复核；
- override：出现足够强的新证据或保护条件，允许提前覆盖旧策略。

## 规则
- 未到观察窗口不等于永远不能改；出现重大风险可override；
- 小幅指标波动不能自动推翻已批准策略；
- 连续同方向证据比单点异常权重更高；
- 反转必须记录trigger和evidence；
- 防抖不是拖延，真正状态切换必须及时响应。

## 核心原则
成熟系统既不能一天一个策略，也不能死守旧策略。S10负责区分“噪声”与“真的该变了”。
