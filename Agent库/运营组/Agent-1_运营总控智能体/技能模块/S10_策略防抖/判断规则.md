# S10 判断规则

1. 对象相同且动作方向相反时进入防抖检查。
2. 观察窗口未结束且无强新证据：hold。
3. 新事件只是重复上报同一事实：merge，不创建新反向策略。
4. stop_condition触发、合规/不可售等高层风险出现：允许override或escalate。
5. 经营状态发生确认切换时，可提前重新评估旧策略。
6. 反转证据应比启动策略时的证据更强或出现关键新事实。
7. 价格、广告、Listing等不同类型动作使用不同观察窗口，具体来自任务/配置，不硬编码统一天数。
8. review_at用于下次正常复核，不靠系统不断猜测。
9. 每次override必须记录被覆盖策略、触发条件和新证据。
10. S10不阻止正常实验迭代，只阻止没有新理由的来回摆动。
