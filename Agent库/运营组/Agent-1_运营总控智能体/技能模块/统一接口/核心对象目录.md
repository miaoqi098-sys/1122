# S01-S10 核心对象目录

## 目的
统一十个 Skill 之间反复出现的业务对象，避免同一含义在不同 Skill 中出现不同字段名、不同层级和不同解释。

## Canonical Objects

| 对象 | 中文 | 首次主要产生位置 | 主要消费者 |
|---|---|---|---|
| `Event` | 标准事件 | 事件入口 / S01标准化 | S01、S02、事件处理 |
| `ContextPackage` | 上下文包 | S02 | S03、大脑、后续Skill |
| `Conflict` | 冲突对象 | S03 | DecisionItemBuilder、S04、S10 |
| `DecisionItem` | 待决事项 | DecisionItemBuilder | S04、S05 |
| `Option` | 候选方案 | S05 | S06、DecisionSelector |
| `RiskAssessment` | 方案风险评估 | S06 | DecisionSelector、S07 |
| `FinalDecision` | 总控最终决策 | Agent-1 DecisionSelector | S07、日志、历史 |
| `Task` | 标准任务 | S07 | 调度层、执行层、S08、S10 |
| `ExecutionResult` | 执行结果 | 执行层 | S08、日志、历史 |
| `ValidationResult` | 验证结果 | S08 | Agent-1、S09、S10 |
| `LearningItem` | 学习经验 | S09 | 记忆层、知识治理、S02 |
| `StrategyChain` | 策略链 | 决策/任务/历史聚合 | S10、S02、S07 |

## 对象主键约定
- Event：`event_id`
- ContextPackage：`context_package_id`（后续实现时新增）
- Conflict：`conflict_id`
- DecisionItem：`decision_item_id`
- Option：`option_id`
- RiskAssessment：使用 `option_id + risk_assessment_id`（后续实现可加独立ID）
- FinalDecision：`decision_id`
- Task：`task_id`
- ExecutionResult：`execution_result_id`（后续执行层标准化）
- ValidationResult：`validation_id`（S08现阶段以task_id为主，后续建议补）
- LearningItem：`learning_id`
- StrategyChain：`strategy_chain_id`

## 单一事实源原则
### ContextPackage
S02 的 `context_package` 是当前决策上下文的唯一事实源。
`current_goals`、`active_tasks`、`agent_analyses` 等如单独传递，只能作为从 ContextPackage 派生的 convenience view，必须保留源引用，不得与 ContextPackage 出现另一套值。

### FinalDecision
S06之后必须先形成 FinalDecision，再进入S07。S07不得自己选择方案。

### Task
任务生命周期以S07当前Task模型为主；外层旧任务生命周期规范后续向S07对齐。

### ExecutionResult
工具/API返回值不能直接当作业务验证结果。执行层先标准化为ExecutionResult，再由S08验证。

## 对象转换原则
1. 不允许静默重命名造成语义漂移。
2. 转换组件必须记录 `source_refs`。
3. 一个对象升级为下一对象时保留上游主键。
4. 允许追加字段，不允许同名字段改变含义。
5. 业务字段与运行字段分离；run_id/trace_id属于Invocation Envelope，不属于业务对象。

## 当前两个必须建立的转换组件
### DecisionItemBuilder
负责：
`Event + ContextPackage + Conflict → DecisionItem[]`

### DecisionSelector
负责：
`DecisionItem + Options + RiskAssessments + Goals + State + Constraints → FinalDecision`

它们不是新增S11/S12，而是 Agent-1 大脑与运行层之间的标准转换/决策组件。
