# Agent-1 决策日志规范

每次形成正式决策，都必须写入决策日志。

## 必填字段
- decision_id
- created_at
- product_id / ASIN
- 触发事件 event_id
- 参与判断的 Agent
- 关键事实
- 被排除的方案及原因
- 最终决策
- 审批级别
- 下发任务 task_id
- 观察窗口
- 成功标准
- 回滚条件
- 最终结果
- 复盘结论

## 目的
1. 保证每个运营动作可追溯。
2. 解释为什么当时做出该决定。
3. 防止后续 Agent 重复试错。
4. 为策略复盘与规则升级提供训练材料。
5. 区分“决策正确但执行失败”和“决策本身错误”。

## 日志原则
- 不覆盖旧日志，只追加新状态。
- 人工修改决策必须记录修改人、时间与原因。
- 日志中的事实、推断、建议必须明确区分。
