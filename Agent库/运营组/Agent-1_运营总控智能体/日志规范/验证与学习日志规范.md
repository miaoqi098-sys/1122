# Agent-1 验证与学习日志规范

## 1. ValidationResult日志
记录：validation_id、execution_result_id、task_id、decision_id、观察窗口、success criteria、关键指标/证据、归因限制、outcome、是否继续观察、rollback/new diagnosis/new decision建议。

必须区分：执行成功、经营结果成功、证据不足/过早评估。

## 2. LearningRecord日志
记录：learning_id、validation_id、decision/task/execution来源链、fact、interpretation、supported/rejected assumptions、适用scope、经营状态/活动背景、freshness/valid_until、knowledge candidates、memory_writes plan。

## 3. 写入边界
S09只生成LearningRecord与memory_writes plan。没有LearningWriteExecutor真实回执，不得记录长期记忆`written`。

## 4. 失败语义
- Execution failure不得直接形成“策略失败”学习。
- Validation failure应保留执行事实与验证结论的分层。
- 不确定结论必须记录uncertainty和所需后续证据。

## 5. Append-only
ValidationResult或LearningRecord修订必须版本化/追加，不覆盖旧结论；新证据到达时保留旧版本及修订原因。

## 6. 与历史记忆边界
日志记录对象生命周期和审计证据；历史记忆决定哪些内容被长期索引、复用和新鲜度管理。两者引用同一canonical对象，不复制成两套事实。
