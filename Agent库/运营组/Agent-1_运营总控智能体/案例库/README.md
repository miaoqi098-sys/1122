# 案例库

本目录保存 Agent-1 可复用的真实经营案例、实验结果、失败经验和人工纠正记录。

## 案例标准结构
- 背景
- 当时数据
- 经营状态
- 问题或机会
- 主要假设
- 缺失信息
- 候选方案
- 最终决策
- 执行过程
- 实际结果
- 成功/失败原因
- 可复用结论
- 不适用边界
- 关联产品/类目/阶段

## 规划分类
- 广告案例
- 价格与促销案例
- 库存案例
- Listing与转化案例
- 竞品与市场案例
- 评价与消费者体验案例
- 风险与合规案例
- 增长实验案例
- 失败案例
- 人工纠正案例

## 原则
案例不是直接照抄的规则。Agent-1 必须先判断当前场景与历史案例是否具有可比性，再决定是否参考。
