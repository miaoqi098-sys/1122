# Agent-1 目标切换规则

本文件定义产品经营状态、风险和机会发生变化时，Agent-1 如何调整当前主目标、副目标和暂停目标。

## 一、目标切换的基本结构
任何时点，Agent-1 应维护：
- **主目标**：当前最重要、获得最多决策权重的目标。
- **副目标**：需要兼顾但不得破坏主目标的目标。
- **暂停/降级目标**：当前阶段暂时不应主动追求的目标。

Agent-1 不应同时把所有目标都设为最高优先级。

## 二、允许触发目标切换的信号
- 经营状态发生变化。
- 出现新的高等级风险。
- 库存、现金、利润、价格、客户体验等进入预警或止损区间。
- 重要促销、旺季或补货窗口临近。
- 关键经营假设被验证或推翻。
- 竞争环境发生结构性变化。
- 原主目标已经达到阶段性成功标准。
- 原主目标继续执行的边际收益明显下降。

## 三、典型切换场景
### 正常经营 → 合规/账户风险
主目标切换为：风险止损、恢复合规与可售。
增长、广告扩量、促销等目标暂停或降级。

### 正常经营 → 商品不可售
主目标切换为：恢复商品可售与购物车/前台状态。
流量、排名和销售增长不再是第一优先级。

### 增长期 → 库存紧张
主目标切换为：保护库存和单位产出效率。
副目标：保住核心关键词和必要自然资产。
暂停/降级：低价值扩量、深度促销、非核心流量探索。

### 增长期 → 现金紧张
主目标切换为：改善现金贡献和降低低质量投入。
副目标：保留高价值增长资产。
暂停/降级：回收周期长且验证不足的实验。

### 稳定期 → 旺季/活动准备
主目标切换为：库存、价格体系、活动资格和承接能力准备。
副目标：保持核心流量和转化稳定。

### 库存积压 → 清理/退出
主目标可从“增长”切换为“降低库存与现金损失”。
价格体系和单位利润可以在审批后进行战略性让渡，但必须定义损失上限和期限。

### 新品验证成功 → 成长期
主目标从“证明产品是否值得继续投入”切换为“放大已验证增长路径”。
探索预算逐步转向确定性更高的关键词、广告和转化路径。

## 四、切换前必须确认
Agent-1 在修改主目标前应检查：
1. 触发信号是否真实且数据新鲜；
2. 是否只是短期噪声；
3. 当前经营状态是否真的变化；
4. 原主目标是否仍在有效观察窗口；
5. 是否触发绝对硬约束或经营硬约束；
6. 切换是否会造成不可逆影响；
7. 是否需要人工审批。

## 五、切换记录
每次重要目标切换必须记录：
- 产品/ASIN；
- 原主目标；
- 新主目标；
- 触发原因；
- 证据；
- 当前经营状态；
- 被降级/暂停的目标；
- 预计持续时间；
- 恢复条件；
- 是否需要审批。

## 六、恢复机制
目标切换不是永久改变。Agent-1 必须定义恢复条件。

例如：
库存保护模式
→ 补货到仓且可售覆盖恢复到安全区间
→ 重新评估是否恢复增长目标

合规风险模式
→ 风险解除、商品恢复正常且无新增高风险信号
→ 再逐步恢复广告、促销与增长计划

## 七、策略防抖
以下情况不应轻易切换主目标：
- 单日指标波动；
- 数据样本不足；
- 观察窗口尚未结束；
- 没有新的关键证据；
- 仅因某个Agent改变建议但事实未发生变化。

除非触发止损、硬约束或新高风险事件。

## 八、与经营状态识别的关系
`经营状态识别/` 负责告诉 Agent-1“现在是什么状态”；本文件负责决定“在这个状态下应该优先优化什么”。

运行逻辑：
经营状态变化
→ 检查约束
→ 触发目标切换规则
→ 设定主目标/副目标/暂停目标
→ 决策排序
→ 方案生成
→ 执行与验证

## 核心原则
目标切换是为了适应现实变化，而不是追逐短期数据波动。任何切换都必须有证据、有理由、有恢复条件。
