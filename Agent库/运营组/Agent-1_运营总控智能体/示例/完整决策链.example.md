## 1. Event
`event_id = EVT-20260829-0001`

Agent-4发现关键词 `travel mahjong set` 在当前观察窗口61次点击0订单。该输入先作为专业Agent来源Event进入S01，不直接执行“暂停关键词”的来源建议。

## 2. S01 EventValidation
结果：`passed_with_warnings`

保留：scope、source、evidence、occurred_at、confidence。

输出：`normalized_event = EVT-20260829-0001:v1`

## 3. S02 ContextLoading
形成 `ContextPackage = CTX-20260829-0001`，至少装载：
- 当前广告匹配方式与竞价；
- Listing相关性与转化历史；
- 产品利润与广告承受能力；
- 库存覆盖天数；
- 当前是否处于Deal/促销/季节性窗口；
- 同关键词及近义词历史；
- 竞品/市场变化；
- 当前StrategyChain与未结束Task。

## 4. S03 ConflictDetection
发现：
- Agent-4倾向降竞价/暂停；
- 历史数据提示该关键词过去曾产生订单；
- 当前Listing近期刚改图，观察窗口不足。

结果：存在证据时效与策略观察窗口冲突，但不是hard block。

## 5. DecisionItemBuilder
形成：
`decision_item_id = DI-20260829-0001`

问题：是否应立即停止该关键词流量，还是继续观察/收缩匹配/调整竞价？

## 6. S04 DecisionPrioritization
结合目标、利润、库存、观察窗口和活动上下文形成动态business_priority。

注意：不是因为“广告问题”或“利润问题”就使用永久固定优先级链。

## 7. S05 OptionGeneration
生成：
- `OPT-A`：立即暂停关键词；
- `OPT-B`：降低竞价并继续观察；
- `OPT-C`：保留当前竞价，但收缩到更高相关性流量/补充Listing观察；
- `OPT-D`：暂不调整，等待观察窗口结束。

## 8. S06 RiskAssessment
示例：
- OPT-A：`eligible_with_controls`，风险是过早切断历史有效流量；
- OPT-B：`eligible`；
- OPT-C：`eligible_with_controls`；
- OPT-D：`eligible_with_controls`，需设止损点击/花费条件。

## 9. S10 StrategyStabilization
由于Listing修改后的观察窗口尚未结束，且OPT-A可能构成当前StrategyChain的方向反转，触发S10。

S10结果：`hold / merge`，不允许无新证据直接full reversal。

## 10. DecisionSelector
选择OPT-B，并保留未选其他Option原因。

形成：
`decision_id = DEC-20260829-0001`

FinalDecision核心内容：
- selected_option_id = OPT-B
- action direction = 适度降低竞价并延长观察
- success criteria = 转化/ACOS/点击质量达到定义条件
- required_controls = 不扩大预算、保留观察窗口、达到止损条件再升级
- approval = 当前动作若在权限范围内可无需额外审批；具体以权限/风险规则为准
- strategy_chain_id = STR-MAHJONG-ADS-001

## 11. 下一步
FinalDecision交S07形成TaskPlan。DecisionSelector本身不创建真实执行结果。
