# 经营指标库

本目录定义 Agent-1 进行跨领域经营判断时使用的核心指标及其解释关系。

## 指标方向
- 流量：曝光、点击、Sessions、自然/广告流量占比、关键词排名。
- 转化：CTR、CVR、Unit Session Percentage、订单与销量。
- 广告：CPC、ACOS、TACOS、CPA、预算利用率、搜索词表现。
- 利润：毛利率、净利率、贡献利润、盈亏平衡点、可接受获客成本。
- 库存：库存覆盖天数、周转、在途、断货风险、库龄。
- 价格：成交价、List Price、Was Price、Coupon、活动价格、价格历史。
- 体验：Rating、Review、退货率、VOC、QA。
- 市场：BSR、竞品价格、竞品促销、类目需求和季节性。

## 每个指标必须说明
1. 定义。
2. 数据来源。
3. 推荐观察周期。
4. 正常解读方式。
5. 与哪些指标必须联动判断。
6. 哪些情况下不能单独使用。
7. 可能的误判来源。

## 原则
Agent-1 不允许因为单个指标异常直接形成重大决策，必须结合经营状态与相关指标交叉判断。
