# Agent-1 经营指标库

## 模块定位
本目录定义 Agent-1 进行跨领域经营判断时使用的核心指标、计算口径、观察窗口、联动关系、基线与阈值规则。

它不是简单的 KPI 名单，而是经营状态识别和大脑判断的量化底座。

经营指标库主要回答：
1. 这个指标到底代表什么；
2. 数据从哪里来、怎么算；
3. 应该看多长时间；
4. 什么情况下它有意义；
5. 必须和哪些指标一起看；
6. 怎样判断正常、关注、预警和停止区；
7. 它能够支持识别哪些经营状态。

## 指标分域
### 商品与风险
可售状态、购物车、变体异常、合规通知、账户风险等强事实信号。

### 流量
曝光、点击、Sessions、自然/广告流量结构、关键词排名、流量增速。

### 转化
CTR、CVR、Unit Session Percentage、订单、销量、转化变化。

### 广告
CPC、CTR、CVR、ACOS、TACOS、CPA、ROAS、预算利用率、搜索词质量、广告销售占比。

### 利润
毛利、贡献利润、净利润、利润率、盈亏平衡 ACOS、可接受获客成本、现金贡献。

### 库存
可售库存、库存覆盖天数、在途覆盖、补货提前期、断货缺口、周转、库龄。

### 价格
当前成交价、日常价、List Price、Was Price、Coupon、Deal价、有效折扣、价格历史与竞品价差。

### 消费者体验
Rating、Review数量与增速、退货率、VOC、差评主题、QA与售后信号。

### 市场与竞争
BSR、类目需求、季节性、竞品价格、促销、排名、Review、流量与竞争变化。

## 标准指标卡
每个关键指标原则上应包含：
- 指标名称；
- 指标代码；
- 定义；
- 公式或计算口径；
- 单位；
- 数据来源；
- 推荐观察窗口；
- 推荐对比基线；
- 正常解释；
- 必须联动的指标；
- 不能单独使用的场景；
- 常见误判来源；
- 可支持识别的经营状态；
- 数据新鲜度要求；
- 缺失数据处理方式。

## 四级状态区间
对于适合量化的指标，统一支持：
- 正常区；
- 关注区；
- 预警区；
- 停止/禁止区。

但具体数值不得默认全产品统一，应根据：
`产品配置 + 生命周期 + 类目特征 + 季节/活动 + 历史基线 + 当前目标`
动态确定。

## 三类阈值
1. **绝对阈值**：平台规则、利润底线、账户/库存不可突破边界等。
2. **相对阈值**：相对历史基线、前周期或对照组的变化。
3. **组合阈值**：多个指标同时满足才触发状态。

## 运行关系
```text
原始数据
↓
指标计算与标准化
↓
基线/阈值判断
↓
指标信号
↓
经营状态识别
↓
目标系统调整
↓
大脑解释和决策
```

## 核心原则
1. 单指标变化首先是“信号”，不是经营结论。
2. 指标解释必须带时间窗口和经营状态。
3. 活动期、测试期与正常期不得机械混用基线。
4. 平均值不能掩盖结构性问题，应允许拆分到 ASIN、变体、关键词、广告活动、流量来源等层级。
5. 趋势、绝对值和变化速度要分开看。
6. 指标阈值要有版本和适用范围，不能靠模型临时猜。
7. 数据缺失、延迟或口径冲突必须降低证据等级。
8. 重大决策必须进行跨域指标验证。
