# 价格指标

## 1. 当前成交价
- 指标代码：current_transaction_price
- 定义：消费者当前实际可购买价格，需考虑Coupon等可见优惠后的有效价格。
- 数据来源：前台、Seller Central、价格接口。
- 推荐窗口：实时 + 历史日级记录。
- 联动：CVR、利润、Buy Box、活动资格、竞品价格。

## 2. 日常价
- 指标代码：regular_price
- 定义：非短期活动状态下的主要常规成交价格。
- 用途：作为活动、折扣和价格恢复的重要基线。

## 3. List Price
- 指标代码：list_price
- 定义：平台展示或后台维护的标价字段，具体含义以平台当前规则为准。
- 联动：参考价展示、促销、价格历史。
- 注意：不得假设填写List Price就必然形成前台划线价。

## 4. Was Price / 参考价信号
- 指标代码：reference_price_signal
- 定义：前台或平台形成的历史参考价相关状态。
- 数据来源：当前前台与后台可验证信息。
- 注意：形成机制可能受平台规则和成交历史影响，规则类判断需核实最新官方信息。

## 5. Coupon有效折扣
- 指标代码：coupon_effective_discount
- 定义：Coupon相对于当前适用价格形成的实际优惠程度。
- 联动：成交价、CVR、利润、促销资格。

## 6. Deal价格
- 指标代码：deal_price
- 定义：BD、LD、Prime Deal等活动期间消费者适用价格。
- 联动：历史最低价、活动资格、利润、库存。

## 7. 有效成交价
- 指标代码：effective_selling_price
- 定义：综合标价、Coupon、Deal、站外折扣等后实际影响消费者支付和利润的价格。
- 用途：比单纯看后台Sale Price更接近真实经营判断。

## 8. 折扣深度
- 指标代码：discount_depth
- 公式：1 - 有效成交价 / 对应有效基线价。
- 必须明确基线是日常价、参考价还是活动规则要求价格。

## 9. 价格历史
- 指标代码：price_history
- 定义：按日或更细粒度保存的主要成交价格、Coupon和Deal变化。
- 用途：参考价保护、活动资格、价格恢复和转化分析。

## 10. 竞品价差
- 指标代码：competitor_price_gap
- 定义：自身有效成交价与主要竞品可比价格之间的差异。
- 联动：产品差异化、Rating、配件、规格、品牌力、CVR。
- 误判：价格高于竞品不自动等于“必须降价”。

## 11. 价格弹性信号
- 指标代码：price_elasticity_signal
- 定义：价格变化与Sessions、CVR、销量、利润变化之间的关系。
- 说明：需要足够样本和相对干净的观察条件，不应从一次降价直接推断真实弹性。

## 12. 价格保护状态
- 指标代码：price_protection_status
- 记录：保护对象、原因、起止条件、禁止动作、允许动作。
- 状态映射：C6价格保护期。

## 核心诊断关系
```text
降价 + CVR提升 + 利润提升 → 可能是有效价格优化
降价 + CVR提升 + 利润下降 → 检查是否过度让利
降价 + CVR无改善 → 问题可能不在价格
活动后参考价异常 → 检查价格历史与平台参考价状态
竞品降价 → 先看相对价值与竞争影响，不机械跟价
```

## 核心原则
价格不是单独的转化按钮。Agent-1必须同时保护利润、活动资格、参考价体系和长期定价空间。
