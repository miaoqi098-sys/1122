# 流量指标

## 1. 曝光量
- 指标代码：traffic_impressions
- 定义：Listing或广告在对应范围内被展示的次数。
- 数据来源：Amazon Ads、Brand Analytics、Search Query Performance等可用数据源。
- 推荐窗口：7/14/30天，异常时可看3天。
- 联动：点击、CTR、Sessions、关键词排名、广告预算。
- 不能单独判断：曝光增长不代表有效流量增长。
- 状态映射：O1关键词流量机会、R4竞争加剧、R6异常待诊断。

## 2. 点击量
- 指标代码：traffic_clicks
- 定义：对应流量入口产生的点击次数。
- 推荐窗口：7/14/30天。
- 联动：曝光、CTR、CPC、CVR、订单。
- 误判：高点击可能来自低意图流量。

## 3. Sessions
- 指标代码：sessions
- 定义：Listing访问会话量，以Amazon业务报表口径为准。
- 推荐窗口：7/14/30天；季节产品增加同比。
- 联动：订单、CVR、广告流量、自然排名、促销。
- 不能单独判断：Sessions下降不一定是需求下降，也可能是广告收缩、库存、Buy Box或活动结束。

## 4. 流量增速
- 指标代码：traffic_growth_rate
- 公式：当前窗口流量 / 对比基线 - 1。
- 推荐基线：前周期、滚动30天、同比、活动前。
- 联动：订单增速、CVR、利润、库存。
- 状态映射：L2成长期、L4衰退调整、O2需求机会。

## 5. 自然流量占比
- 指标代码：organic_traffic_share
- 定义：自然来源流量占总流量的比例；具体计算依赖可获得的数据源。
- 联动：广告销售占比、关键词排名、TACOS、总销量。
- 说明：数据源若无法完整拆分自然与广告，应标记估算性质。

## 6. 广告流量占比
- 指标代码：paid_traffic_share
- 定义：广告来源流量占总流量的比例。
- 联动：广告销售依赖度、TACOS、自然流量、广告预算。
- 误判：占比高不一定坏，新品冷启动可能合理；成熟期长期高度依赖则需要关注。

## 7. 关键词自然排名
- 指标代码：organic_keyword_rank
- 定义：目标关键词下ASIN的自然搜索位置。
- 数据来源：可靠关键词数据源或可验证搜索数据。
- 推荐窗口：日级采样 + 7/14/30天趋势。
- 联动：关键词搜索量、广告投放、CVR、销量、活动。
- 误判：单次排名截图噪声大，应看趋势和数据来源一致性。

## 8. 搜索曝光份额/展示份额
- 指标代码：search_impression_share
- 定义：在可获得的数据体系中，自身对目标搜索需求的曝光占比。
- 联动：排名、点击份额、转化份额、广告位置、竞争强度。
- 状态映射：O1关键词机会、R4竞争变化。

## 9. 流量结构集中度
- 指标代码：traffic_concentration
- 定义：流量是否过度依赖少量关键词、广告活动或单一来源。
- 解释：集中度过高可能形成脆弱性，但核心词集中也可能是类目结构本身。
- 联动：自然关键词数量、广告搜索词、渠道结构。

## 核心判断链
```text
曝光 → 点击 → Sessions → 订单
         ↓
      流量质量
```

流量问题不能只问“流量多不多”，还要问“从哪里来、意图是否匹配、能否转化、是否可持续、是否值得付出成本”。
