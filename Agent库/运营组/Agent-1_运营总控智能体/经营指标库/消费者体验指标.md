# 消费者体验指标

## 1. Rating
- 指标代码：rating
- 定义：商品当前公开评分。
- 推荐窗口：当前值 + 7/30/90天变化。
- 联动：Review增速、差评主题、退货率、CVR。
- 误判：单次评分波动受Review数量影响很大，应结合基数。

## 2. Review数量
- 指标代码：review_count
- 定义：当前Review总量。
- 联动：Rating、Review增速、竞品Review结构、生命周期。
- 说明：数量本身不代表体验质量。

## 3. Review增速
- 指标代码：review_growth_rate
- 定义：指定窗口内Review净新增速度。
- 用途：观察口碑积累、竞争变化和新品成长。

## 4. 低星Review占比
- 指标代码：low_star_review_share
- 定义：低星Review在可获得Review样本中的占比。
- 联动：差评主题、退货率、产品版本。
- 数据限制：若无法获得完整样本，应标记估算。

## 5. 差评主题集中度
- 指标代码：negative_review_theme_concentration
- 定义：负面反馈是否集中指向少数可识别问题，例如尺寸、质量、使用难度、说明书、包装。
- 用途：判断是否存在可修复的产品或内容问题。

## 6. 退货率
- 指标代码：return_rate
- 定义：退货件数 / 对应销售件数，按可获得官方口径计算。
- 联动：退货原因、Rating、利润侵蚀、变体、批次。
- 误判：类目正常退货水平差异很大，需使用自身历史和类目背景。

## 7. 退款率
- 指标代码：refund_rate
- 定义：退款订单或金额占对应销售的比例，需明确口径。
- 联动：退货、售后、利润。

## 8. VOC问题强度
- 指标代码：voc_issue_strength
- 定义：Voice of the Customer中的负面体验问题强度和趋势。
- 状态：稳定 / 关注 / 预警 / 严重，根据官方与内部规则判断。
- 联动：退货原因、Review、产品质量、Listing表达。

## 9. QA问题密度
- 指标代码：qa_issue_density
- 定义：消费者反复询问同一功能、尺寸、兼容、使用方式等问题的程度。
- 用途：识别页面信息缺口和购买阻力。

## 10. 售后问题率
- 指标代码：support_issue_rate
- 定义：可归属到产品的售后问题量 / 对应订单量。
- 联动：问题类型、退款、Review、批次。

## 11. 体验利润侵蚀
- 指标代码：cx_profit_erosion
- 定义：退货、退款、补发、不可售损耗等消费者体验问题造成的利润损失。
- 用途：把“体验差”连接到真实经营结果。

## 12. 变体体验差异
- 指标代码：variation_experience_gap
- 定义：不同颜色、款式、规格之间Rating、退货或差评主题的差异。
- 用途：判断销量失衡是否与体验差异有关。

## 核心诊断关系
```text
Rating下降 + 退货上升 + 同主题差评集中 → 高概率真实产品/体验问题
Rating下降但退货稳定、样本极少 → 先判断样本噪声
CVR下降 + Rating下降 → 体验可能开始影响转化
销量上涨 + 售后问题率上升 → 检查增长是否放大质量问题
```

## 核心原则
消费者体验指标既影响转化，也影响利润、合规和长期品牌资产。Agent-1不能只把差评当作“页面文案问题”，必须区分产品真实缺陷、使用预期错配和信息表达不足。
