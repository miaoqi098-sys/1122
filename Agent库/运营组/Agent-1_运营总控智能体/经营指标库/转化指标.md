# 转化指标

## 1. CTR
- 指标代码：click_through_rate
- 定义：点击量 / 曝光量。
- 单位：百分比。
- 推荐窗口：7/14/30天；高流量场景可缩短。
- 联动：主图、标题、价格、Rating、广告位置、关键词意图。
- 不能单独使用：CTR高不代表转化高，可能只是吸引了错误流量。
- 状态映射：O4内容与转化机会、R6异常待诊断。

## 2. CVR
- 指标代码：conversion_rate
- 定义：订单或购买行为 / 对应访问或点击；必须明确使用广告CVR还是Listing整体CVR。
- 推荐窗口：7/14/30天，并根据样本量调整。
- 联动：价格、Coupon、Rating、Review、流量来源、关键词意图、库存、配送。
- 误判：活动期CVR不能直接作为正常期基线。

## 3. Unit Session Percentage
- 指标代码：unit_session_percentage
- 定义：Amazon业务报表口径下的单位会话转化指标。
- 数据来源：Business Reports等官方数据。
- 推荐窗口：7/14/30天。
- 联动：Sessions、Units Ordered、价格、促销、Buy Box。

## 4. 订单量
- 指标代码：orders
- 定义：对应层级与窗口内的订单数量。
- 联动：Sessions、CVR、ASP/成交价、广告销售、自然销售。
- 不能单独判断：订单上涨可能由深折扣、广告烧钱或季节需求带来。

## 5. 销量 Units
- 指标代码：units_ordered
- 定义：售出件数。
- 联动：订单、变体结构、库存消耗、利润。
- 注意：多件订单会导致Units与Orders不一致。

## 6. 转化变化率
- 指标代码：conversion_change_rate
- 公式：当前CVR / 基线CVR - 1。
- 基线：前周期、滚动30天、活动前、测试前或同比。
- 状态映射：R6异常待诊断、O4内容转化机会。

## 7. 广告点击到订单转化率
- 指标代码：ad_click_to_order_rate
- 定义：广告订单 / 广告点击。
- 联动：Search Term相关性、CPC、ACOS、广告位置、Listing整体CVR。
- 用途：区分广告流量质量与页面整体转化问题。

## 8. 流量到订单效率
- 指标代码：session_to_order_efficiency
- 定义：以Sessions为分母观察订单产出效率。
- 用途：与流量变化联动判断“订单下降来自流量还是转化”。

## 9. 变体转化差异
- 指标代码：variation_conversion_gap
- 定义：不同子ASIN之间CVR或Unit Session Percentage差异。
- 联动：价格、Review共享、图片、颜色/款式需求、库存。
- 状态映射：O4内容/变体机会、R6异常。

## 核心诊断链
```text
曝光不足 → 流量问题
曝光正常但点击不足 → 点击吸引力/相关性问题
点击正常但订单不足 → 转化/流量质量问题
CVR正常但销量下降 → 优先检查流量
流量正常但订单下降 → 优先检查CVR、价格、Buy Box、体验与商品状态
```

## 核心原则
转化率不是单纯的Listing质量分数。它是流量意图、页面表达、价格、信任、配送、促销和经营状态共同作用的结果。
