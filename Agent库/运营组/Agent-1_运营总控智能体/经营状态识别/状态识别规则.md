# 经营状态识别规则

## 目的
定义 Agent-1 如何从数据、事件、历史和专业 Agent 结论中识别经营状态。本文件定义判断逻辑，不在此硬编码所有具体业务阈值。

## 一、状态识别输入
状态识别可使用：
- 商品前后台状态；
- 上架和历史经营时间；
- Sessions、曝光、点击、订单、CVR等流量转化数据；
- 广告数据和搜索词数据；
- 自然关键词排名与流量结构；
- 当前价格、价格历史、Coupon和Deal；
- 单位利润、总利润、广告成本和现金相关指标；
- FBA库存、在途、补货周期和销售速度；
- Review、Rating、退货和VOC；
- 竞品价格、排名、促销、Review和页面变化；
- 合规、绩效、资质和平台通知；
- 当前活动、实验和任务记录；
- 历史决策、观察窗口和结果。

## 二、识别顺序
### 第一步：检查高优先级风险
优先识别：
1. 合规与账户风险；
2. 商品不可售或重大商品状态风险；
3. 断货与严重库存风险；
4. 现金和利润底线风险。

高优先级风险不阻止其他状态继续识别，但会影响最终优先级。

### 第二步：识别生命周期
结合产品历史、订单稳定性、流量结构、关键词资产、Review基础、增长趋势和经营模型判断，不使用单一“上架天数”。

### 第三步：识别经营情境
检查是否处于测试、活动准备、活动进行、活动恢复、价格保护或正常经营。

### 第四步：识别其他风险
检查竞争、利润、库存、商品状态和异常待诊断等状态。

### 第五步：识别机会
检查关键词、需求、竞争空档、内容转化和新增长机会。

## 三、状态证据要求
每个被识别的状态至少记录：
- 状态代码与名称；
- 触发事实；
- 关键指标；
- 数据时间范围；
- 证据来源；
- 当前严重程度或强度；
- 置信度：低 / 中 / 高；
- 是否需要补信息；
- 预计复核时间。

## 四、禁止单指标定性
除明确的平台状态事实外，复杂经营状态原则上不能只由一个指标触发。

例如：
- ACOS升高不能单独认定利润风险；
- 销量增长不能单独认定成长期；
- 竞品一次降价不能单独认定竞争加剧；
- 7天销量下降不能单独认定衰退期；
- 点击无订单不能单独认定关键词无价值。

## 五、生命周期识别原则
### 新品冷启动
重点判断是否仍处于“建立有效经营模型”的阶段，包括：
- 稳定订单是否尚未形成；
- 核心流量入口是否仍在探索；
- 关键词资产是否尚未建立；
- 转化和价格定位是否仍在验证；
- Review和信任基础是否仍明显不足。

### 成长期
重点判断：
- 是否已有基本稳定转化；
- 自然或广告流量是否存在持续扩张；
- 核心关键词资产是否改善；
- 增长是否具有一定质量；
- 库存、利润和供应链是否能够承接增长。

### 成熟稳定期
重点判断：
- 销量和流量结构是否相对稳定；
- 主要关键词与转化模型是否成熟；
- 经营重点是否从验证转向效率、利润和防守。

### 衰退/调整期
需要持续性证据，不因短期波动触发。重点判断需求、竞争力、流量、利润和产品价值是否出现结构性弱化。

## 六、测试状态识别
只有满足以下基本条件的行动才应正式标记为“测试”：
- 有明确测试假设；
- 有测试对象和主要变量；
- 有开始时间；
- 有观察窗口；
- 有成功标准；
- 有止损或停止条件。

没有这些条件的频繁修改不能被包装成测试。

## 七、活动状态识别
活动应区分：
- 准备期；
- 进行期；
- 恢复期。

活动结束不等于立即恢复正常经营。只有当关键指标和价格、流量等活动影响已经消退，或达到预设恢复条件，才能退出恢复期。

## 八、风险状态识别
风险应同时判断：
- 发生概率；
- 影响范围；
- 距离风险真正发生的时间；
- 是否可逆；
- 是否存在替代方案。

风险状态应尽可能分级，而不是只有“有/没有”。

## 九、机会状态识别
机会必须同时回答：
- 机会来自什么证据；
- 可利用窗口预计多长；
- 需要什么资源；
- 与当前风险是否冲突；
- 如果不行动可能损失什么；
- 是否值得进入候选方案。

机会存在不代表必须立即执行。

## 十、异常待诊断
当重要指标或经营结果发生明显异常，但当前证据不足以确认根因时，进入 R6 异常待诊断。

此时应：
1. 记录异常现象；
2. 匹配经营知识库中的异常诊断卡；
3. 调用相关专业 Agent；
4. 生成主要假设；
5. 获取区分假设的关键证据；
6. 原因确认后退出或转换为更具体的风险/机会状态。

## 十一、阈值原则
具体数值阈值原则上不长期硬编码在本文件。

例如库存天数、利润警戒线、CVR异常幅度、竞争变化幅度等，应由：
`经营指标库 + 产品配置 + 生命周期/季节参数`
共同提供。

状态识别规则负责说明“哪些证据组合意味着什么”，指标库负责说明“数据如何定义和计算”。
