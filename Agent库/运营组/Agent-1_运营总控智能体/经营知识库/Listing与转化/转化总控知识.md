# Listing与转化总控知识

## 核心定位
转化率是流量质量、价格、页面表达、评价、竞争环境、配送体验和产品匹配度共同作用的结果。Agent-1 不应把转化问题自动归因于 Listing，也不能只通过降价解决。

## 转化异常主要诊断方向
- 流量是否精准；
- 搜索词意图与产品是否匹配；
- 主图是否传达核心价值；
- 标题与卖点是否回答购买问题；
- A+、视频和图片是否降低理解成本；
- 价格与竞品是否匹配；
- Coupon/促销是否变化；
- Rating与Review是否变化；
- 是否出现差评或VOC集中问题；
- 配送时效、库存、购物车是否异常；
- 竞品是否推出更强产品或促销；
- 流量来源结构是否发生变化。

## 基本原则
1. CVR下降先拆流量结构，再判断页面。
2. 广告CVR和整体CVR应分开观察。
3. 新流量扩张可能暂时拉低整体CVR，不代表策略必然失败。
4. Listing优化应有明确假设，例如“用户无法理解计数功能”，而不是无目的频繁换图。
5. 页面大改应避免与价格、广告、促销同时大幅变化，否则难以归因。
6. 转化测试必须设置观察窗口并记录版本。

## 内容优化优先级思路
优先解决影响购买决策最大的阻碍：
产品理解错误 → 核心差异化不清 → 信任不足 → 使用场景不清 → 规格信息缺失 → 视觉表现弱。
