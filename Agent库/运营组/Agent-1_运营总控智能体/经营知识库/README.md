# 经营知识库

本目录保存 Agent-1 作为运营总控必须掌握的“总控型经营知识”。

## 定位
Agent-1 不复制 Agent-2 至 Agent-13 的全部专业知识，而是掌握足以理解各专业 Agent 报告、识别冲突并进行经营取舍的跨领域知识。

经营知识库回答的是：面对一个真实经营问题，Agent-1 应该从哪些维度理解、哪些因素不能遗漏、哪些常见结论可能是误判、什么时候必须请求其他 Agent 补充证据。

## 当前已建立的第一层知识
- `总控经营原则.md`：整体最优、硬约束、跨指标验证、可逆测试、活动期隔离、策略防抖和闭环原则。
- `产品生命周期/生命周期总则.md`：新品、成长、稳定、衰退/调整阶段的目标差异。
- `广告经营/广告总控知识.md`：广告与利润、自然流量、关键词资产、库存和转化的联动判断。
- `价格体系/价格总控知识.md`：价格、利润、参考价、促销、转化与库存之间的联动。
- `库存经营/库存总控知识.md`：库存覆盖、在途、补货、放量、积压和断货风险。
- `利润经营/利润总控知识.md`：真实利润、获客成本、计划性利润让渡和止损。
- `Listing与转化/转化总控知识.md`：流量质量、页面、价格、评价、竞品与转化的联合诊断。
- `评价与消费者体验/消费者体验总控知识.md`：Review、Rating、VOC、退货与产品体验信号。
- `竞品与市场/竞争与市场总控知识.md`：竞争动作、市场趋势、季节性和机会判断。
- `风险与合规/风险合规总控知识.md`：账户、商品可售、政策与高风险动作的总控边界。

## 知识内容标准
后续每个知识主题尽量包含：
1. 核心概念/经营定位；
2. 适用场景；
3. 关键判断维度；
4. 常见误判；
5. 关联指标；
6. 关联Agent；
7. 可采取的策略方向；
8. 边界与例外；
9. 真实案例（成熟后链接到案例库）。

## 使用原则
- 本知识库提供“如何理解经营问题”的知识，不直接替代实时数据。
- 涉及平台规则、资格、费用和政策等会变化的信息，应通过最新数据/官方规则/专业 Agent 验证。
- 数值阈值尽量不硬编码在知识文档，统一进入经营指标库和配置层管理。
- 产品特有经验进入长期记忆或案例库，不把单一产品经验误写成全局规则。
