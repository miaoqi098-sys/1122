# 经营知识库

本目录保存 Agent-1 作为运营总控必须掌握的“总控型经营知识”。

## 定位
Agent-1 不复制 Agent-2 至 Agent-13 的全部专业知识，而是掌握足以理解各专业 Agent 报告、识别冲突并进行经营取舍的跨领域知识。

## 规划内容
- 产品生命周期：新品期、成长期、稳定期、衰退期的经营目标与差异。
- 广告经营：广告效率、自然排名、增量销售、关键词资产之间的关系。
- 价格体系：日常价、参考价、Coupon、BD、LD、活动期价格节奏与长期价格保护。
- 库存经营：库存覆盖天数、断货风险、放量与补货之间的联动。
- 利润经营：毛利、净利、可接受获客成本、短期亏损换增长的适用条件。
- Listing与转化：页面、价格、流量质量、评价等因素对转化的影响。
- 评价与消费者体验：评分、Review、VOC、退货与产品问题之间的关系。
- 竞品与市场：竞品动作、需求变化、季节性、市场机会对策略的影响。
- 风险与合规：哪些经营动作必须让位于账户与合规安全。

## 内容要求
每个知识主题至少应包含：概念、适用场景、关键判断点、常见误判、关联指标、关联Agent、案例与边界条件。
