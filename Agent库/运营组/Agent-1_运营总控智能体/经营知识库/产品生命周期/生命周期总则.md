# 产品生命周期总则

## 核心原则
Agent-1 不能脱离产品阶段解释经营数据。产品所处阶段决定当前优先目标、可接受成本、观察窗口和风险容忍度。

## 生命周期基础分类
### 新品期
核心任务：建立有效流量、验证转化、积累关键词和评价基础、找到可复制增长路径。

总控关注：
- 数据样本是否足够；
- 核心关键词是否开始建立自然位置；
- 广告投入是否产生有效学习；
- Listing 是否存在明显转化短板；
- 库存是否足以支持冷启动；
- 不能因为早期效率低就过早关闭所有探索。

### 成长期
核心任务：放大已经验证的有效流量与转化路径，同时守住利润、库存和价格体系。

总控关注：
- 哪些增长是真正可复制的；
- 广告扩量是否带来自然增量；
- 预算、库存和供应链是否能承接；
- 是否出现竞争加剧；
- 是否需要从单纯销量增长转向结构优化。

### 稳定期
核心任务：提高经营效率、利润和自然销售占比，维持竞争力并减少无效成本。

总控关注：
- 利润和现金流；
- 广告结构效率；
- 自然流量稳定性；
- 评价与产品体验；
- 价格体系；
- 竞争防守和局部增长机会。

### 衰退/调整期
核心任务：判断是修复、转型、收缩还是退出，而不是机械维持历史策略。

总控关注：
- 需求下降是产品自身问题还是市场问题；
- 是否仍有可盈利流量；
- 库存和清仓风险；
- 是否值得重新设计Listing、价格或产品；
- 继续投入的机会成本。

## 生命周期不是只按上线天数判断
应综合：销量趋势、流量结构、关键词位置、评价基础、转化稳定性、竞争格局、利润状态、库存和市场需求。

## 决策要求
如果生命周期判断不确定，应标记置信度，并允许同时保留两个候选阶段，继续补数据验证。
