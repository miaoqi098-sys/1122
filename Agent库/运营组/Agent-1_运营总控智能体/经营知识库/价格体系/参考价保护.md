# 参考价保护

## 核心定位
参考价、划线价和促销展示属于价格体系的一部分。Agent-1关注的不是“永远维持高参考价”，而是避免短期价格动作破坏未来价格空间和消费者价格预期。

## 决策前必须确认
- 当前平台展示的参考价/划线价状态；
- 最近一段时间真实成交价格分布；
- Coupon、BD、LD、Prime等活动记录；
- 站外折扣或其他可能影响成交价的动作；
- 当前正常售价目标；
- 未来计划中的促销窗口；
- 当前利润与库存压力。

## 基本原则
1. 不为了短期转化长期依赖深折扣。
2. 价格动作必须考虑未来促销资格和参考价展示空间。
3. 平台参考价规则会变化，不能仅依赖历史经验或旧规则。
4. 需要依赖平台规则的判断，应调用最新官方信息或由Agent-10/Agent-12提供当前依据。
5. 参考价保护不能凌驾于严重库存积压、现金流或合规风险之上。

## 常见误判
- 只要提高List Price就能恢复划线价；
- 某次高价出几单，就一定能长期形成参考价；
- Coupon不影响消费者实际成交价判断；
- 站外折扣与站内参考价完全无关；
- 为了保护参考价，应拒绝所有必要促销。

## 可能策略方向
- 保持稳定正常价并减少频繁价格跳动；
- 将促销集中在明确活动窗口；
- 避免多个深折扣渠道叠加；
- 在不确定平台机制时先查证再行动；
- 对需要清库存的产品重新评估“价格体系保护”权重。

## Agent协作
主要：Agent-10促销价格智能体。
联动：Agent-6利润、Agent-7库存、Agent-12规则/合规，必要时Agent-5观察价格变化后的流量与转化。
