# 利润总控知识

## 核心定位
Agent-1 不追求每一单利润最大，而是确保增长投入、价格策略和库存策略在可接受的利润与现金流约束内运行。

## 利润分析不能只看毛利率
应区分并联动：
- 售价；
- 产品成本；
- 头程/物流；
- FBA费用；
- 佣金；
- 广告成本；
- Coupon与促销成本；
- 退款退货；
- 仓储成本；
- 其他可归因成本；
- 单位贡献利润；
- 总利润；
- 现金流。

## 基本原则
1. 高毛利率不等于高总利润。
2. 高销量不等于高利润。
3. 广告可接受成本必须结合产品阶段和增长目标。
4. 短期低利润甚至计划性亏损只能用于有明确战略价值、期限、预算上限和验证标准的场景。
5. 任何“先亏钱把排名打起来”的策略都必须回答：排名提升后如何收回投入？失败时何时止损？
6. 促销必须计算真实成本，而不是只看折扣后的销量提升。

## 可接受短期利润让渡的典型条件
可能包括：
- 新品验证关键关键词；
- 明确可提升自然排名的核心词；
- 有时间边界的重要活动窗口；
- 高复购/高长期价值产品；
- 清理库存避免更大损失；
- 战略性市场进入测试。

但必须同时具备：预算上限、观察窗口、成功标准、失败止损和回收路径。

## 利润恶化诊断顺序
不要只归因广告。检查：
- 售价/折扣变化；
- CPC与广告结构；
- 转化率；
- FBA/物流费用；
- 退款率；
- 产品成本；
- 促销成本；
- 销售结构变化；
- 库存相关费用。
