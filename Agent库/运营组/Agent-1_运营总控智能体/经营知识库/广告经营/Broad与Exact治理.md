# Broad与Exact治理

## 核心定位
Broad用于发现和扩展搜索需求，Exact用于更可控地承接已经验证的高价值搜索词。Agent-1关注的是两者在整体增长中的分工，而不是机械认为Exact一定优于Broad。

## Broad主要价值
- 发现新搜索词；
- 扩展长尾与场景需求；
- 获取市场语言变化；
- 帮助新品探索潜在转化路径。

## Broad主要风险
- 流量分散；
- 意图不稳定；
- 搜索词质量差异大；
- 容易与已有广告重复竞争；
- 难以直接控制每个搜索词成本。

## Exact主要价值
- 精准承接已验证关键词；
- 更容易单独管理竞价、预算和表现；
- 适合核心词、转化词和战略词长期运营。

## 治理逻辑
1. Broad负责发现，不应无限扩大未经验证流量。
2. 当搜索词达到足够价值证据时，应考虑迁移或补充Exact承接。
3. 是否在Broad中否定已转Exact搜索词，应根据是否需要流量隔离、竞价控制和数据清晰度决定，而不是绝对规则。
4. Exact表现差不代表搜索词没有价值，需要判断竞价、广告位、Listing、价格与匹配流量差异。
5. 同一关键词不同匹配方式必须分别看真实转化，不用Broad表现推断Exact表现，反之亦然。

## Agent-1重点判断
- 当前广告目标是探索还是效率；
- Broad是否持续发现新价值搜索词；
- 是否存在大量重复或内耗；
- 高价值词是否已获得独立控制；
- 是否存在61点击0单这类需要继续诊断而非直接定性的搜索词；
- 自然排名、利润、库存是否支持继续投入。

## 常见策略方向
- 保留Broad探索；
- Broad降价继续观察；
- 提取搜索词建立Exact；
- Broad中否定已明确隔离的Exact词；
- 暂停持续低价值Broad目标；
- 对战略关键词同时保留探索与精准承接，但控制重复竞争。
