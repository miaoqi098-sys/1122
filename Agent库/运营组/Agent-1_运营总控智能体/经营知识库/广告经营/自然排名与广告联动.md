# 自然排名与广告联动

## 核心定位
广告不仅可能产生直接订单，也可能影响关键词成交密度、流量结构和自然排名表现。Agent-1需要判断广告投入是否形成了长期可保留的自然资产。

## 必须区分
- 广告带来的直接销售；
- 广告帮助发现的搜索词；
- 广告期间自然排名变化；
- 广告减少后自然流量是否保留；
- 广告是否只是替代原本会发生的自然成交。

## 正向联动信号
- 广告转化稳定；
- 核心关键词自然排名持续改善；
- 自然点击/自然销售同步增加；
- TACOS随整体销量增长而改善或稳定；
- 减少部分广告后自然成交仍能维持。

## 弱联动或替代信号
- 广告销售增长，但整体销量增长有限；
- 广告占比持续提高，自然销售没有增长；
- 关键词自然位置长期无改善；
- 增加预算只带来更多广告成交，没有整体增量；
- 广告停止后销量立即等比例消失。

## Agent-1决策原则
1. 对核心战略关键词，不能只看短期ACOS，应同时看自然排名和整体增量。
2. 对长期无自然改善、无利润、无战略价值的词，降低持续投入优先级。
3. 自然排名改善不证明一定由广告造成，应排除价格、促销、评价、季节性等共同因素。
4. 评估广告价值时应看一段时间内的趋势，而不是单日排名。

## 需要Agent协作
- Agent-4：广告表现与搜索词；
- Agent-5：自然排名、自然流量与整体流量结构；
- Agent-6：投入成本和可接受回收周期；
- Agent-9：Listing转化变化；
- Agent-10：价格/促销干扰因素。
