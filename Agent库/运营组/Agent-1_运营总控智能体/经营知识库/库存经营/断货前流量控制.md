# 断货前流量控制

## 核心定位
当库存进入明显风险区间时，Agent-1应从“追求销量”切换为“延长可售时间、保护高价值流量和等待补货”。

## 断货风险判断不能只看可售库存
必须结合：
- 当前日均销量与趋势；
- 广告和促销计划；
- 在途数量；
- 预计到仓时间；
- 入库延误概率；
- 旺季/淡季；
- 是否存在核心关键词排名爬升窗口。

## 优先控制顺序
1. 停止或降速低价值、低转化流量；
2. 减少不必要深折扣；
3. 保留利润较好或战略价值高的核心流量；
4. 重新评估活动报名与放量计划；
5. 必要时通过价格控制销售速度；
6. 同步推进补货和入库异常处理。

## 不应机械执行的动作
- 库存少就关闭全部广告；
- 为了避免断货立刻大幅涨价；
- 把所有Broad都停掉而不保留核心探索；
- 因为有在途就继续按正常速度放量。

## 决策目标
不是“绝对不允许断货”，而是在补货时点、利润、自然排名和库存风险之间找最优解。

## 止损条件
若预计补货无法在安全时间内入库，应进一步收缩；若补货提前确认到仓，可以逐步恢复流量，但仍需避免一次性放量造成二次风险。

## Agent协作
主要：Agent-7库存供应链。
联动：Agent-4广告、Agent-5流量、Agent-6利润、Agent-10价格促销。
