# 异常诊断卡：降价后转化没有提升

## 触发信号
产品降价、增加Coupon或加深促销后，CVR、订单或整体销量没有达到预期改善。

## 不能直接下的结论
- 不能继续无止境降价。
- 不能认定消费者只是不够便宜。
- 不能忽略流量质量、页面表达、评价和产品匹配问题。

## 优先排查顺序
1. 降价幅度是否足以被消费者感知。
2. 价格变化前后流量结构是否可比。
3. 是否引入了更多低意图流量，稀释整体CVR。
4. 主图、标题、卖点是否存在核心理解障碍。
5. Rating、Review、退货、QA是否暴露信任问题。
6. 竞品是否同步做了更强促销或推出更优产品。
7. 配送、库存、购物车是否异常。
8. 当前价格是否已经损害参考价/长期价格体系，却没有换来增量。

## 需要请求的Agent
Agent-10、Agent-9、Agent-5为核心；联动Agent-3、Agent-11、Agent-2、Agent-6。

## 可选动作
- 停止继续降价，转向页面、流量或产品问题诊断。
- 做单变量测试，避免价格和Listing同时大改。
- 若降价无效果且利润受损，恢复价格或减小促销。
- 如果发现流量意图错误，优先治理广告和关键词。

## 成功判断
不是价格越低越好，而是找到能提升单位流量价值和总利润的真实转化杠杆。
