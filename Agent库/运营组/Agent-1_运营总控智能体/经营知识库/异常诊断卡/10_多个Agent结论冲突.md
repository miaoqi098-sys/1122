# 异常诊断卡：多个Agent结论冲突

## 触发信号
不同专业Agent针对同一产品、同一时间窗口或同一策略提出方向相反的建议。

典型例子：
- Agent-4建议广告加预算，但Agent-7提示库存不足。
- Agent-10建议促销降价，但Agent-6提示利润已接近底线。
- Agent-13发现增长机会，但Agent-12提示存在合规风险。

## 不能直接下的结论
- 不能按“多数Agent意见”决定。
- 不能默认某个专业Agent永远优先。
- 不能把冲突简单理解为谁对谁错。

## 冲突识别顺序
1. 是否讨论同一个时间窗口。
2. 是否使用相同的数据口径。
3. 是否针对同一个经营目标。
4. 是否存在信息新旧不一致。
5. 是否有硬约束冲突。
6. 每个建议的预期收益、风险和可逆性分别是什么。

## 总控优先级
默认遵循：账户与合规安全 → 商品可售 → 库存安全 → 现金流与利润底线 → 价格体系 → 转化效率 → 流量规模 → 增长机会。

但最终决策必须结合产品生命周期、活动状态和当前经营目标动态调整。

## Agent-1处理方法
1. 把每个Agent的事实、推断和建议拆开。
2. 标出真正冲突的是事实、目标还是行动方案。
3. 请求缺失数据，统一时间窗口和口径。
4. 生成至少两个可执行折中/替代方案。
5. 比较整体收益、风险、成本、可逆性和长期影响。
6. 若仍无法消除重大不确定性，选择继续观察、小范围测试或人工审批。

## 输出要求
必须明确：冲突来源、各Agent关键依据、被采用和被否决建议、总控权衡理由、最终方案、风险、观察窗口与回滚条件。
