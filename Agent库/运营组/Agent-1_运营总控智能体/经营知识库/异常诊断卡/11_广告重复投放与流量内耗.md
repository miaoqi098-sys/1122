# 异常诊断卡：广告重复投放与流量内耗

## 触发信号
- 同一搜索词同时被多个广告活动、广告组或匹配方式大量承接。
- Broad、Phrase、Exact或商品投放之间出现明显重叠。
- CPC持续上涨但整体流量和销量没有同步增长。
- 单个搜索词数据被拆散，难以判断真实表现。

## 不能直接下的结论
- 不能因为重复覆盖就认定必须全部否定或合并。
- 不能只看某一个广告组表现决定搜索词归属。
- 不能把所有多入口覆盖都视为内耗；部分场景可能承担探索、防守或广告位控制目的。

## 优先排查顺序
1. 搜索词实际由哪些活动、广告组、匹配方式承接。
2. 各入口的CPC、CTR、CVR、订单和广告位。
3. 是否存在明确的探索层、承接层、防守层设计。
4. 重复投放是否造成竞价失控、预算分散或数据碎片化。
5. Exact是否已经具备独立管理价值。
6. 否词是否会误伤仍有探索价值的流量。

## 需要的Agent
Agent-4主分析；Agent-5判断整体流量增量；Agent-6检查成本与利润。

## 可选动作
- 明确Broad探索、Exact承接的职责。
- 对已稳定迁移的搜索词做流量隔离。
- 合并无意义的重复结构。
- 保留有明确不同目的的多入口投放。
- 建立搜索词级统一观察视图。

## 升级条件
如果重复投放导致成本持续上升且无整体增量，提升优化优先级。
