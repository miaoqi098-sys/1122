# 异常诊断卡：促销结束后参考价异常

## 触发信号
促销结束后划线价、参考价、Was Price或前台价格展示出现异常，影响折扣展示或后续促销空间。

## 不能直接下的结论
- 不能凭历史经验断言平台一定会在固定天数恢复。
- 不能为了恢复划线价立即反复调价。
- 不能忽略近期真实成交价格历史。

## 优先排查顺序
1. 当前前台展示和后台价格设置。
2. 最近成交价历史和促销时间线。
3. Coupon、BD、LD、站外折扣等是否重叠。
4. List Price/参考价是否仍有效。
5. 当前促销资格或系统提示。
6. 最新平台规则和价格政策。
7. 是否存在多个变体价格相互影响的情况。

## 需要的Agent
Agent-10主分析；Agent-2确认前后台状态；Agent-12处理规则/资格风险；Agent-6评估价格调整成本。

## 可选动作
- 暂停无目的反复调价。
- 建立价格时间线。
- 获取当前官方规则或后台资格信息。
- 根据长期价格目标制定恢复路径。
- 必要时等待足够正常成交样本再评估。

## 升级条件
参考价异常已经影响重要促销报名、价格合规或大量销售时，提升优先级。
