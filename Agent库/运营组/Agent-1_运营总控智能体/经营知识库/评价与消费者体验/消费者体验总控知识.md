# 评价与消费者体验总控知识

## 核心定位
Review、Rating、退货、VOC和QA不仅是售后数据，也是产品质量、消费者预期、Listing表达和未来转化的重要信号。

## Agent-1关注的问题
- Rating是否出现趋势性下降；
- 差评是否集中在同一问题；
- 退货原因是否与差评一致；
- Listing是否造成错误预期；
- 产品批次/质量是否存在系统性问题；
- 评价变化是否已经影响转化和广告效率；
- QA是否暴露消费者高频疑问；
- 是否存在需要升级到风险合规处理的问题。

## 基本原则
1. 单条差评不等于产品存在系统性问题。
2. 多来源重复出现同一问题时，应提高优先级。
3. 区分产品缺陷、使用误解、物流问题、预期错配和个体偏好。
4. 如果消费者误解来自Listing表达，应优先修正内容而不是只处理售后。
5. 涉及安全、合规、知识产权或平台政策的问题立即升级 Agent-12。
6. 不以违规方式操纵、诱导或交换评价。

## 评价问题的经营影响
可能影响：
- 转化率；
- 广告效率；
- 自然排名；
- 退款成本；
- 品牌信任；
- 产品迭代优先级。

## Agent协作
主要来源：Agent-11 评价体验智能体。
联动 Agent-9 内容转化、Agent-2 商品状态、Agent-6 利润、Agent-12 风险合规，必要时 Agent-13 增长机会用于产品改进机会。
