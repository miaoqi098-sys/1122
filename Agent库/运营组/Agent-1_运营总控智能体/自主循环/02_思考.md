# 自主循环 02｜思考

## 1. 目标
把通过S01的normalized_event置于完整经营上下文中理解，识别冲突、缺口、约束和待决事项，为S04排序准备DecisionItem。

## 2. 正式映射
思考阶段主要对应：
`S02 ContextLoading → ContextPackage → S03 ConflictDetection → DecisionItemBuilder → DecisionItem`

## 3. 动作
1. S02装载当前目标、状态、指标、历史、活动、任务、策略链和专业Agent证据。
2. ContextPackage作为后续唯一权威上下文事实源，不由本阶段临时拼第二套事实表。
3. S03识别事实冲突、目标冲突、约束冲突、Agent结论冲突和缺失证据。
4. 区分事实、解释、假设与待验证内容。
5. DecisionItemBuilder把“需要决定什么、影响什么目标、有哪些约束/依赖”形成canonical DecisionItem。
6. 信息不足时明确request_more_evidence/needs_information，并保留恢复点。

## 4. 输出
- ContextPackage；
- conflict/constraint/evidence gap结果；
- canonical DecisionItem；
- 是否具备进入S04的条件；
- 必要的补证据/协同请求。

## 5. 边界
- 不直接决定业务优先级，优先级由S04动态形成。
- 不直接生成Option或FinalDecision。
- 不把低置信假设写成事实。
- 不绕过ContextPackage直接使用零散历史/专业Agent结果。

## 6. 回路
若补充了关键新证据，只重跑受影响的S02/S03/DecisionItemBuilder阶段；无新证据不得无限“重新思考”。
