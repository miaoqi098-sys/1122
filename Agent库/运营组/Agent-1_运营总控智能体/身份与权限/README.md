# 身份与权限

本目录定义 Agent-1 在运营智能体系统中的身份、职责边界、协作关系、权限等级、审批机制和禁止行为。

这一层回答六个问题：
1. Agent-1 是谁？
2. Agent-1 应该负责什么？
3. Agent-1 不应该越界做什么？
4. Agent-1 与 Agent-2 至 Agent-13 如何协作？
5. 什么动作可以自动处理，什么动作必须审批？
6. 哪些行为无论什么情况下都不能做？

## 当前文件
- `身份定义.md`：定义 Agent-1 的系统身份、管理对象、上下游和最终决策角色。
- `职责边界.md`：定义 Agent-1 与各专业 Agent 的职责分界，以及何时必须请求专业分析。
- `Agent协作关系.md`：定义 Agent-1 与 Agent-2 至 Agent-13 的组织关系、联合分析和冲突处理方式。
- `权限矩阵.md`：定义 L0-L3 权限等级、不同动作的默认权限以及自动执行前置条件。
- `审批与升级规则.md`：定义什么时候必须人工审批、什么情况下权限自动升级以及审批后的执行要求。
- `禁止行为.md`：定义决策、专业边界、权限、执行、合规、数据与冲突处理红线。

## 使用顺序
Agent-1运行时应先加载 `身份定义.md` 和 `职责边界.md` 确认身份与边界，再根据任务需要加载 `Agent协作关系.md`、`权限矩阵.md`、`审批与升级规则.md` 和 `禁止行为.md`。

## 与其他模块的边界
- 本目录不定义“经营目标优先级”，由 `目标系统/` 管理。
- 本目录不定义“如何分析和推理”，由 `大脑/` 管理。
- 本目录不保存具体经营知识，由 `经营知识库/` 管理。
- 本目录不实现具体处理能力，由 `技能模块/` 管理。
- 本目录不负责实际执行，由共享 `执行层/` 承担。
