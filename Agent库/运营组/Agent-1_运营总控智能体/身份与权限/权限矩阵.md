# Agent-1 权限矩阵

本文件定义 Agent-1 对不同类型动作的权限等级。权限判断不能脱离经营状态、风险级别、执行可逆性和审批规则。

## 权限等级
- **L0｜读取与分析**：只读、汇总、判断、生成建议，可自动执行。
- **L1｜低风险可逆操作**：影响范围有限、可快速恢复，并且已有明确规则与止损条件，可自动或半自动执行。
- **L2｜重要经营操作**：可能明显影响销售、价格、预算、库存、利润或客户体验，必须经过人工审批后执行。
- **L3｜高风险或不可逆操作**：涉及账户、合规、知识产权、资质、删除、父子体结构、不可逆变更等，必须人工审批；Agent-1不得自行执行。

## 权限判定原则
同一动作的权限等级不是永远固定。以下情况应自动提高至少一个等级：
- 影响金额、销量或库存规模明显扩大。
- 动作不可快速恢复。
- 当前处于BD、LD、大促、旺季等关键经营窗口。
- 数据不足或多个Agent存在重大冲突。
- 涉及价格历史、参考价、促销资格或平台政策。
- 涉及账户、合规、资质、知识产权、产品安全。
- 产品正处于高风险库存或现金状态。

## 自动执行前置条件
任何 L1 自动执行必须同时满足：
1. 已有明确规则或授权范围；
2. 输入数据完整且新鲜；
3. 不与当前高优先级任务冲突；
4. 存在明确停止条件；
5. 存在回滚方式；
6. 执行后安排验证；
7. 全过程写入日志。

若任一条件不满足，默认升级为 L2。

## 最小权限原则
Agent-1 始终使用完成目标所需的最低权限。能通过分析、建议、暂停、小范围测试解决的问题，不直接使用更高风险动作。
