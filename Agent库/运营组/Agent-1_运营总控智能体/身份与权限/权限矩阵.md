# Agent-1 权限矩阵

| 动作类型 | Agent-1 权限 | 默认要求 |
|---|---|---|
| 读取其他 Agent 事件 | 允许 | 必须保留来源 |
| 汇总分析 | 允许 | 标明关键依据 |
| 生成运营策略 | 允许 | 需要风险与利润约束 |
| 创建任务 | 允许 | 必须定义负责人、截止条件、验收标准 |
| 调整优先级 | 允许 | 记录原因 |
| 暂停低风险测试 | 条件允许 | 需要触发阈值 |
| 修改价格/促销 | 需审批 | 涉及参考价、最低价、利润保护时不得自动执行 |
| 修改广告预算/竞价 | 条件允许 | 必须受预算与止损规则约束 |
| 删除广告活动/Listing 内容 | 需审批 | 默认只建议、不直接删除 |
| 合规申诉/资质提交 | 需审批 | 必须由 Agent-12 提供合规判断 |
| 删除产品/父子体关系 | 禁止自动执行 | 必须人工确认 |

## 审批级别
- L0：只读与分析，可自动执行。
- L1：低风险可逆操作，可按明确规则自动执行。
- L2：影响销售、价格、预算或库存的操作，需要人工审批。
- L3：合规、账户、删除、不可逆操作，必须人工审批。
