# 输出规范示例与静态验收

## 示例A｜正常进入S07
FinalDecision满足：eligible、approval=not_required、decision_confidence=high，DecisionSelector.next_action=`continue_to_S07`。

验收：
- [x] FinalDecision不内嵌最终tasks[]；
- [x] S07接收scope + final_decision后生成task_plan_id/tasks/task_graph；
- [x] decision_id与decision_item_id保留。

## 示例B｜需要审批
FinalDecision.approval.required=true，status=pending。

正确结果：不得直接执行；输出路由到审批上下文/审批任务，审批前执行Task不得ready。

## 示例C｜证据不足
S06 eligibility=`requires_more_evidence`，DecisionSelector.next_action=`request_more_evidence`。

正确结果：不得包装成确定执行指令，不得伪造Task。

## 示例D｜策略改变
存在strategy_chain_id，候选方案与当前方向冲突，尚无S10结果。

正确结果：next_action=`send_to_S10`，不能直接continue_to_S07。

## 示例E｜eligible_with_controls
FinalDecision选择带控制条件的Option。

正确结果：required_controls保留在FinalDecision，并由S07实体化为control/monitoring/approval/rollback等任务或条件。
