# Agent-3｜情报监控范围

## 1. 原则
Agent-3监控的是**具体竞争实体及其竞争相关事实**，不是替代其他Agent做最终策略判断。所有观察必须绑定marketplace、时间、竞品实体和与我方的竞争关系。

## 2. 核心监控域
### 价格与促销事实
- 当前售价、参考价展示、Coupon/Deal、会员价等前台事实；
- 价格变化幅度、持续时间、促销开始/结束；
- 同一竞品不同时间点的变化，而非只保留最新值。

### 搜索与类目可见性
- 目标关键词搜索结果中的自然/广告可见位置；
- 类目榜单、Best Seller/New Release等可观察位置；
- 多次观察后形成的持续上升/下降信号。

搜索位置必须保存关键词、时间、marketplace、设备/页面上下文（如可得）。单次位置变化不得直接解释为稳定趋势。

### Listing与商品呈现
- 标题、主图、图片数量、要点、A+、变体、套装、规格等可观察变化；
- 新增卖点、功能、包装和附件变化；
- 只能记录事实变化，转化价值判断主要交Agent-9。

### 评价展示
- 星级、评论数量、近期明显变化；
- 评论内容深度分析/VOC主题主要交Agent-11；Agent-3仅保留竞争层面的展示和变化事实。

### 新品与竞争动作
- 新ASIN/新父体进入目标关键词、类目或竞品品牌；
- 变体扩展、套装变化、价格带迁移；
- 同一品牌多个实体同步动作。

### 流量与销量代理信号
允许保存公开可观察或合法第三方提供的代理信号，但必须标记source与estimate/proxy属性，不得伪称Amazon官方真实销量或流量。

## 3. 不属于本Agent的主监控域
- 类目长期宏观趋势、季节性：Agent-8；
- 我方流量结构与渠道归因：Agent-5；
- 我方广告投放表现：Agent-4；
- 我方Listing转化：Agent-9；
- 我方价格策略：Agent-10；
- VOC根因：Agent-11。

## 4. 新鲜度
不同事实必须有独立freshness要求。价格/促销/搜索位通常需要更短时间窗，Listing结构和品牌关系可更长。框架不写死具体小时阈值，实际阈值由配置层按数据源和业务场景设置。

## 5. 缺失与冲突
- 无数据 = unknown，不得填充猜测；
- 两个来源冲突时保留双来源、采集时间和可信度；
- 工具失败不得转换成“竞品状态异常”；
- 不可比观察必须标记comparison_eligible=false。
