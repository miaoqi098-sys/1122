# Agent-3｜配置与日志

## 1. 配置职责
本模块定义Agent-3未来运行时需要的配置合同，不实现真实配置服务。

建议配置：
- marketplace范围；
- 我方scope与关键词/类目观察集合；
- 竞品池复核策略；
- 各情报域freshness目标；
- 变化复核次数/窗口；
- 信号severity映射参数；
- 数据源优先级与降级规则；
- 允许的第三方数据源及口径说明。

具体阈值应配置化，不硬编码在规则文档。

## 2. 日志边界
业务日志至少记录：
- competitor_entity_id / relation_id；
- snapshot_id；
- signal/event引用；
- 观察时间和来源；
- 比较基线；
- confidence变化；
- 关系入池/降级/移除原因；
- 请求request_id与输出状态。

运行日志（工具调用、重试、耗时、异常栈）属于未来运行层，不和业务历史混为一体。

## 3. 审计要求
任何竞品关系变化、信号升级/恢复、来源替换都应可追溯到证据和时间。禁止无证据静默修改竞品池。

## 4. 配置版本
未来配置应保留version/effective_at，使历史信号能解释“当时为什么触发”。本框架不实现真实版本存储。
