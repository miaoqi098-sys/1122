# Agent-5｜跨Agent边界与升级

## 1. 与Agent-3竞品情报
Agent-5可发现流量份额下降、Query可见性损失等现象；若怀疑竞品价格、促销、内容、排名或份额变化，需要Agent-3提供竞争证据。

## 2. 与Agent-4广告运营
Agent-5把paid traffic作为整体来源之一；campaign/ad_group/target/search_term内部表现、竞价预算和否定治理由Agent-4负责。若paid来源变化是总流量变化的重要分支，向Agent-4请求专业解释。

## 3. 与Agent-8市场趋势
Agent-5可发现搜索曝光/Query流量系统性变化，但季节性、类目需求、新兴趋势等市场级根因由Agent-8确认。

## 4. 与Agent-9内容转化
流量稳定但点击率/转化或Listing承接异常时，Agent-5不得继续把问题归为流量根因，应升级Agent-9。关键词相关性/内容布局也由Agent-9负责。

## 5. 与Agent-10促销价格
价格、Coupon、Deal可能影响CTR、流量获取和排名，需Agent-10提供价格/促销窗口上下文。

## 6. 与Agent-13增长机会
Agent-5识别visibility_gap、rising_query等流量侧机会；是否扩大资源投入由Agent-13与Agent-1进一步评估。

## 7. 升级Agent-1
多原因并存、跨Agent建议冲突、需要资源分配、策略反转、重要流量损失或增长机会需要经营优先级时，升级Agent-1。

## 8. 升级包
携带source_event/request_id、scope、窗口、来源结构、Query证据、cause_candidates、confidence、evidence_refs、待补专业Agent和当前不确定性。

## 9. 禁止
不替其他Agent确认其域内根因，不把流量侧相关性写成跨域因果，不绕过Agent-1下最终动作。
