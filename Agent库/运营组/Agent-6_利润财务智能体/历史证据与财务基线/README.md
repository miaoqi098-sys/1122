# 历史证据与财务基线

## 目的
Agent-6 的利润判断必须建立在可追溯基线之上，避免把季节性、促销、费用版本变化或广告归因变化误判成结构性利润问题。

## 基线类型
- 近期基线：7/14/30天滚动；
- 同比/同周期基线：用于季节性明显产品；
- 活动前基线：BD、LD、Coupon、Deal等前后对照；
- 成本版本基线：COGS/FBA/税费等版本切换前后；
- 产品生命周期基线：新品、成长期、稳定期、衰退期使用不同解释；
- 自定义经营窗口：由Agent-1或目标系统指定。

## 财务证据记录
每个关键结论至少绑定：
- evidence_id；
- source；
- scope；
- metric；
- time_window；
- baseline_window；
- cost_version；
- attribution_window；
- currency；
- freshness；
- completeness；
- confidence。

## 混杂因素 confounder
以下变化必须作为混杂因素记录：
- 价格或促销变化；
- 广告预算/竞价/结构变化；
- Listing或转化重大变化；
- 库存可售状态与断货；
- 竞争格局或类目需求突变；
- 退款成熟窗口不足；
- COGS/FBA费用版本变化；
- 节假日/大促/季节性。

## 基线失效
当出现以下情况，旧基线不得机械复用：
1. 成本结构明显变化；
2. 产品生命周期切换；
3. 价格体系重置；
4. 重大促销或流量结构变化；
5. 币种/税费口径变化；
6. 数据源或归因口径发生版本升级。

## 历史学习边界
历史结论可以作为 S02/Agent-1 上下文，但必须保留当时条件；Agent-6 不得把“过去有效”自动等同于“当前应执行”。历史基线用于解释和约束，不拥有最终策略权。
