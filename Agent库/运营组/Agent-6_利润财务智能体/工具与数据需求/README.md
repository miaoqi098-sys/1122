# 工具与数据需求

## 目标
定义 Agent-6 为完成利润、成本、盈亏平衡和财务约束分析所需的数据、时效、完整性和降级要求；这里只定义接口需求，不实现真实连接器。

## 核心数据源
1. 订单与销售：订单金额、折扣、退款、取消、SKU/ASIN、时间；
2. Amazon费用：Referral Fee、FBA Fulfillment Fee、Storage Fee、Long-Term Storage Fee及其他平台费用；
3. 广告：广告花费、归因销售、点击、订单、广告类型与实体层级；
4. 采购与头程：COGS、头程/关税/包装等可归属成本；
5. 退款退货：退款金额、退款率、退货相关费用和成熟期；
6. 促销价格：售价、coupon、deal、promotion让利；
7. 库存仓储：库存量、库龄、仓储费用、移除/弃置成本；
8. 税费与其他成本：仅在口径明确时纳入净利润层。

## 数据字段最低要求
每条事实至少具备：
- source；
- scope；
- occurred_at / period；
- currency；
- amount/value；
- cost_type或metric_type；
- version/ref；
- freshness；
- completeness。

## 时效等级
- 广告成本、售价、促销：日级或更高频；
- 订单销售：日级；
- 退款：需要成熟窗口，近期数据标记未成熟；
- FBA与仓储费用：以平台可得账期为准；
- COGS：版本变化时立即失效重算；
- 税费/结算类：允许更低频，但必须标注周期。

## 数据质量与降级
- 缺COGS：可计算收入/广告指标，但不得声称完整贡献利润；
- 缺退款成熟数据：利润结论降低置信度；
- 缺FBA/仓储费用：不得给净利润或完整break-even边界；
- 广告归因窗口不一致：不得直接横向比较；
- 币种不同：必须转换并记录汇率时间；
- 成本版本变化：所有相关历史模拟需要标记失效或重算。

## 未来工具能力
- 财务事实读取；
- 成本版本管理；
- 币种转换；
- 聚合与分摊；
- break-even计算；
- 情景模拟；
- Schema验证；
- 历史基线读取。

## 运行依赖映射
- Amazon SP-API Connector：订单、费用、退款、库存相关事实；
- Amazon Ads API Connector：广告成本和归因；
- 长期记忆数据库：成本版本、利润基线、历史情景；
- Schema Validator：财务事件和响应结构。
