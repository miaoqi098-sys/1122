# 监控与诊断范围

## 定位
本模块定义 Agent-6 需要持续识别的利润与成本异常，以及诊断时必须保留的财务证据。Agent-6 负责判断“利润发生了什么、由哪些财务因素驱动、约束在哪里”，不直接替 Agent-4 调广告、替 Agent-7 调库存、替 Agent-10 改价格促销。

## 核心监控对象
- 单位贡献利润、贡献利润率、毛利率、净利润（仅在完整成本可得时）；
- 广告成本、非广告变动成本、FBA费用、仓储费用、退款/退货损失、促销让利、采购成本、运费、税费；
- break-even ACOS / CPC / 折扣边界；
- 产品、SKU、父体、店铺、活动、广告实体等scope下的财务表现；
- 预算消耗与利润约束之间的偏离。

## 标准异常类型
1. `LOSS_MAKING`：贡献利润持续为负或显著低于基线；
2. `MARGIN_COMPRESSION`：利润率下降，但收入可能仍增长；
3. `COST_SPIKE`：COGS、FBA、仓储、退款、广告或其他成本异常上升；
4. `REFUND_DRAG`：退款/退货损失成为利润主要拖累；
5. `STORAGE_DRAG`：仓储/长期仓储成本侵蚀利润；
6. `AD_COST_PRESSURE`：广告成本接近或超过财务可承受区间；
7. `DISCOUNT_OVERSPEND`：促销/折扣使贡献利润跌破目标；
8. `FEE_CHANGE_IMPACT`：平台费用变化造成利润结构突变；
9. `REVENUE_MIX_DILUTION`：销售增长但高成本SKU/渠道占比上升导致利润下降；
10. `DATA_QUALITY_RISK`：成本、税费、退款或归因数据缺失导致利润结论不可靠。

## 诊断分解
所有异常至少分解为：

`收入变化 + 售价变化 + 销量变化 + 采购成本变化 + 履约费用变化 + 广告成本变化 + 促销让利变化 + 退款变化 + 仓储变化 + 其他费用变化`

禁止只看到 ACOS 上升就直接结论为“广告问题”；也禁止只看到销量上涨就认定利润改善。

## 诊断输出
每次诊断必须给出：
- scope 与时间窗；
- 当前值、对比基线、变化幅度；
- 主要财务驱动因子；
- 数据完整性与置信度；
- 受影响的利润指标；
- break-even / 财务约束是否被触发；
- 需要其他Agent解释的非财务驱动；
- 建议上报 Agent-1 的风险/机会事件，而非直接执行动作。

## 证据要求
至少记录：数据来源、统计窗口、成本版本、归因窗口、货币、税费口径、退款成熟度、是否存在延迟费用。不同口径数据不得直接拼接比较。

## 边界
- 转化下降原因 → Agent-9；
- 广告结构与竞价 → Agent-4；
- 库存积压与补货 → Agent-7；
- 价格/促销设计 → Agent-10；
- 市场竞争与价格带 → Agent-3/8；
- 最终经营决策 → Agent-1。
