# 配置与日志

## 配置范围
本模块只定义 Agent-6 的框架级配置项和审计要求，不实现运行时配置中心。

## 配置项
- 默认货币与汇率来源；
- COGS版本与生效时间；
- FBA/仓储/平台费用版本；
- 税费是否计入当前利润层级；
- 退款成熟窗口；
- 默认基线窗口；
- 异常阈值与最小样本要求；
- break-even安全缓冲；
- 情景模拟变量范围；
- 数据新鲜度与完整性最低标准。

## 版本规则
任何会改变历史利润结论的配置都必须版本化，并记录 `config_version`、`effective_from`、`changed_fields`、`reason`、`source`。禁止无记录覆盖旧口径。

## 审计日志
至少记录：
- calculation_id / event_id / response_id；
- scope与时间窗；
- 使用的数据版本和成本版本；
- 使用的公式/利润层级；
- 输入缺失与降级；
- 主要驱动因子；
- 置信度；
- 生成时间；
- 上报/请求对象。

## 规则
配置改变后，受影响的break-even、模拟结果和历史比较必须重新计算或标记失效。日志是证据链，不替代长期记忆数据库。
