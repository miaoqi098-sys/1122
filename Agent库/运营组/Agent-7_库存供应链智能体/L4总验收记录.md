## 一致性结论
1. 当前库存与未来供给严格分离，避免把在途伪装为可售。
2. 补货基于校正需求、供应周期与安全库存，不机械使用单一销量均值。
3. 供应约束可向Agent-4/10/13提供专业证据，但最终动作仍由Agent-1决定。
4. Agent-6负责财务影响，Agent-7负责库存/供应事实和供给约束，职责不重叠。
5. 当前无需要用户业务选择的结构性歧义。
