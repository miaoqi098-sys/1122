# 工具与数据需求

## 目标
定义 Agent-7 在框架层需要哪些库存、销量、供应和物流数据。只描述数据与工具接口，不实现真实连接器。

## 核心数据
1. FBA库存：可售、预留、不可售、FC转运、接收中；
2. 在途货件：货件ID、数量、发运时间、ETA、接收进度；
3. 上游库存：AWD/3PL/海外仓等可调拨量与调拨lead time；
4. 销量：SKU/ASIN日销量、订单、断货日、促销/活动标记；
5. 采购与供应：PO、供应商、生产/备货周期、最小起订量、历史延迟；
6. 物流：头程、清关、预约、到仓、接收节点；
7. 库龄/仓储：库存年龄段、仓储费、长期仓储风险；
8. 产品状态：可售、抑制、Listing异常等来自Agent-2的状态证据；
9. 价格/促销/广告计划：来自Agent-4/10，用于修正未来需求。

## 最低字段
- source；
- sku / asin；
- marketplace；
- quantity/value；
- inventory_status / metric_type；
- occurred_at / snapshot_at；
- expected_available_at（如适用）；
- freshness；
- confidence；
- source_ref。

## 新鲜度
- FBA库存与在途：日级或更高频；
- 销量：日级；
- 供应周期/供应商参数：发生变化时更新；
- 库龄：按平台数据刷新频率；
- 价格促销广告计划：计划变更后及时同步。

## 降级规则
- 缺在途ETA：只能做当前覆盖判断，未来覆盖降低置信度；
- 缺供应周期：不得给确定性补货窗口；
- 缺断货日标记：销量基线可能被供给约束扭曲；
- 缺上游库存可信状态：不得计入可承诺库存；
- 数据快照过期：必须输出DATA_QUALITY_RISK。
