# 监控与诊断范围

## 定位
本模块定义 Agent-7 需要持续识别的库存与供应链异常。Agent-7判断“供给风险和库存结构发生了什么”，但不直接替其他Agent做价格、广告、利润或最终经营决策。

## 核心异常类型
1. `STOCKOUT_RISK`：预计在下一批合格供给可售前发生断货；
2. `LOW_COVERAGE`：库存覆盖低于当前供应周期+安全缓冲；
3. `OVERSTOCK_RISK`：未来供给明显超过合理需求；
4. `AGED_INVENTORY`：库龄结构恶化；
5. `INBOUND_DELAY`：在途/接收时间偏离计划；
6. `RECEIVING_STALL`：到仓后长时间未转可售；
7. `UNFULFILLABLE_SPIKE`：不可售库存异常增加；
8. `DEMAND_SURGE_SUPPLY_GAP`：需求上涨超出补货能力；
9. `DEMAND_DROP_OVERHANG`：需求下降导致库存消化周期拉长；
10. `SUPPLIER_LEADTIME_DRIFT`：供应周期持续恶化；
11. `STORAGE_COST_RISK`：仓储/库龄开始构成经营约束；
12. `DATA_QUALITY_RISK`：库存、在途、销量或供应周期数据不足。

## 诊断分解
每个库存异常至少检查：
- 当前可售与预留；
- 在途与预计可售时间；
- 上游可调拨库存；
- 7/14/30日需求基线及扭曲标记；
- lead time与其波动；
- 促销、广告、价格、季节性计划；
- 不可售与接收异常；
- 库龄与仓储成本；
- 产品生命周期/下架/合规风险。

## 输出要求
必须给出：
- scope；
- 当前覆盖天数；
- 预计断货/积压时间点；
- 主要驱动；
- 需求和供给假设；
- 数据新鲜度与置信度；
- 是否需要其他Agent补充；
- 风险等级；
- 建议Agent-1关注的决策窗口。

## 禁止误判
- 低库存不等于一定需要补货；
- 高库存不等于一定需要降价清仓；
- 在途库存不等于当前可售；
- 销量下降可能由断货/Listing/广告/价格造成，不能直接当真实需求下降；
- 仓储费用属于Agent-6财务量化，Agent-7提供库存与库龄事实。
