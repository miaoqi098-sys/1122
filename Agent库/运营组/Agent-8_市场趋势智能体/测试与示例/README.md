# 测试与示例

## 静态验收目标
验证 Agent-8 能区分真实趋势、季节性、事件峰值和噪声，并保持与Agent-3/5/7/10/13及Agent-1的职责边界。

## 必测场景
1. 单关键词3天暴涨：只形成candidate，不直接confirmed；
2. 搜索热度、类目销量、多个关键词连续4周同步上涨：可确认CONFIRMED_UPTREND；
3. 每年11月固定增长：优先识别SEASONAL_RISE，而不是新结构趋势；
4. 媒体事件导致一周峰值后快速回落：EVENT_DRIVEN_SPIKE→cooldown；
5. 搜索热度上涨但类目销售不变：保留冲突证据并降低confidence；
6. 价格带从$20-30向$40-60持续迁移：可形成STRUCTURAL_SHIFT候选；
7. 一个竞品爆款：需Agent-3证据，不能直接当市场整体趋势；
8. 店内流量下降但市场整体上升：由Agent-5进一步解释自身可见性问题；
9. 旺季临近但库存不足：Agent-8上报季节窗口，Agent-7提供供给约束，Agent-1决策；
10. 外部数据源口径更新：旧基线失效，不直接比较。

## 示例A｜多源确认上涨
- 搜索主题连续6周增长；
- 类目相关关键词breadth扩大；
- 多个竞品销量代理信号同向；
- 非历史季节窗口。

正确：`CONFIRMED_UPTREND`，记录supporting_signals与置信度，不直接输出扩广告/补货指令。

## 示例B｜节日型峰值
Halloween相关词9月开始抬升，历史每年同周期均出现。正确：`SEASONAL_RISE`，给出lead time窗口，而非宣布新长期增长趋势。

## 验收判定
- 单点信号不等于趋势；
- 季节与事件能独立解释；
- 多源冲突会降级；
- 事件/响应可供Agent-1消费；
- 不越权形成最终动作；
- 外部采集留在运行依赖R14。
