# 测试与示例

## 静态验收目标
验证 Agent-9 能正确分析Listing内容、转化异常、内容实验与跨Agent混杂因素，并保持内容职责边界。

## 必测场景
1. CVR下降但价格上涨：不得直接归因内容；
2. 内容改版后CVR上涨但同时大促：因果等级不得超过plausible_driver；
3. 标题与图片规格冲突：输出CONTENT_MISMATCH；
4. 主图/A+缺关键尺寸/适用信息：输出内容缺失问题；
5. 移动端关键卖点被裁切：输出MOBILE_CONVERSION_GAP候选；
6. 变体名称混乱导致选择困难：输出VARIATION_CONVERSION_GAP候选；
7. A/B实验样本不足：结果必须inconclusive；
8. 内容修改期间断货：实验invalidated或大幅降置信度；
9. 评论集中反映“与预期不符”：由Agent-11提供VOC证据，Agent-9检查页面是否造成错误期待；
10. 高风险医疗/安全claim：标记并转Agent-12，不自行判定最终合规。

## 示例A｜CVR下降但内容未变
- 内容版本30天未变；
- CVR近7天下降20%；
- 同期价格上涨15%。

正确：优先请求Agent-10价格上下文，不输出“内容变差”。

## 示例B｜图片规格冲突
副图写尺寸12in，属性和A+写10in。正确：输出高优先级CONTENT_MISMATCH，要求核实真实产品事实并统一内容。

## 示例C｜实验结果
A/B主图实验达到样本要求，variant CVR提升且价格/广告/库存稳定。可标记experiment_supported，但是否全量采用由Agent-1决策。

## 验收判定
- 内容对象结构完整；
- 转化指标口径清楚；
- 混杂因素优先检查；
- 因果等级不过度声明；
- 内容实验有观察窗口和失效条件；
- 事件/响应可供Agent-1消费；
- 真实发布留在执行层。
