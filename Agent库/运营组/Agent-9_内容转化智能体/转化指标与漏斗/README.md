# 转化指标与漏斗

## 定位
本模块定义 Agent-9 判断页面转化表现时使用的指标、漏斗层级和口径边界。

## 核心漏斗
`曝光/搜索可见 → 详情页访问 → 页面互动/内容消费 → 加购/意向 → 订单 → 退款/退货后的有效购买结果`

其中前端曝光与流量获取主责在Agent-4/5；Agent-9重点从详情页访问后的页面体验与购买转化开始分析。

## 核心指标
- Sessions / Page Views；
- Unit Session Percentage / Conversion Rate；
- Orders / Units Ordered；
- Buy Box可用性（作为转化混杂因素，来自Agent-2）；
- Mobile/Desktop差异（若数据可得）；
- Variation层级转化；
- 内容互动指标（视频播放、A+交互等，若数据可得）；
- Refund/Return rate作为购买质量后验指标，由Agent-11提供体验解释。

## 口径规则
1. CVR必须绑定时间窗、marketplace、ASIN/SKU/父体scope；
2. Session与Page View不得混为同一分母；
3. 广告转化率与Listing整体转化率必须区分；
4. 变体共享页面时需区分父体入口与子体订单归属；
5. 断货、购物车丢失、价格变化、促销、评价变化等必须作为混杂因素；
6. 低样本窗口不得输出确定性转化结论。

## 转化异常判断
至少比较：
- 当前窗口 vs 7/14/30日基线；
- 同比/活动前后（适用时）；
- 流量结构是否改变；
- 价格/促销是否改变；
- 评价与商品状态是否改变；
- 内容版本是否改变。

## 边界
Agent-9不能只因CVR下降就认定内容变差；必须先检查关键非内容混杂因素。
