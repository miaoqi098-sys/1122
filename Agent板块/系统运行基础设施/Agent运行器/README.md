# Agent运行器

负责把 Agent库 中的静态 Agent 定义装载成一次可执行运行。

## 规划模块
- Agent装载器：读取指定 Agent 的身份、目标、规则、提示词、技能模块、权限和工作流。
- 运行控制器：负责一次 Agent 运行从启动到结束的总控制。
- 自主循环控制器：驱动“观察→思考→计划→行动→验证→学习”。
- 结果解析器：把模型返回结果转换成系统可识别的结构化结果。
- 运行状态管理：维护运行中、等待工具、等待审批、完成、失败等状态。

## V0.1目标
手动输入一个事件并指定 Agent-1 后，系统能够装载 Agent-1、构建运行输入、调用大模型、取得结构化结果并保存运行记录。

## 边界
本目录不保存 Agent 自身业务知识；业务知识仍属于 Agent库。
