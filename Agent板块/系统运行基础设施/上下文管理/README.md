# 上下文管理

负责为一次 Agent 运行准备“当前真正需要知道的信息”，避免缺少关键背景，也避免把所有历史和文件全部塞入大模型。

## 规划模块
- 上下文装载器：从 Agent库、记忆与数据层、当前任务等位置装载信息。
- 上下文选择：根据任务类型判断哪些信息需要进入本次运行。
- 上下文裁剪：控制上下文规模，保留高价值信息。
- 产品上下文：产品状态、价格、活动、库存、利润等当前背景。
- 任务上下文：本次任务、事件、目标、限制条件。
- 跨Agent上下文：其他专业 Agent 已形成的事实、判断和智能事件包。

## 标准上下文方向
一次决策上下文应逐步统一为：产品信息、当前状态、近期事件、当前策略、约束条件、历史记录、未完成任务、相关专业Agent结论。

## V0.1目标
先能为 Agent-1 的一次手动运行构建一个标准上下文包。
