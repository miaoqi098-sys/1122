# 大模型运行时

负责向统一的大模型接口提交推理请求，并把模型能力提供给 Agent-1 至 Agent-13。

## 规划模块
- 模型客户端：统一封装模型调用。
- 模型配置：管理不同任务使用的模型、参数与成本策略。
- 提示词组装器：根据 Agent、任务和上下文动态构建模型输入。
- 结构化输出：要求模型按照指定数据结构返回结果。
- 调用重试：处理临时失败、超时和可恢复错误。

## 设计原则
- Agent 不直接绑定某一个具体模型。
- 所有 Agent 通过统一模型接口调用大模型。
- 不把 Agent 全部文件无差别塞给模型，应根据任务选择必要上下文。
- 模型输出必须尽可能结构化，便于后续工具调用、任务调度和结果验证。

## V0.1目标
先支持一次可靠的大模型调用和结构化结果返回，不在第一版实现复杂多模型路由。
