# 机会发现与证据门槛

## 目标
定义哪些信号可以生成候选增长机会，以及候选机会何时有资格进入Agent-1视野。

## 机会来源
- Agent-3：竞品缺口、竞争格局变化；
- Agent-4：广告词路、预算、结构机会；
- Agent-5：流量缺口与搜索可见性机会；
- Agent-6：利润/成本改善空间；
- Agent-7：库存可承接窗口或库存压力；
- Agent-8：市场趋势/季节窗口；
- Agent-9：内容/转化提升假设；
- Agent-10：价格/促销窗口；
- Agent-11：体验修复机会；
- Agent-12：风险解除后重新开放的机会。

## 候选生成门槛
至少需要：
- 明确scope；
- 明确机会假设；
- 至少一个专业信号/证据；
- 可能的影响方向；
- 可验证方式；
- 没有已知prohibited资格。

## Qualified门槛
候选升级qualified至少需要：
- 核心证据新鲜且可追溯；
- 主要专业Agent边界已补齐；
- 利润/库存/风险等关键约束已检查或明确待检查；
- 机会窗口与依赖清楚；
- 有成功指标、失败/停止条件；
- 不与现有qualified机会重复。

## 证据不足
若市场信号强但库存、利润或风险证据缺失，只能保持 `evidence_gathering` 并发请求，不能为赶进度直接qualified。

## 反证
必须主动保存与机会假设冲突的证据。若反证足以推翻核心机制，应将机会降级或关闭，而不是无限补充支持材料。

## 边界
Agent-13负责把信号组织成可验证机会，不替专业Agent重做原始诊断。
