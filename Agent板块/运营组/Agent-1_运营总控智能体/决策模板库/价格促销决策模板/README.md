# 价格促销决策模板

## 定位
本目录承载 Agent-1 对售价、Coupon、BD、LD、Prime Deal、站外折扣、参考价/Was Price 等经营问题的标准决策结构。

Agent-10 负责价格与促销监控、资格与风险分析；Agent-1 结合利润、库存、转化、广告、活动节奏和长期价格体系形成最终决策。

## 典型问题
- 是否降价、提价或恢复常态价；
- 是否参加/退出促销；
- Coupon与Deal是否叠加或冲突；
- 促销价是否破坏利润底线或参考价体系；
- 活动后价格如何恢复；
- 清库存、新品增长、竞争应对时如何设计价格节奏。

## 原则
- 价格不是单一转化杠杆，必须同时评估利润、价格体系、促销资格和消费者预期；
- 不在模板内硬编码平台规则或参考价阈值，规则由最新数据/规则来源提供；
- 短期促销收益不得自动覆盖长期价格体系风险；
- Agent-10建议不等于最终执行指令。
