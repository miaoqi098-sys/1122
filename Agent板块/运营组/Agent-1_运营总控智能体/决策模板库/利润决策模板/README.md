# 利润决策模板

## 定位
本目录承载 Agent-1 对利润、成本、现金流和经营收益约束相关问题的标准决策结构。

Agent-6 负责利润、成本与经营结果核算；Agent-1 使用本模板决定广告、价格、促销、库存、Listing等动作在利润与现金流约束下是否值得执行。

## 典型问题
- 毛利/净利下降或亏损；
- 广告、促销、仓储、退款等成本上升；
- 是否接受短期亏损换取增长；
- 清库存、提价、降广告、降促销等方案如何取舍；
- 盈亏平衡点变化；
- 多SKU/产品利润结构失衡。

## 原则
- 利润是目标与约束之一，不自动压倒安全、可售和关键增长目标；
- 必须区分单件利润、贡献利润、总利润、现金流与长期价值；
- 成本口径与时间窗口必须一致；
- 短期亏损策略必须有明确期限、理由、成功标准和退出条件；
- Agent-6核算结果不直接等于最终经营动作。
