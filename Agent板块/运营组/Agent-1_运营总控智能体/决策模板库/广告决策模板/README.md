# 广告决策模板

## 1. 定位

本目录承载 Agent-1 对广告经营问题的标准决策结构。

Agent-4 负责广告监控、分析和优化建议；Agent-1 使用本模板把广告问题放回产品目标、库存、利润、价格、转化、活动状态和风险约束中做最终经营决策。

因此本模板域不是“广告优化算法库”，也不替代 Agent-4。

---

## 2. 适用问题

典型包括：
- 花费增长但订单/销售未同步增长；
- 高点击低转化；
- 搜索词/关键词需要收缩、扩展或迁移匹配方式；
- 广告预算是否需要增加、减少或重分配；
- 竞价是否需要调整；
- 广告结构是否需要拆分、合并或隔离；
- 广告流量与自然流量/活动流量关系发生变化；
- 广告策略与库存、利润、价格、Listing转化发生冲突；
- 新品、BD/LD、Coupon、断货预警等特殊阶段的广告承接策略。

---

## 3. 不适用/应升级

以下问题不应只靠广告模板闭环：
- 根因主要是 Listing 内容/转化 → Listing与转化模板为主；
- 根因主要是库存风险 → 库存模板为主；
- 价格/促销资格决定动作边界 → 价格促销模板为主；
- 广告动作会使利润跌破底线 → 利润模板为主或组合；
- 多专业Agent建议互斥 → 多Agent冲突模板；
- 三个以上经营域共同决定策略 → 综合经营模板。

---

## 4. 主要输入

优先读取：
- Agent-4 广告事件与分析；
- DecisionItem / ContextPackage；
- 广告表现指标与搜索词证据；
- Listing转化状态；
- 库存覆盖与断货风险；
- 利润与边际贡献约束；
- 当前价格/促销/活动状态；
- 历史广告策略与观察窗口；
- StrategyChain（若已有广告策略在运行）。

---

## 5. 决策原则

- 广告指标不是最终经营目标；
- 不能仅凭 ACOS/ROAS 单指标决定增减预算；
- 高点击低转化先区分流量质量、Listing转化、价格、评价和活动因素；
- 搜索词迁移、否定、竞价调整应保留来源与观察窗口；
- 新品期、活动期、断货预警期允许使用不同判断标准，但必须来自当前经营状态；
- 大幅反转正在运行的广告策略时对齐 S10；
- 最终输出只有 Agent-1 的 FinalDecision，Agent-4 建议不能直接成为执行命令。
