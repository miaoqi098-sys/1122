# 综合经营决策模板

## 定位
本目录承载 Agent-1 在多个经营域、多个目标或多个 DecisionItem 需要联合规划时的标准决策结构。

它不是“万能模板”。只有单域模板无法充分覆盖问题，且多个经营变量之间存在明显耦合时才使用。

## 典型场景
- 新品期同时需要广告、价格、库存、Listing协同；
- BD/LD/Coupon活动前后需要广告承接、库存安全、利润和价格恢复联合设计；
- 清库存同时涉及降价、促销、广告、现金流和价格体系；
- 多个DecisionItem互相依赖，需要形成组合策略；
- 单域最优会造成明显次生问题。

## 原则
- 先拆清子问题和DecisionItem，再做联合规划；
- 不允许用“综合”掩盖问题定义不清；
- 必须明确主目标、次目标、硬约束和可接受取舍；
- 子域判断复用各领域模板，不复制一套简化版；
- 最终仍由Agent-1输出可追溯的唯一决策或明确关联的决策组合。
