# 策略稳定与反转规则

## 1. 定位
本规则约束 Agent-1 在存在运行中 StrategyChain 时，何时可以保持、微调、扩大、缩小、合并、暂停、恢复、替换或反转策略。正式稳定性判断由 S10 完成。

## 2. 触发 S10 的场景
当新的 Event / Option / Decision proposal 可能改变当前 StrategyChain 时，必须检查是否需要 S10，尤其是：
- 方向相反或部分反向；
- 相同目标但显著扩大/缩小动作；
- 未完成观察窗口就准备替换策略；
- 新方案会取消、暂停或覆盖现有 Task；
- 同一问题在短期内重复产生决策；
- 虽然方向一致，但 scope、预算、时长或强度发生显著变化。

## 3. 策略变化类型
策略变化不得只分成“继续/反转”。至少使用以下语义：
- `maintain`：保持现有策略不变；
- `tune`：小幅参数微调，不改变主要方向；
- `scale_up`：扩大强度、预算或覆盖；
- `scale_down`：缩小强度、预算或覆盖；
- `scope_expand`：扩大作用对象；
- `scope_reduce`：缩小作用对象；
- `merge`：并入现有 StrategyChain；
- `pause`：暂时停止但保留恢复条件；
- `resume`：恢复此前暂停策略；
- `replace`：用新策略替代旧策略；
- `full_reverse`：方向完全反转；
- `terminate`：策略结束且不计划恢复。

不同变化类型需要不同证据强度。`tune` 不应被错误当成 `full_reverse`，`full_reverse` 也不得伪装成普通微调。

## 4. S10结果约束
- `allow`：允许进入正常 DecisionSelector/S07。
- `hold`：保持当前策略，不创建冲突 Task；必须保留 hold_reason、release_conditions、review_trigger。
- `merge`：并入现有 StrategyChain，避免创建重复策略链。
- `escalate`：进入审批/复核，不自动反转。
- `override`：允许形成替代决策，但旧 Decision/Task 历史必须保留，并由 S07 重新编排。

## 5. 允许改变/override 的证据
典型包括：
- stop_condition 触发；
- guardrail 达到不可接受水平；
- critical_risk；
- 经营状态确认切换使旧策略失效；
- critical_new_fact；
- 新证据显著强于启动旧策略的证据；
- 原目标/约束发生正式变化；
- 达到预先定义的 scale_up / scale_down 条件；
- 观察窗口完成并满足调参标准。

## 6. 不足以反转的情况
- 单日波动；
- 重复信号但没有更强证据；
- 观察窗口尚未完成且未触发 stop/guardrail；
- 仅因模型产生不同方案；
- 短期局部指标改善但长期风险更高；
- 没有说明旧策略为何失效。

## 7. 微调与幅度控制
任何 tune/scale_up/scale_down 至少应记录：
- `previous_value / new_value` 或前后范围；
- `change_magnitude`；
- `change_reason`；
- `evidence_refs`；
- 新观察窗口；
- 下一次允许继续扩大/缩小的条件。

连续多次微调若累计效果等同方向性重大改变，应升级为 replace/full_reverse 级别重新评估，禁止通过“切成很多小步”绕过门禁。

## 8. 反转记录
发生 override / replace / full_reverse 时至少保留：
- strategy_chain_id；
- overridden_decision_id；
- overridden_task_ids；
- previous_direction / new_direction；
- change_type；
- trigger；
- evidence_refs；
- reason；
- approval_required；
- old_task_actions 的建议处置引用。

S10 不直接执行 cancel/pause/rollback，旧任务如何处理由 S07 编排。

## 9. 禁止
- 用“最新决策”覆盖历史而不保留 supersedes/strategy_chain 引用；
- 无新证据反复 full_reversal；
- 把 hold 理解为固定时间死等；
- S10 hold 后仍创建冲突执行 Task；
- S10 override 后直接由本规则取消旧任务；
- 用连续小幅 tune 绕过重大策略变更门禁。
