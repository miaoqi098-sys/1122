# Agent-1 方案比较机制

## 目的
让 Agent-1 围绕当前主目标、约束和经营状态比较方案，而不是机械执行第一个建议，也不使用简单平均分替代经营判断。

## 第一步：硬约束筛选
任何违反绝对硬约束的方案直接淘汰，不进入评分或排序。

若方案需要突破经营硬约束，例如主动牺牲部分利润、库存安全边际或价格保护空间，则必须：
- 明确为什么值得突破；
- 说明影响范围；
- 判断权限等级；
- 获得必要审批后才可进入执行。

## 第二步：证据基础检查
对每个方案确认：
- 方案建立在哪些事实和假设上；
- 关键假设的证据强度；
- 是否存在会推翻方案的重大未知信息；
- 证据时间窗口是否适用于当前经营状态。

证据明显不足的高影响方案，应优先降级为小规模测试、继续观察或补信息，而不是直接大范围执行。

## 第三步：方案比较维度
每个候选方案至少比较：
- 对当前主目标的预期贡献；
- 对副目标的影响；
- 对利润和现金流的影响；
- 对库存和供应链的影响；
- 对价格体系的影响；
- 对流量、转化、自然资产和市场竞争力的影响；
- 合规与账户风险；
- 证据强度；
- 执行成本；
- 可逆性；
- 生效速度；
- 观察周期；
- 最坏情况；
- 短期、中期和长期影响。

## 第四步：判断方案类型
方案可标记为：
- 直接执行型；
- 小规模测试型；
- 分阶段执行型；
- 防守保护型；
- 继续观察型；
- 人工审批型。

方案类型本身没有高低之分，应根据当前经营状态选择。

## 第五步：辅助评分
必要时可使用 1-5 分作为辅助表达：
- 预期收益；
- 证据强度；
- 风险可控性；
- 可逆性；
- 执行可行性；
- 长期价值。

评分只能帮助比较，不能作为自动决策公式。不得简单相加后认定总分最高方案必然获胜。

若使用评分，必须同时保留评分依据，避免模型凭感觉给分。

## 第六步：形成排序
排序时优先回答：
1. 哪个方案最符合当前主目标？
2. 哪个方案最不容易触发不可接受风险？
3. 哪个方案的关键判断有更强证据支持？
4. 哪个方案在失败时更容易停止或回滚？
5. 哪个方案能以合理成本更快获得有效反馈？
6. 哪个方案对中长期经营价值更有利？

## 差异不显著时
如果两个方案预期差异很小：
- 优先可逆方案；
- 优先成本更低方案；
- 优先验证速度更快方案；
- 优先影响范围更小方案；
- 必要时先测试而不是一次性押注。

## 合法的“不行动”
“继续观察并补充证据”必须保留为合法候选方案，但只有在以下情况下才合理：
- 当前没有紧急风险；
- 继续观察能获得有价值的新信息；
- 等待成本可接受；
- 已明确观察窗口和触发条件。

不得用“继续观察”逃避应该及时处理的高风险问题。

## 决策记录
最终应记录：
- 被选方案；
- 主要备选方案；
- 淘汰方案及原因；
- 关键比较依据；
- 剩余不确定性；
- 成功标准、观察窗口、止损和回滚条件。

## 核心原则
方案比较不是为了找到理论上的完美方案，而是在当前信息、时间、风险和资源约束下选择最值得执行或验证的下一步。
