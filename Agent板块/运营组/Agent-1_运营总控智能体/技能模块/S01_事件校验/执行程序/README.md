# S01 执行程序

## 当前状态
本目录预留 S01 的真正可运行实现。

当前 V1.0 已完成：
- 技能边界；
- 输入规范；
- 输出规范；
- 判断规则；
- 异常处理；
- 示例；
- 验收测试。

尚未完成：
- JSON Schema运行时校验器；
- 来源与产品主数据查询；
- 时间新鲜度策略加载；
- 重复事件相似度检测；
- 与Agent运行器的实际接口；
- 自动化测试代码。

## 推荐实现顺序
1. 基础 JSON Schema 校验；
2. 必填字段与格式校验；
3. 来源白名单；
4. 产品对象解析；
5. 时间校验；
6. warning/error 标准代码；
7. 与历史事件库做精确重复检查；
8. 再增加近重复检测。

## 设计要求
- 执行程序不得硬编码业务阈值；
- 来源、有效期和允许对象规则应从配置加载；
- 所有输出必须符合 `输出规范.json`；
- 无法访问外部依赖时必须显式返回依赖异常；
- 不在执行程序中加入经营决策逻辑。

## 与运行器关系
未来由系统运行层中的 Agent运行器调用：
```text
Agent运行器
↓
S01执行程序
↓
校验结果
↓
passed / passed_with_warnings → S02
needs_information → 请求补充
rejected → 终止当前事件链
```

当前这里保留接口边界，等系统运行层进入真实代码阶段后再实现。
