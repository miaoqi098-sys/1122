# S02 上下文域映射

## 目的
给 S02 一张默认“问题 → 应加载什么”的地图。它是默认规则，不替代动态判断。

| 问题类型 | P0 必须装载 | P1 高价值 | 常见可省略 |
|---|---|---|---|
| 广告高点击无订单 | C01/C02/C03/C04/C05/C10 | C06/C07/C09 | 无关竞品全量数据、无关Review |
| ACOS/TACOS异常 | C02/C03/C04/C05 | C06/C07/C10 | 与问题无关的内容历史 |
| 自然排名下降 | C02/C04/C05 | C06/C07/C08/C09 | 无关财务细项 |
| CVR下降 | C01/C02/C04/C05 | C06/C07/C09/C10 | 无关供应链细节 |
| 库存断货风险 | C01/C02/C03/C04/C05/C10 | C06/C07 | 大量内容知识 |
| 库存积压 | C02/C03/C04/C05 | C06/C07/C08/C09 | 无关短期事件 |
| 价格/促销决策 | C01/C02/C03/C04/C05/C10 | C06/C07/C08 | 无关Review全文 |
| 利润下降 | C02/C03/C04/C05 | C06/C07/C10 | 无关市场资料 |
| Rating/退货恶化 | C01/C02/C04 | C05/C06/C07/C09 | 无关广告明细 |
| Listing冻结/合规 | C01/C02/C03/C05/C07/C10 | C06 | 大量市场趋势 |
| 竞品重大动作 | C02/C03/C08 | C04/C05/C06/C07/C09 | 无关内部历史细节 |
| 新增长机会 | C02/C03/C04/C08/C10 | C05/C06/C07/C09 | 无关低价值历史 |

## 十个上下文域
- C01 产品身份
- C02 当前经营状态
- C03 当前经营目标
- C04 当前核心指标
- C05 经营事件与活动
- C06 产品历史
- C07 专业Agent结论
- C08 市场与竞品
- C09 经营知识
- C10 当前任务与限制

## 动态扩展条件
默认映射后，如出现以下情况应追加上下文：
- 风险状态升级；
- 现有结论冲突；
- 重大不可逆动作；
- 当前方案影响新领域；
- 专业Agent指出关键缺失信息；
- 经营状态发生切换。

## 动态缩减条件
- 已有新鲜结论覆盖；
- 当前问题低风险且可逆；
- 信息不会改变方案排序；
- 数据重复；
- 超出当前问题范围。

## 核心原则
上下文域映射提供默认起点，真正装载范围仍由“问题 + 状态 + 目标 + 风险 + 已有信息”共同决定。
