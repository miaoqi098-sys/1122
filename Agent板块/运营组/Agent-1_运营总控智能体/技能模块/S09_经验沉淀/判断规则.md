# S09 判断规则 V1.1

## 一、标准学习链
```text
1. 读取S08完整verification result
2. 先生成fact_records
3. 基于事实生成interpretation_records
4. 判断是否值得形成learning_item
5. 根据data quality / attribution / failure type判断最高可升级等级
6. 与previous_lessons和historical_evidence比对
7. 标记supports / contradicts / refines / supersedes / coexists
8. 通过promotion gate决定create / promote / merge / refine / hold
9. 生成memory_writes计划
```

## 二、先事实后经验
事实必须能追溯到decision/task/verification/data。不得把“降低竞价有效”这种因果解释写成fact。

## 三、解释必须带归因
interpretation必须继承S08 attribution_status和confounders。weak/confounded不得写成强因果句式。

## 四、经验等级受证据约束
- 单次结果默认不超过product_lesson；
- reusable_pattern通常需要重复支持或跨相似场景证据；
- knowledge_candidate需要更强证据、明确边界和较少重大冲突；
- validated_knowledge必须经过知识治理和多案例验证，S09单次运行不得直接越权升级。

## 五、Promotion Gate
### eligible
证据、边界和归因满足当前目标等级要求。

### hold
值得保存但暂不升级。

### needs_more_evidence
已有方向性经验，但支持次数/窗口/样本/归因不足。

### conflicted
存在重要反例或旧经验冲突，需要进一步治理。

### rejected
证据明显不足、错误或不应形成该类经验。

## 六、S08失败类型直接继承
- execution_failure：学习执行链问题，不学习策略无效；
- strategy_failure：在执行真实、窗口完整、数据可靠时可形成策略失败经验；
- guardrail_breach：学习目标收益与保护代价之间的边界；
- data_failure：主要形成数据质量/验证流程经验；
- external_confounding：只保留事实和弱解释，通常hold；
- assumption_failure：可沉淀“该假设在当前适用条件下被推翻”；
- premature_evaluation：记录过早验证事实，不形成策略结论。

## 七、低归因限制升级
attribution=weak/confounded/not_evaluable时，不得生成高置信强因果reusable_pattern/knowledge_candidate。

正向结果也受此规则约束。

## 八、新旧经验不是简单覆盖
比对适用条件后决定：supports、contradicts、refines、supersedes、coexists。

只有证据足够强且适用范围真正替代旧版本时才使用supersedes；旧记录仍保留历史。

## 九、重复经验优先merge
同一产品、相同适用边界、相同结论的重复lesson优先合并证据并增加support_count，不无限复制。

## 十、反例必须累计
contradiction_count不能因为当前结果成功而清零。重要反例应降低promotion资格或触发review。

## 十一、适用边界是必需字段
缺applicability或invalid_when时，经验默认降级到observation/hold，除非该类型本身不需要因果复用。

## 十二、时效经验必须可失效
活动期、季节性、价格环境、政策、竞争状态等敏感经验必须设置valid_until或review_trigger。

## 十三、学习动作与证据匹配
- record_fact：只记录事实；
- create_lesson：首次形成经验；
- promote：证据足够升级；
- merge：重复证据合并；
- refine：细化边界；
- deprecate：经验已不适合继续主动使用，但保留历史；
- hold：暂不升级。

## 十四、S09不负责真实数据库写入
S09输出memory_writes计划。真正写库、索引、版本持久化由共享记忆与数据层负责。写入失败不得假装成功。

## 核心原则
S09不是总结器，而是经验治理门：让正确经验逐步升级，让不确定经验停留在合适层级，让失败和反例同样被保存，并阻止偶然相关性污染长期知识。
