# 字段命名与引用规范 V1.0

## 目的
消除S01-S10之间的重复字段、同义字段和隐式映射，确保同一业务对象只有一个正式名称、一条引用链和一个权威来源。

## 一、正式主键
| 对象 | 正式主键 |
|---|---|
| Event | `event_id` |
| DecisionItem | `decision_item_id` |
| Option | `option_id` |
| FinalDecision | `decision_id` |
| TaskPlan | `task_plan_id` |
| Task | `task_id` |
| ExecutionResult | `execution_result_id` |
| ValidationResult | `validation_id` |
| LearningBatch | `learning_batch_id` |
| LearningRecord | `learning_id` |
| StrategyChain | `strategy_chain_id` |
| Skill Run | `run_id` |
| End-to-end Trace | `trace_id` |

## 二、禁止继续新增的旧别名
- `item_id` → 统一为 `decision_item_id`
- `problem` → 统一为 `problem_definition`
- `verification_result` → 统一为 `validation_result`
- `actual_execution` → 统一为 `execution_result`
- Skill内部独立`product_id`作为唯一作用域 → 统一使用 `scope`，其中可包含 `product_id`
- `decision_id + selected_option + risk_assessment`散装传S07 → 统一为 `final_decision`

旧别名只允许出现在历史记录、迁移说明或兼容适配器，不得继续写入新Schema和新示例。

## 三、唯一事实源规则
### ContextPackage
S02输出的`context_package`是当前决策上下文唯一事实源。

S03-S06不得同时接收另一套`current_goals`、`business_state`、`constraints`、`agent_analyses`并把它们当成同等级事实源。

如运行器为了性能生成快捷字段，只能标记为derived view，并能追溯回ContextPackage。

### FinalDecision
Agent-1 DecisionSelector输出的`final_decision`是S07任务编排唯一决策源。

S07不得重新选择Option，不得自行改变risk_assessment、business_priority或approval要求。

## 四、正式引用链
```text
event_id
↓
decision_item_id
↓
option_id
↓
decision_id
↓
task_plan_id
↓
task_id
↓
execution_result_id
↓
validation_id
↓
learning_id
```

`strategy_chain_id`横向贯穿decision/task/validation，并在策略变化时由S10管理。

## 五、引用一致性
1. 下游对象必须保存必要的上游主键，不能只保存自然语言描述。
2. `ExecutionResult.task_id`必须与真实执行Task一致。
3. `ValidationResult.execution_result_id/task_id/decision_id/decision_item_id`必须可交叉核对。
4. `LearningRecord.validation_id`必须存在，不允许使用`TASK-xxx:S08`这类临时字符串代替正式验证ID。
5. 任何override必须保留`strategy_chain_id`和被覆盖的`decision_id/task_id`。
6. ID不要求当前阶段强制UUID格式，但进入运行时后必须由统一ID生成器产生，禁止各Skill自行发明互相冲突的格式。

## 六、状态命名原则
- `status`只描述当前对象生命周期状态。
- 业务判断结果使用更明确字段，例如`business_outcome_status`、`overall_validation_status`、`eligibility`、`promotion_gate`。
- 不使用`state`和`status`表达同一语义。

## 七、时间字段
统一使用带时区ISO 8601；正式字段优先：
- `occurred_at`
- `created_at`
- `started_at`
- `finished_at`
- `updated_at`
- `valid_until`
- `review_at`

业务观察窗口使用结构化`observation_window`，不把“7天”等自然语言作为唯一机器字段。

## 核心原则
同一概念只有一个正式名字；同一事实只有一个权威来源；同一业务链必须靠ID引用而不是靠模型猜测上下文关系。
