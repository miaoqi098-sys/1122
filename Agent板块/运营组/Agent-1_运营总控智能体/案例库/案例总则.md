# Agent-1 案例总则

## 1. 目的

案例库把一次完整经营决策过程封装成可回放、可比较、可检索的 Case，使 Agent-1 能在未来判断“当前场景与历史场景到底哪里相似、哪里不同”。

案例不是规则生成器，也不是自动模仿器。

## 2. Case 的最小边界

一个 Case 应对应一个相对完整的经营 episode，至少具有：
- 明确的时间范围；
- 明确的Scope；
- 至少一个 DecisionItem；
- 至少一个最终 Decision 或明确的“未形成决策”结论；
- 执行/未执行状态；
- 结果或验证状态；
- 可追溯证据。

如果只是单一事实，进入历史记忆；如果只是原子经验，进入 S09 LearningRecord；如果是泛化知识，进入经营知识库。

## 3. Case 生命周期

```text
draft
→ complete
→ reviewed
→ archived
```

另有：
- `invalidated`：后续发现案例事实链存在重大错误；
- `superseded`：同一episode有更完整版本替代旧版本。

### draft
事实或结果尚未闭合。

### complete
episode主要链路已完整，但未经过案例质量复核。

### reviewed
通过案例质量门禁，可以用于相似场景参考。

### archived
历史保留，不再作为默认检索候选。

## 4. 引用优先，复制最少

案例只保存足以理解 episode 的摘要和关键状态快照，正式业务对象以引用为准。

必须优先保留：
- event_id / source_event_refs
- decision_item_id
- template_id + template_version
- option_id
- decision_id
- task_plan_id / task_id
- execution_result_id
- validation_id
- learning_id
- strategy_chain_id（适用时）

禁止复制一整份 FinalDecision 或 LearningRecord 后独立维护，避免两个事实源分叉。

## 5. 案例版本

`case_id` 标识同一episode，`case_version` 标识案例整理版本。

案例补证据、补结果、修摘要时提升 case_version，但不改变原canonical对象ID。

若发现原案例事实错误：
- 不静默覆盖；
- 记录 revision_reason；
- 保留 supersedes_case_version；
- 必要时标记旧版本 invalidated/superseded。

## 6. 案例质量

案例质量至少考虑：
- evidence_quality；
- attribution_strength；
- outcome_completeness；
- context_completeness；
- confounders；
- freshness；
- reproducibility；
- review_status。

“成功案例”不等于“高质量案例”。如果归因弱、变量过多，仍然只能低置信度复用。

## 7. 案例与模板

案例应记录当时实际使用的 `template_id + template_version`。

用途：
- 验证模板在真实场景下是否有效；
- 识别模板失配；
- 支持模板版本升级。

案例不能反向修改模板注册状态。

## 8. 案例与学习

Case 可以引用多个 LearningRecord。

案例正文中的“可复用结论”只能是学习摘要，不替代 LearningRecord 的正式 evidence_quality / attribution_strength / applicability / invalid_when / promotion_gate。

单一 Case 不得直接把经验升级为 validated_knowledge。

## 9. 人工纠正

如果人工推翻、修正或补充 Agent-1 的判断，应完整记录：
- 原Decision引用；
- correction_reason；
- corrected_by_role；
- corrected_decision_ref（如有）；
- 人工新增证据；
- 原判断错误类型；
- 后续验证结果。

人工纠正案例不得只记录“人说了算”，必须保存原因和证据。

## 10. 案例关闭条件

一个 Case 进入 reviewed 前至少满足：
- 核心链路可追溯；
- 结果状态明确；
- 关键干扰因素已记录；
- 适用范围与不适用边界存在；
- 新鲜度/失效条件明确；
- 没有把案例结论误写成全局规则。
