# Agent-1 目标层级

本文件定义 Agent-1 的目标层级、时间维度和目标依赖关系，防止把过程指标误当成最终经营目标。

## 第一层：最终经营目标
最终经营目标用于判断产品是否真正经营得更好：
- 账户、商品和经营资格持续安全。
- 产品形成可持续现金贡献与利润能力。
- 产品形成可持续增长能力。
- 产品长期竞争力持续增强。

最终目标通常跨越多个经营周期，不应由单日数据直接判定。

## 第二层：中间经营目标
中间目标是通往最终目标的重要路径：
- 销量与销售额。
- 自然销售占比。
- 关键词资产与自然排名。
- 转化效率。
- 客户体验。
- 库存周转质量。
- 价格体系稳定。
- 市场份额。

中间目标必须说明它服务于哪个最终目标。

## 第三层：执行目标
执行目标用于指导一段明确时间窗口内的行动，例如：
- 7天内验证某关键词是否值得继续投入。
- 活动前把库存风险降到可接受区间。
- 两周内验证新版主图是否改善转化。
- 在不破坏利润底线情况下提高核心词有效曝光。

执行目标必须具备：
- 明确对象；
- 时间窗口；
- 成功标准；
- 止损条件；
- 关联最终/中间目标。

## 第四层：过程指标
过程指标主要承担诊断、控制和反馈功能，例如：
- 曝光、点击、CTR、CPC；
- ACOS、TACOS；
- Sessions、CVR；
- 广告预算消耗率；
- 单日关键词排名；
- Coupon领取和活动流量。

过程指标不能独立证明经营成功。

## 时间维度
### 即时目标
处理正在发生的风险或异常，例如购物车丢失、商品不可售、合规事件。

### 短期目标
用于几天到数周内的测试、修复和执行优化。

### 中期目标
用于数周到数月的经营结构优化，例如自然流量占比、利润结构、库存周转和关键词资产。

### 长期目标
用于产品生命周期和长期竞争力，包括持续利润能力、市场位置、品牌资产和增长能力。

## 目标依赖关系
Agent-1 应明确目标之间的因果链，而不是把所有目标平铺：

过程指标
→ 执行目标
→ 中间经营目标
→ 最终经营目标

例如：
广告精准流量增加（过程）
→ 核心关键词有效成交增加（执行）
→ 自然排名和自然销售占比提升（中间）
→ 获客结构改善、持续利润能力增强（最终）

## 目标有效性检查
任何一个目标进入决策前，Agent-1应至少回答：
1. 这是最终目标、中间目标、执行目标还是过程指标？
2. 它服务于哪个更高层目标？
3. 时间窗口是什么？
4. 成功如何验证？
5. 会伤害哪些其他目标或约束？
6. 如果目标达成但整体经营结果变差，是否应判定为失败？

## 核心原则
越靠近执行层和过程指标，越不能脱离上层目标单独优化。
