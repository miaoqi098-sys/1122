# 利润指标

## 1. 销售收入
- 指标代码：revenue
- 定义：对应层级与窗口内的销售收入。
- 联动：销量、成交价、退款、促销。

## 2. 毛利
- 指标代码：gross_profit
- 定义：销售收入减去产品成本及按公司统一口径计入毛利的直接成本。
- 注意：必须统一成本口径，避免不同任务使用不同“毛利”。

## 3. 毛利率
- 指标代码：gross_margin_rate
- 公式：毛利 / 销售收入。
- 联动：成交价、采购成本、FBA费用、促销。

## 4. 贡献利润
- 指标代码：contribution_profit
- 定义：在毛利基础上进一步扣除广告、平台履约/销售相关可变成本、促销和可归属退款等后的经营贡献。
- 用途：Agent-1判断一个产品是否真正为整体经营贡献现金。
- 具体口径必须由财务配置统一。

## 5. 贡献利润率
- 指标代码：contribution_margin_rate
- 公式：贡献利润 / 销售收入。
- 联动：TACOS、价格、促销、退款、FBA费用。

## 6. 净利润
- 指标代码：net_profit
- 定义：按公司财务口径扣除应归属成本后的净经营结果。
- 说明：若某些固定成本无法可靠分摊，应明确口径，不制造假精确。

## 7. 单位贡献利润
- 指标代码：unit_contribution_profit
- 公式：贡献利润 / 销售件数。
- 用途：判断每多卖一件是否创造价值，以及广告/促销可承受空间。

## 8. 盈亏平衡ACOS
- 指标代码：break_even_acos
- 定义：在指定成本口径下，广告销售最多可承受的广告成本比例。
- 计算必须基于真实单位经济模型，不使用固定行业值。
- 联动：售价、毛利、FBA费用、Coupon、退款成本。

## 9. 可接受获客成本
- 指标代码：allowable_cac
- 定义：当前目标下允许为新增订单/客户支付的最高成本。
- 说明：可因新品、增长、成熟、防守等状态不同而变化，但不能突破未批准的经营硬约束。

## 10. 利润安全边际
- 指标代码：profit_safety_margin
- 定义：当前利润水平距离最低允许利润底线的空间。
- 用途：支持正常/关注/预警/停止区判断。

## 11. 促销后单位利润
- 指标代码：post_promotion_unit_profit
- 定义：考虑Coupon、Deal、站外折扣及相关费用后的单位利润。
- 用途：避免只看折扣率和销量，不看真实经济性。

## 12. 退款/退货利润侵蚀
- 指标代码：return_profit_erosion
- 定义：退款、退货、不可售损耗等对利润的实际影响。
- 联动：退货率、VOC、产品质量。

## 13. 仓储成本压力
- 指标代码：storage_cost_pressure
- 定义：仓储、库龄及长期库存相关成本对利润和现金的侵蚀。
- 联动：库存周转、库龄、清货策略。

## 14. 现金贡献
- 指标代码：cash_contribution
- 定义：产品在指定窗口内对可用现金的贡献或消耗，具体按公司财务口径计算。
- 用途：利润为正但现金被大量库存占用时，需要区别判断。

## 核心诊断关系
```text
销量上涨 + 利润上涨 → 优先判断增长质量是否健康
销量上涨 + 利润下降 → 检查价格、广告、促销、成本和退货
CVR上涨 + 利润下降 → 检查是否用过度降价/促销换转化
ACOS下降 + 总利润下降 → 检查流量规模和自然销售是否同时萎缩
```

## 核心原则
利润指标必须与现金、库存、增长阶段一起看。短期利润下降可以是战略投资，但必须有预算、时间边界、验证目标和退出条件。
