# 商品与风险信号

## 目的
定义影响商品可售、购买路径和账户安全的高优先级信号。这类信号很多不是连续数值指标，而是能够直接改变经营状态的强事实。

## 1. 商品可售状态
- 指标代码：listing_sellability_status
- 定义：ASIN/SKU当前是否可以正常被消费者购买。
- 常见值：正常可售 / 部分受限 / 不可售 / 状态未知。
- 数据来源：Seller Central、SP-API、前台验证。
- 推荐窗口：实时或最近一次可靠状态。
- 联动：Buy Box、库存、配送、价格、合规通知。
- 状态映射：R1 商品状态风险；严重时直接影响主目标。

## 2. Buy Box / Featured Offer状态
- 指标代码：featured_offer_status
- 定义：自身报价是否获得主要购买入口。
- 观察：当前状态 + 丢失时长 + 丢失范围。
- 联动：价格、配送、库存、账号状态、竞品报价。
- 误判：短时前台波动不一定代表结构性问题。

## 3. Listing前台完整性
- 指标代码：listing_frontend_integrity
- 定义：标题、图片、价格、变体、库存、购买按钮等是否正常展示。
- 状态：正常 / 部分异常 / 严重异常。
- 联动：转化、流量、商品状态、合规。

## 4. 变体关系健康度
- 指标代码：variation_integrity
- 定义：父子关系、主题、子体展示和评论共享等结构是否处于预期状态。
- 联动：流量分配、CVR、Review、商品状态。
- 说明：平台规则和前台展示可能变化，不以历史经验替代最新事实。

## 5. 合规/资质风险信号
- 指标代码：compliance_risk_signal
- 典型来源：政策通知、资质审核、危险品分类、知识产权投诉、Listing冻结、账户健康通知。
- 强度建议：无 / 风险信号 / 已确认风险 / 商品受限 / 账户级风险 / 恢复验证。
- 数据新鲜度：高要求，应使用最新官方信息。
- 状态映射：R5 合规与账户风险。

## 6. 账户健康与绩效信号
- 指标代码：account_health_signal
- 包括：账户健康警报、订单缺陷、迟发、取消、政策违规等与当前业务相关的正式信号。
- 说明：具体平台指标和规则可能变化，必须以当前官方定义为准。

## 7. 配送/履约异常
- 指标代码：fulfillment_risk_signal
- 包括：FBA不可售、配送承诺显著异常、仓储/入库异常、配送限制等。
- 联动：库存、转化、Buy Box、活动承接。

## 风险区间原则
这类指标优先采用事实等级而非百分比阈值：
- 正常：无有效风险信号；
- 关注：弱信号或待确认异常；
- 预警：已确认且会影响经营；
- 停止/禁止：不可售、账户级风险或明确硬约束触发。

## 核心原则
商品可售和合规信号优先级高于一般增长指标。强事实可以由单一A级证据直接触发状态，不需要为了“多指标验证”延误风险处理。
