# 广告指标

## 1. CPC
- 指标代码：advertising_cpc
- 公式：广告花费 / 点击。
- 联动：CTR、CVR、ACOS、竞价、广告位置、关键词竞争。
- 误判：CPC下降不一定更好，可能意味着拿不到高价值流量。

## 2. ACOS
- 指标代码：advertising_acos
- 公式：广告花费 / 广告销售额。
- 推荐窗口：7/14/30天；新品和低单量词需结合样本。
- 联动：CPC、CVR、客单价、毛利、自然排名、生命周期。
- 不能单独使用：高ACOS可能是无效亏损，也可能是新品学习、关键词资产建设或活动承接。

## 3. ROAS
- 指标代码：advertising_roas
- 公式：广告销售额 / 广告花费。
- 说明：与ACOS互为倒数关系的效率表达方式。

## 4. TACOS
- 指标代码：tacos
- 公式：广告花费 / 总销售额。
- 用途：判断广告成本对整体经营的侵蚀以及广告与自然销售联动。
- 联动：广告销售占比、自然销售占比、利润、关键词排名、生命周期。

## 5. CPA / CPO
- 指标代码：advertising_cost_per_order
- 公式：广告花费 / 广告订单。
- 联动：单位贡献利润、可接受获客成本、复购/长期价值（若适用）。

## 6. 广告CTR
- 指标代码：advertising_ctr
- 公式：广告点击 / 广告曝光。
- 联动：关键词相关性、主图、标题、价格、位置。

## 7. 广告CVR
- 指标代码：advertising_cvr
- 公式：广告订单 / 广告点击。
- 联动：Search Term意图、Listing整体CVR、价格、Rating、位置。

## 8. 预算利用率
- 指标代码：budget_utilization_rate
- 定义：实际广告花费相对可用预算的利用程度。
- 用途：识别预算限制或“预算烧不完”问题。
- 联动：曝光、竞价、相关性、流量规模、广告资格。
- 误判：预算未花完不一定需要提价，可能是流量池小或结构问题。

## 9. 广告销售占比
- 指标代码：ad_sales_share
- 公式：广告销售额 / 总销售额。
- 联动：自然销售、TACOS、自然排名、生命周期。
- 解释：新品期高占比可能正常；成熟产品持续高依赖需检查自然资产。

## 10. 搜索词转化效率
- 指标代码：search_term_conversion_efficiency
- 观察字段：Search Term点击、订单、销售额、ACOS/CPA、相关性。
- 用途：Broad/Phrase/Auto探索，识别Exact候选与否词候选。

## 11. 搜索词探索价值
- 指标代码：search_term_discovery_value
- 定义：除直接订单外，搜索词是否提供新的关键词、意图、场景或自然资产线索。
- 说明：属于复合判断，不应只按ACOS衡量。

## 12. 边际广告效率
- 指标代码：marginal_ad_efficiency
- 定义：增加一单位广告投入带来的新增销售、利润或战略价值。
- 用途：决定是否继续放量，而不是只看平均ACOS。
- 数据条件不足时应标记为估算。

## 13. 广告重复/内耗信号
- 指标代码：advertising_overlap_signal
- 观察：同ASIN、同Search Term在多个活动/匹配方式中的重复触达、CPC与转化差异。
- 用途：识别流量重复、结构冗余和归因混乱。

## 盈亏平衡关系
广告不能脱离利润判断：
- 盈亏平衡ACOS应由产品贡献毛利结构推导；
- 可接受ACOS可以高于或低于盈亏平衡ACOS，取决于当前目标与战略预算；
- 战略性亏损必须有时间、预算、验证目标和停止条件。

## 核心判断链
```text
曝光拿不到 → 资格/竞价/相关性/预算/流量池
有曝光没点击 → CTR与吸引力
有点击没订单 → 流量意图 + Listing转化
有订单但ACOS高 → CPC/CVR/售价/利润结构
ACOS高但自然资产增长 → 判断是否为可接受战略投入
```

## 核心原则
Agent-1看广告时不只问“广告赚不赚钱”，还要问它是否带来学习、关键词资产、防守、测试或增量价值，以及这些价值是否值得当前成本。
