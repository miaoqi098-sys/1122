# 经营状态识别指标映射

## 目的
把经营指标库与 `经营状态识别/` 接起来，明确不同经营状态通常需要哪些指标和信号支持。

本文件不提供统一固定数值，而提供“状态 ← 指标组合”的判断结构。

## 一、生命周期状态
### L1 新品冷启动
重点指标与信号：
- 上架与历史经营时间；
- 稳定订单是否形成；
- Sessions与流量入口数量；
- 广告搜索词有效性；
- 核心关键词自然排名；
- CVR稳定度；
- Review数量与增长；
- 价格和促销是否仍处于验证；
- 是否仍频繁进行核心经营测试。

### L2 成长期
重点指标与信号：
- 销量/订单趋势；
- Sessions增长；
- 自然流量占比；
- 核心词排名改善；
- 广告增量效率；
- CVR是否稳定或改善；
- 利润与TACOS是否可承受；
- 库存是否能支持放量。

### L3 成熟稳定期
重点指标与信号：
- 销量和Sessions波动幅度；
- 流量来源结构稳定度；
- 核心关键词位置；
- CVR稳定性；
- 利润稳定度；
- 库存周转；
- 广告依赖度；
- 市场份额/竞争位置。

### L4 衰退/调整期
重点指标与信号：
- 60/90天或同比需求下降；
- BSR/关键词排名持续恶化；
- Sessions持续下降；
- CVR或价格竞争力持续弱化；
- 利润/贡献持续下降；
- 库存周转恶化；
- 竞品结构性增强。

## 二、经营情境状态
### C1 正常经营
- 无活动/测试特殊窗口；
- 商品和风险指标未进入高等级预警；
- 关键经营指标处于当前产品正常基线附近。

### C2 测试期
不是由KPI触发，而由实验记录触发：
- 测试假设；
- 测试变量；
- 对照/基线；
- 观察窗口；
- 成功标准；
- 止损条件。

### C3-C5 活动准备/进行/恢复
主要信号：
- Deal/Coupon活动时间；
- 活动价格；
- 库存覆盖；
- 广告预算和流量承接；
- 活动前/中/后 Sessions、CVR、订单、利润；
- 自然排名恢复/沉淀。

### C6 价格保护期
主要信号：
- 当前成交价；
- List Price/Was Price；
- 历史成交价；
- Coupon/Deal/站外折扣；
- 活动资格与价格规则；
- 竞品价格；
- 单位利润。

## 三、风险状态
### R1 商品状态风险
主要信号：
- 是否可售；
- Buy Box状态；
- Listing前台异常；
- 变体关系异常；
- 后台抑制/冻结/错误提示；
- 价格或配送异常。

### R2 库存风险
核心组合：
- 可售库存；
- 7/14/30天销售速度；
- 库存覆盖天数；
- 在途数量与ETA；
- 补货提前期；
- 安全库存；
- 旺季/活动需求修正；
- 预计断货日期。

### R3 利润与现金风险
核心组合：
- 成交价；
- 单位贡献利润；
- 净利润率；
- 广告成本；
- TACOS；
- 退款/退货成本；
- 促销成本；
- 仓储成本；
- 现金占用；
- 盈亏平衡ACOS/CPA。

### R4 竞争加剧
核心组合：
- 竞品价格变化；
- Deal/Coupon变化；
- BSR变化；
- 核心词广告/自然占位；
- Review增速；
- 新竞品数量；
- 页面重大更新；
- 自身流量份额变化。

### R5 合规与账户风险
主要为强事实信号：
- 平台通知；
- Listing冻结/下架；
- 资质审核；
- 危险品状态；
- IP投诉；
- 账户健康与绩效问题；
- 申诉/恢复状态。

### R6 异常待诊断
通常由“结果显著偏离基线，但原因未知”触发，例如：
- 订单骤降；
- Sessions骤降；
- CVR骤降；
- TACOS突然升高；
- Rating快速下降；
- Buy Box异常；
- 价格/参考价异常。

## 四、机会状态
### O1 关键词与自然流量机会
- 核心词自然排名上升；
- Search Term出现高相关转化词；
- 广告词转自然资产迹象；
- 展现份额仍有空间；
- 边际流量仍可盈利或具有战略价值。

### O2 市场需求机会
- 类目需求增长；
- BSR改善与类目销量扩张；
- 季节/节日窗口临近；
- 搜索需求上升；
- 外部趋势增强。

### O3 竞争空档机会
- 主要竞品断货；
- 竞品涨价；
- 竞品Rating/Review恶化；
- 竞品促销退出；
- 竞品广告/排名位置减弱。

### O4 内容与转化机会
- CTR明显弱于可比基线；
- CVR弱于历史/同类基线；
- 负面VOC集中指向可修复信息缺口；
- 主图/A+/视频缺失或表达不足；
- 高流量但低转化搜索意图可被页面更好承接。

### O5 渠道与增长机会
- 新流量入口；
- 新广告类型；
- 新变体/组合；
- 新渠道；
- 新市场；
- 可控成本的实验机会。

## 五、映射使用规则
1. 状态由指标组合支持，不要求每次所有指标齐全。
2. 缺关键指标时必须降低置信度。
3. 强事实状态，例如已下架或已断货，可由单一A级证据直接确认。
4. 生命周期和结构性风险通常需要多窗口、多指标支持。
5. 同一指标可以支持多个状态，最终由状态识别模块结合上下文判断。
6. 状态识别结果应回写本次使用的指标、基线、阈值与证据等级。

## 核心原则
指标库负责提供“看什么、怎么算、如何比较”，状态识别负责回答“这些信号组合意味着当前处于什么经营状态”。
