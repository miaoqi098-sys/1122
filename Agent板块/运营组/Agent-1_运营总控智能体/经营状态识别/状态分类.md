# 经营状态分类

## 目的
将原本平铺的状态名称整理成四个维度，避免把生命周期、经营动作、风险和机会混为同一种状态。

# 一、生命周期状态
生命周期描述产品当前主要发展阶段。原则上同一时间只保留一个主要生命周期状态。

## L1 新品冷启动
产品仍在建立基础流量、转化认知、关键词资产、Review基础和稳定订单模型。

不得仅用“上架多少天”判断。老 ASIN 大幅重构、重新定位后也可能重新进入类似冷启动状态。

## L2 成长期
产品已经形成基本可售与转化能力，销量、自然流量、关键词资产或市场份额仍有明显扩张空间。

应同时关注增长质量，避免把纯促销或亏损换来的销量误认为健康成长。

## L3 成熟稳定期
产品已经形成相对稳定的销量、流量结构、转化基础和经营模型，重点从验证转向效率、利润、防守和持续优化。

## L4 衰退/调整期
需求、竞争力、利润、流量或产品生命周期出现持续弱化，需要修复、重新定位、清库存、改版或退出。

# 二、经营情境状态
经营情境描述当前正在发生或主动执行的经营活动，可以同时存在多个。

## C1 正常经营
没有特殊活动、重大实验或异常保护窗口，当前策略处于常规执行和观察状态。

## C2 测试期
正在执行有明确假设、变量、观察窗口、成功标准和止损条件的实验。

测试状态必须携带：
- 测试对象；
- 测试假设；
- 开始时间；
- 观察窗口；
- 成功标准；
- 止损条件；
- 允许变化的变量。

## C3 活动准备期
BD、LD、Prime Deal、Coupon、大促或其他重要促销即将开始，当前策略重点包括资格、库存、价格和流量承接准备。

## C4 活动进行期
重要促销正在运行。活动期间的数据不得机械作为正常经营基线。

## C5 活动恢复期
促销已经结束，但销量、流量、价格、自然排名和库存可能仍受活动影响，需要判断恢复速度和活动后遗效应。

## C6 价格保护期
当前存在明确的参考价、促销资格、价格历史或其他价格体系保护目标。

必须记录保护对象、原因、开始/结束条件、受限动作和允许动作。

# 三、风险状态
风险状态允许多个同时存在，并应标记严重程度。

## R1 商品状态风险
包括购物车、变体、Listing可售、前后台异常、页面异常等影响正常销售的问题。

## R2 库存风险
根据可售库存、在途、销售速度、补货周期、安全库存和季节因素识别。

建议状态等级：安全 / 预警 / 高风险 / 断货临界 / 已断货。

## R3 利润与现金风险
包括单位利润恶化、总利润下降、广告成本挤压、促销亏损、现金占用或现金安全边际不足。

应区分战略性短期投入与不可持续亏损。

## R4 竞争加剧
竞争环境出现明显变化，例如持续降价、广告占位增强、排名提升、新品进入、Review快速积累或流量份额变化。

必须区分短期动作与结构性竞争变化。

## R5 合规与账户风险
包括政策、资质、危险品、知识产权、Listing冻结、绩效和账户风险。

建议至少区分：风险信号 / 已确认风险 / 商品受限 / 账户级风险 / 恢复验证。

## R6 异常待诊断
发现重要经营异常，但原因尚未得到足够证据确认。

该状态用于触发进一步诊断，不代表已经确认根因。

# 四、机会状态
机会状态允许多个同时存在，也允许与风险同时存在。

## O1 关键词与自然流量机会
关键词排名、自然曝光、搜索需求或广告学习结果显示存在进一步获取高质量流量的窗口。

## O2 市场需求机会
类目需求、季节性、消费者趋势或外部事件形成新的需求增长窗口。

## O3 竞争空档机会
竞品断货、涨价、评价恶化、退出、内容弱点或竞争结构变化形成可利用空间。

## O4 内容与转化机会
Listing、主图、A+、视频、变体结构、价格呈现或信任要素存在明确改善空间。

## O5 渠道与增长机会
新广告入口、新站外渠道、新组合、新变体、新市场或其他增长实验具备合理验证价值。

# 五、状态不是结果指标
以下本身不是经营状态：
- ACOS上升；
- CTR下降；
- 销量上涨；
- 流量下降；
- CVR上涨。

它们首先是现象或指标变化，必须结合时间、经营阶段、上下文和其他证据判断是否构成某种状态。

# 六、状态画像示例
```text
生命周期：L2 成长期
经营情境：C4 活动进行期 + C2 Exact关键词测试
风险状态：R2 库存预警
机会状态：O1 核心关键词自然排名增长机会
```

Agent-1 不应问“它到底属于哪一个状态”，而应问“当前完整状态组合是什么，以及这个组合对目标和决策意味着什么”。
