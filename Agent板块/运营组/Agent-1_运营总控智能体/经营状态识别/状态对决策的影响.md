# 经营状态对决策的影响

## 目的
经营状态识别不是为了贴标签，而是为了改变 Agent-1 的目标权重、指标解释、知识调用、风险判断和行动方式。

## 一、状态影响五个核心对象
每个重要状态至少应影响：
1. 当前主目标与副目标；
2. 指标解释方式；
3. 需要加载的经营知识和专业 Agent；
4. 允许的行动强度和风险偏好；
5. 观察窗口与验证方式。

## 二、生命周期对决策的影响
### 新品冷启动
决策倾向：
- 优先验证可售、流量入口、转化和关键词资产；
- 允许合理的学习成本；
- 不因短期 ACOS 或少量点击立即否定方向；
- 更重视有效学习速度和可重复增长信号；
- 仍必须受库存、利润底线和合规约束。

### 成长期
决策倾向：
- 追求高质量增长；
- 关注自然资产、市场份额和边际收益；
- 判断供应链和利润是否能承接放量；
- 避免为了增长破坏库存和价格体系。

### 成熟稳定期
决策倾向：
- 提高利润、效率和防守权重；
- 保护核心流量和市场位置；
- 优化广告、库存周转和价格体系；
- 对大规模高风险实验要求更强证据。

### 衰退/调整期
决策倾向：
- 先判断可修复性；
- 比较修复、重新定位、降本、清库存和退出方案；
- 降低对历史策略的路径依赖；
- 更关注现金回收和机会成本。

## 三、经营情境对决策的影响
### 正常经营
使用常规经营基线和正常观察窗口。

### 测试期
- 不在观察窗口未结束且未触发止损时频繁反向调整；
- 避免同时修改会污染测试结果的关键变量；
- 测试结论必须与原假设和成功标准比较。

### 活动准备期
提高库存、价格资格、促销条件、广告承接和页面准备优先级。

### 活动进行期
- 活动数据与正常期分开解释；
- 关注库存消耗、利润、流量承接和异常；
- 不用活动期 CVR、销量等直接重设正常经营基线。

### 活动恢复期
- 判断活动后回落是否正常；
- 观察自然排名、流量、价格和转化恢复；
- 识别活动是否留下长期资产或负面影响。

### 价格保护期
涉及价格、Coupon、Deal和站外折扣的动作提高谨慎程度，并检查是否影响参考价、活动资格或长期价格空间。

## 四、风险状态对决策的影响
### 商品状态风险
优先恢复正常可售和购买路径。严重商品状态问题可以暂停增长型动作。

### 库存风险
随着风险升级：
- 增长目标逐步降权；
- 广告和促销从放量转向高价值流量保护；
- 深折扣和低质量流量动作受到限制；
- 补货和库存分配优先级上升。

### 利润与现金风险
- 检查增长质量；
- 限制不可持续亏损；
- 区分战略性投资和结构性亏损；
- 必要时提高现金回收和单位经济性权重。

### 竞争加剧
- 先判断临时动作还是结构性变化；
- 再决定防守、差异化、价格、促销、内容或新流量策略；
- 不因竞品一次动作立即跟价或大改策略。

### 合规与账户风险
高等级合规/账户风险可直接压制增长目标，并触发 Agent-12、权限和审批机制。不得以销量或排名为理由绕过合规约束。

### 异常待诊断
- 暂缓高影响不可逆动作；
- 优先诊断和补关键证据；
- 加载相关异常诊断卡；
- 根据证据逐步转成具体风险、机会或正常扰动。

## 五、机会状态对决策的影响
机会状态主要提高对应增长方向进入候选方案的优先级，但不自动授权执行。

### 关键词与自然流量机会
检查是否值得增加高质量流量、加强关键词承接或调整广告与自然协同。

### 市场需求机会
检查季节窗口、库存、供应链和竞争强度是否支持抓取需求。

### 竞争空档机会
判断空档持续时间以及是否值得用广告、价格、内容或库存优势快速承接。

### 内容与转化机会
优先评估页面优化是否能够在不破坏当前测试或活动的情况下提升转化。

### 渠道与增长机会
进入 Agent-13 或相关专业 Agent 的实验候选池，经过风险、成本和资源评估后再执行。

## 六、多状态组合示例
### 示例1：成长期 + 活动期 + 库存预警 + 自然排名机会
Agent-1 不应简单“继续放量”。

应理解为：
- 生命周期支持增长；
- 活动正在放大需求；
- 自然排名出现机会；
- 但库存成为当前限制条件。

因此主目标可能从“最大化增长”切换为“保护库存前提下保留高价值增长资产”。

### 示例2：新品冷启动 + Exact测试 + 61点击0订单
不能直接判定关键词无价值。

应检查：
- 样本是否足够；
- 搜索意图；
- Listing承接；
- 价格竞争力；
- 广告位置和流量质量；
- 自然排名变化；
- 测试观察窗口是否结束。

### 示例3：成熟稳定期 + 合规风险
即使当前利润和销量很好，主目标也应切换为账户/商品安全和风险解除，增长动作降级。

## 七、与目标系统联动
状态识别完成后，应向目标系统提供：
- 当前主要生命周期；
- 当前经营情境；
- 风险列表及严重程度；
- 机会列表及强度；
- 当前主导状态；
- 建议提高权重的目标；
- 建议降低或暂停的目标；
- 建议复核时间。

目标系统最终决定主目标、副目标和暂停目标。

## 八、与大脑联动
大脑不得跳过经营状态直接解释指标。

同一个指标在不同状态下可能含义不同，例如：
- 新品期高 ACOS 可能代表学习成本；
- 成熟期持续高 ACOS 可能代表效率恶化；
- 活动期 CVR 提升不能直接作为正常期基线；
- 库存风险期销量快速增长可能反而扩大断货风险。

## 核心原则
状态本身不直接产生答案。它改变的是 Agent-1 看问题的上下文，使同一组数据在正确的经营背景下被解释，并让目标、知识、风险和行动强度保持一致。
