# 新品冷启动经营

## 核心目标
新品冷启动的首要任务不是立即把所有指标做到成熟期水平，而是尽快验证“有效流量 → 转化 → 关键词资产 → 可复制增长路径”是否成立。

## Agent-1必须识别的四个阶段
1. 基础可售：Listing、价格、库存、购物车、合规状态正常。
2. 流量验证：测试核心词、场景词、长尾词和不同流量来源。
3. 转化验证：确认哪些流量能产生真实购买，识别Listing与价格短板。
4. 放量验证：将已验证路径扩大，并观察自然排名、TACOS、利润和库存承接。

## 新品期不能直接套用成熟品规则
新品可能出现：
- ACOS偏高；
- CVR波动大；
- 单个关键词样本不足；
- 广告销售占比高；
- 自然流量弱；
- 评论基础不足。

这些现象本身不等于策略失败。

## Agent-1应重点观察
- 核心关键词是否开始产生有效点击和订单；
- 哪些搜索词有明确购买意图；
- Listing是否存在明显理解障碍；
- 价格是否落在合理竞争带；
- 评论和信任基础是否足以承接流量；
- 广告投入是否带来自然位置改善；
- 库存是否足够支持测试与后续放量。

## 冷启动决策原则
- 先验证方向，再追求效率；
- 先保留有战略价值且有信号的流量，再淘汰明确无效流量；
- 不因短期无单就过早砍掉所有探索；
- 不允许无预算边界的“烧钱换排名”；
- 任何高成本探索都必须有观察窗口、样本要求和停止条件。

## 常见误判
- 新品ACOS高，所以广告结构一定错误；
- 前几天没自然单，所以Listing没机会；
- 某词几十次点击无单，就永远没有价值；
- 有广告订单，就说明广告带来真实增量；
- 一旦开始出单，就应该立刻大幅加预算。

## 何时从冷启动转向成长期
需要综合看到：
- 至少一批稳定有效关键词；
- 转化开始具备可解释性；
- Listing没有重大基础缺陷；
- 自然流量或自然排名出现持续改善；
- 库存、利润和价格允许扩大；
- 扩量路径可以被重复验证。
