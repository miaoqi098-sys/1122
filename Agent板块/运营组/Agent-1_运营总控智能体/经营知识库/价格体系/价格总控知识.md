# 价格总控知识

## 核心定位
价格不是单独的“转化按钮”，而是同时影响转化、利润、参考价、促销空间、消费者预期和长期品牌定位的经营变量。

## Agent-1 需要同时关注
- 当前成交价；
- 日常售价；
- List Price / 参考价状态；
- 历史成交价；
- Coupon；
- BD、LD、Prime等促销；
- 站外折扣；
- 竞品价格；
- 单位利润；
- 转化率；
- 价格变化后的销量弹性；
- 库存与清仓压力。

## 基本原则
1. 不以短期转化最大化替代长期价格体系。
2. 价格调整必须明确目的：测试、放量、防守、促销、清仓、恢复利润或建立参考价。
3. 活动价和正常价必须分开分析。
4. 价格下降产生销量增长时，要判断增长是否足以覆盖利润损失。
5. 价格上涨导致转化下降时，要判断利润总额和市场位置是否反而改善。
6. 涉及参考价、最低价、促销资格等平台机制时，应优先获取最新规则和真实历史数据，不凭旧经验强行判断。

## 常见误判
- 竞品降价，因此自己必须跟价。
- 转化下降，因此一定是价格过高。
- 低价销量更高，因此低价一定更优。
- 活动期间的高转化可以作为正常期转化基准。
- 一次促销成功意味着长期维持促销价更好。

## 降价前检查
- 当前问题是否真由价格导致；
- 毛利与净利空间；
- 是否影响参考价和未来促销空间；
- 库存是否需要加速周转；
- 竞品价格变化是否临时；
- 是否有Listing、评价、流量质量等更根本问题。

## 涨价前检查
- 当前转化与自然位置是否稳定；
- 竞品价格带；
- 产品差异化；
- 预计转化损失；
- 单位利润提升是否能抵消销量损失；
- 当前是否处于重要活动或排名爬升窗口。

## Agent协作
主要来源：Agent-10 促销价格智能体。
重大价格决策通常联动 Agent-6 利润、Agent-5 流量、Agent-7 库存、Agent-3 竞品、Agent-9 转化，并受 Agent-12 合规/规则风险约束。
