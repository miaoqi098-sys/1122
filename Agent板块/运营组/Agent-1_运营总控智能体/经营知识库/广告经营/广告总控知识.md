# 广告总控知识

## Agent-1 对广告的定位
Agent-1 不负责代替 Agent-4 做具体广告操作，而是判断广告投入是否服务于产品整体经营目标。

广告的价值可能包括：
1. 直接产生可盈利销售。
2. 获取新品早期有效流量和转化数据。
3. 建立关键词成交与自然排名资产。
4. 防守品牌词、核心词和竞品流量。
5. 验证新关键词、新受众或新场景。
6. 在活动期承接额外需求。

因此不能只用 ACOS 判断广告价值。

## 广告判断必须联动的维度
- 广告销售与广告成本；
- ACOS、CPC、CTR、CVR；
- TACOS；
- 自然销售占比；
- 关键词自然排名趋势；
- 产品毛利和可接受获客成本；
- 库存覆盖；
- 当前价格和促销；
- Listing 转化能力；
- 产品生命周期；
- 竞争环境。

## 常见总控误判
### 误判一：ACOS高就立即暂停
可能忽略新品探索、关键词自然排名提升、战略关键词价值或样本不足。

### 误判二：ACOS低就持续加预算
可能忽略库存不足、广告抢占本来自然成交、流量天花板或利润结构变化。

### 误判三：点击多不出单就认定关键词无价值
需要进一步判断搜索意图、匹配方式、广告位、Listing承接、价格、竞品促销、样本量和自然排名变化。

### 误判四：广告销售上涨等于广告带来增量
必须观察自然销售、TACOS和整体销量变化，避免只是把自然成交转移到广告成交。

## 广告扩量前检查
至少确认：
- 有真实转化或明确战略价值；
- 利润/预算可承受；
- 库存可承接；
- Listing 没有明显转化短板；
- 当前价格策略允许放量；
- 扩量有观察窗口与止损条件。

## 广告收缩前检查
至少确认：
- 数据窗口足够；
- 是否处于活动期/新品期等特殊阶段；
- 是否存在自然排名价值；
- 是否能通过降竞价、改匹配、否词、调整广告位等更可逆方式优化；
- 收缩是否会伤害核心关键词或整体流量结构。

## Agent协作
主要来源：Agent-4 广告运营智能体。
重大判断通常联动：Agent-5 流量、Agent-6 利润、Agent-7 库存、Agent-9 内容转化、Agent-10 价格促销，必要时 Agent-3 竞品。
