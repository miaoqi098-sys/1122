# 广告扩量与收缩

## 目的
Agent-1负责判断“什么时候值得扩大广告、什么时候应该收缩”，而不是代替Agent-4执行具体竞价与结构调整。

## 扩量前必须回答
1. 当前流量是否已经验证有价值？
2. 增量预算预计买到什么：订单、关键词排名、市场份额还是测试数据？
3. 利润与现金流能否承受？
4. 库存是否能承接？
5. Listing转化是否足够稳定？
6. 价格与促销状态是否适合放量？
7. 扩量后如何判断成功？

## 适合扩量的信号
- 关键词或广告组已有稳定转化；
- 预算限制明显压制有效流量；
- 自然排名与广告转化形成正反馈；
- 产品处于增长窗口或活动窗口；
- 库存、利润和价格体系允许；
- 竞品流量机会明显增大。

## 不宜盲目扩量的情况
- 高点击低转化原因未查清；
- Listing存在重大转化短板；
- 库存覆盖偏低；
- 当前利润已经跌破底线；
- 价格正在异常或活动状态不清；
- 只是因为单日表现很好；
- 自然流量没有同步改善且广告疑似替代自然成交。

## 收缩不等于暂停
收缩优先级通常可以从低风险动作开始：
1. 降低竞价；
2. 降低低价值位置溢价；
3. 限制预算；
4. 否定明显无关搜索词；
5. 将高价值搜索词迁移到更可控匹配；
6. 暂停明确低价值目标；
7. 最后再考虑关闭整个广告活动。

## 收缩前检查
- 当前是否处于新品测试期；
- 当前是否处于BD/LD/Coupon等活动期；
- 关键词是否有自然排名战略价值；
- 样本是否足够；
- 是否存在更可逆的优化手段；
- 收缩是否会造成核心流量断层。

## 观察窗口
扩量或收缩后应预先定义观察窗口，不因1-2天波动立即反向操作。若触发库存、利润、合规等止损条件，可提前终止。
