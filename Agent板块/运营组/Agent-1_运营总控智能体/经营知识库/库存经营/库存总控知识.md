# 库存总控知识

## 核心定位
库存既是增长能力，也是经营风险。库存不足会限制广告、促销和自然排名增长；库存过多会占用现金、增加仓储与清仓压力。

## Agent-1 关注的库存维度
- FBA可售库存；
- 在途库存；
- 入库/转运状态；
- 日均销量与趋势；
- 库存覆盖天数；
- 补货提前期；
- 旺季/淡季；
- 计划促销造成的销量变化；
- 库龄与长期仓储风险；
- 供应链稳定性。

## 基本原则
1. 库存覆盖不能只按当前平均销量计算，应考虑趋势、活动和季节性。
2. 在途库存不能与可售库存等价看待，应考虑延误概率和实际可售时间。
3. 当断货风险明显上升时，应重新评估广告扩量、促销和降价计划。
4. 当库存严重积压时，可以提高周转目标权重，但仍需评估利润和价格体系代价。
5. 断货前的最后一批库存不应为了维持短期销量盲目高成本获取流量。

## 放量前库存检查
- 当前可售天数；
- 在途到仓时间；
- 放量后的预计销量；
- 促销期间峰值需求；
- 补货能否在安全库存前到达；
- 如果到货延误，是否有降速方案。

## 库存不足时的可能动作
按实际情况组合：
- 降低低价值广告流量；
- 保护高价值核心关键词；
- 减少深折扣；
- 推迟部分促销；
- 调整价格控制销售速度；
- 加速补货；
- 优先保证利润更高或战略价值更高的流量。

## 库存过多时的判断
不要直接等于“降价清仓”。应先判断：
- 是需求不足、流量不足还是转化不足；
- 产品是否还有季节机会；
- 是否可以通过内容、广告、促销解决；
- 清仓对价格体系的长期影响；
- 继续持有库存的现金和仓储成本。
