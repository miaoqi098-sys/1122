# 库存积压处理

## 核心定位
库存积压不是单纯的“卖得慢”，而是现金占用、仓储成本、价格空间和未来采购能力共同恶化的问题。Agent-1必须先诊断积压原因，再决定清理方式。

## 先判断积压类型
- 需求不足：市场规模或季节性下降；
- 流量不足：曝光或关键词覆盖不够；
- 转化不足：Listing、价格、评价或产品力问题；
- 供给过量：采购/补货超过真实需求；
- 竞争变化：竞品降价、新品替代、类目变化；
- 生命周期问题：产品进入衰退或季节结束。

## 处理优先级
1. 查清积压原因；
2. 判断产品还有没有正常经营价值；
3. 评估继续持有库存的成本；
4. 比较内容优化、广告扩量、促销、降价、组合销售、清仓等方案；
5. 为清库存策略设置价格底线与时间边界；
6. 同步调整后续采购和补货计划。

## 不应机械执行
- 一积压就直接最低价清仓；
- 只加广告而不修转化；
- 只做深折扣而不考虑参考价和长期品牌影响；
- 明知需求结构已改变仍按历史销量补货。

## 决策核心
如果产品仍有可修复的正常经营价值，优先修复；如果继续持有的成本和机会成本高于未来收益，应逐步提高去库存优先级。

## Agent协作
Agent-7库存、Agent-6利润、Agent-8市场趋势、Agent-9内容转化、Agent-10价格促销、Agent-4广告。
