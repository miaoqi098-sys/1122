# 异常诊断卡：购物车丢失

## 触发信号
Listing仍可访问，但购物车丢失、转化突然下降或广告点击后购买能力明显受影响。

## 不能直接下的结论
- 不能默认是价格问题。
- 不能只通过降价抢回购物车。
- 不能忽略配送、库存、账户健康和其他卖家竞争。

## 优先排查顺序
1. 当前是否仍有可售库存。
2. 配送时效和FBA状态是否异常。
3. 是否存在其他卖家竞争同一ASIN。
4. 当前价格与历史价格、竞品价格是否异常。
5. 是否出现账户绩效、商品状态或抑制问题。
6. 是否存在区域性、临时性前台异常。
7. 广告是否仍在持续消耗但无法正常转化。

## 需要请求的Agent
- Agent-2：商品状态、购物车、库存可售状态。
- Agent-7：库存与配送状态。
- Agent-10：价格与促销。
- Agent-12：若涉及账户/政策异常。
- Agent-4：判断是否需要临时收缩广告。

## 可选动作
- 若确认购物车异常且短期无法恢复，临时降低无效广告消耗。
- 若为价格竞争问题，评估降价对利润和价格体系影响后再处理。
- 若为库存/配送问题，优先恢复可售能力。
- 若为账户或Listing抑制，优先处理商品状态和合规问题。

## 升级条件
购物车持续丢失且影响核心ASIN销售，应提升至商品可售级高优先级事件；若伴随抑制、账户通知或合规提示，立即联动Agent-12。
