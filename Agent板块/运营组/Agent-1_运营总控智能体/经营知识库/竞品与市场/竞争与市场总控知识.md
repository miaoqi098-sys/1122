# 竞争与市场总控知识

## 核心定位
竞品数据用于理解市场变化和寻找机会，不用于机械模仿。Agent-1 关注的是竞争变化是否改变当前产品的经营策略。

## 需要关注的变化
- 主要竞品价格和促销；
- 排名与销量趋势；
- 新品进入；
- Listing、图片、卖点和规格变化；
- Review增长和消费者反馈；
- 广告可见度；
- 产品组合与变体；
- 市场季节性；
- 搜索需求和关键词变化；
- 类目整体增长或衰退。

## 基本原则
1. 竞品降价不代表必须跟价。
2. 竞品销量上涨应区分价格、促销、流量、产品差异、季节性等原因。
3. 单一竞品动作不应自动触发重大策略变化。
4. 优先寻找结构性变化，而不是对短期噪声过度反应。
5. 市场趋势必须与自身产品数据交叉验证。
6. 发现机会后，应判断是否符合自身供应链、利润、品牌和执行能力。

## 竞争变化后的常见策略方向
- 防守核心流量；
- 强化差异化内容；
- 调整价格/促销节奏；
- 开发新场景词或细分需求；
- 改善产品组合；
- 暂不跟随，继续观察；
- 将机会提交 Agent-13 做增长实验设计。
