# 风险与合规总控知识

## 核心定位
账户安全、商品可售和合规是高于短期销售、广告效率和增长机会的硬约束。Agent-1 负责识别经营决策是否触碰风险边界，但专业合规判断应由 Agent-12 提供。

## 高优先级风险方向
- Listing被冻结或下架；
- 资质审核；
- 危险品/电池/运输限制；
- 知识产权投诉；
- 账户绩效；
- 变体与父子体合规；
- 评论与促销合规；
- 产品安全；
- 平台政策变化；
- 可能导致不可逆损失的操作。

## 基本原则
1. 不为了维持销量继续执行可能扩大合规风险的动作。
2. 对政策、资格、平台规则等时效性信息，不依赖过期记忆，应获取当前官方规则或 Agent-12 的最新判断。
3. 合规问题区分：事实、平台通知、推测原因、证据、可执行申诉动作。
4. 未确认原因前不做可能破坏证据或扩大问题的高风险修改。
5. 合规申诉、资质提交、删除父子关系等高风险动作必须按权限矩阵审批。
6. 经营策略必须允许因风险事件临时中断，例如停止广告放量、暂停促销或冻结内容修改。

## 风险事件发生时 Agent-1 的动作
- 提升事件优先级；
- 请求 Agent-12 专业判断；
- 识别受影响的销售、库存、广告、价格和现金流；
- 暂停与风险冲突的计划；
- 形成短期止损方案和恢复方案；
- 记录证据、时间线和已执行动作。

## Agent协作
主要来源：Agent-12 风险合规智能体。
根据影响联动 Agent-2 商品状态、Agent-7 库存、Agent-6 利润、Agent-4 广告、Agent-10 价格促销等。
