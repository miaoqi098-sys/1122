# 自主循环 06｜学习

## 1. 目标
把ValidationResult转化为可复用但带适用边界的LearningRecord和memory_writes计划，为未来判断提供经验，而不是把一次结果直接固化为永久规则。

## 2. 正式映射
`ValidationResult → S09 LearningWriteback → LearningRecord / knowledge candidates / memory_writes plan → LearningWriteExecutor（R10，未来）`

## 3. 学习动作
1. 保留decision_id/task_id/execution_result_id/validation_id等完整来源链。
2. 区分事实、解释、假设、可复用经验和待验证规律。
3. 记录哪些假设被支持、被否定或仍不确定。
4. 记录策略结果及其适用scope、经营状态、活动背景、时间窗口和证据质量。
5. 识别一次性结果与可能可复用规律，避免过度泛化。
6. 形成LearningRecord、knowledge candidates和memory_writes plan。
7. 若发现既有规则可能不合理，生成规则修订候选/任务，不静默改写已封板核心规则。
8. 真实写入长期记忆必须等待LearningWriteExecutor回执。

## 4. 输出
- LearningRecord；
- fact/interpretation层次；
- knowledge candidates；
- memory_writes plan；
- 适用范围、新鲜度和失效条件；
- 下一轮观察重点/触发条件；
- 必要的规则修订候选。

## 5. 边界
- S09生成write plan，不得自行声称`written`。
- 不直接改历史事实；修订必须通过版本/追加记录。
- 不把单次成功自动升级成全局经营规则。
- 不因执行失败就学习“策略失败”。
- 真实持久化、索引和写入回执属于R06/R10。

## 6. 下一轮
学习完成不等于立即重新跑六阶段。只有新Event、新证据、review trigger、观察窗口结束、审批结果、stop condition或经营状态变化出现时，才进入下一轮相关阶段。
