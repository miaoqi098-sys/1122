# Agent-1 权限矩阵

本文件定义 Agent-1 对不同类型动作的**权限/影响等级参考**。等级用于表达可见范围、动作影响、可逆性和默认执行边界；**不再等同于固定审批等级**。

是否需要审批，必须结合：
- 身份与权限边界；
- 动作影响与可逆性；
- 当前经营状态和hard constraints；
- S06 RiskAssessment；
- FinalDecision中的approval requirements/state；
- S07 Task审批节点；
- 当前授权范围。

## 权限/影响等级
- **L0｜读取与分析**：只读、汇总、诊断、请求信息、生成候选方案，不产生真实经营变更。
- **L1｜低影响可逆动作**：影响范围有限、可快速恢复，并有明确guardrail/stop condition/rollback条件。
- **L2｜重要经营动作**：可能明显影响销售、价格、预算、库存、利润、客户体验或策略方向，需要更严格的风险/授权检查；是否人工审批由FinalDecision/S07正式判断。
- **L3｜高影响/高风险/不可逆动作**：涉及账户、合规、资质、知识产权、删除、结构性变更或不可逆影响。默认不得无人值守自动执行，通常需要明确人工授权；具体approval requirements仍通过正式决策链表达。

> L0-L3是权限/影响分类，不是“动作命中某等级就自动生成固定审批结果”的第二套审批真源。

## 动作权限参考矩阵
| 动作类型 | 影响等级参考 | 关键要求 |
|---|---|---|
| 读取其他Agent事件与分析结果 | L0 | 保留来源、时间与证据 |
| 读取历史与经营数据 | L0 | 记录scope与数据新鲜度 |
| 汇总分析与异常诊断 | L0 | 区分事实、解释、假设与建议 |
| 请求其他Agent补充分析 | L0 | 明确缺失字段和问题 |
| 生成候选运营方案 | L0 | 经过S05/S06，不直接执行 |
| 调整问题排序 | L0/L1 | business_priority仍由S04形成 |
| 创建分析/复查任务 | L0/L1 | 由S07建立Task并定义验收条件 |
| 暂停/恢复低风险测试 | L1 | 需命中规则、授权范围和恢复/止损条件 |
| 小范围广告竞价/预算调整 | L1/L2 | 影响等级随范围、幅度、库存、利润、活动期等变化 |
| 大幅广告预算/竞价调整 | L2/L3 | 必须评估风险、权限、可逆性与approval requirements |
| 修改售价 | L2/L3 | 检查利润、价格体系、促销、参考价与权限；不硬编码固定审批等级 |
| 创建/修改Coupon、BD、LD等促销 | L2/L3 | 检查资格、价格历史、利润、时间窗口与权限 |
| 调整补货、采购或库存分配 | L2/L3 | 结合覆盖天数、在途、现金、预测和可逆性 |
| 修改Listing核心内容 | L2/L3 | 保留旧版本、验证计划、合规与影响范围 |
| 删除广告活动或大规模否定流量 | L2/L3 | 优先可逆方案；需要明确影响与恢复策略 |
| 提交合规申诉或资质材料 | L3 | 必须有Agent-12或等效可靠专业证据，并满足正式审批要求 |
| 删除Listing、ASIN或重要数据 | L3 | 默认禁止无人值守执行 |
| 修改父子体关系/合并拆分变体 | L3 | 高影响结构动作，需明确人工授权与风险检查 |
| 账户健康、知识产权、危险品等高风险动作 | L3 | 不获得超越原身份权限的自动执行权 |

## 影响等级动态调整
同一动作的影响等级不是永久固定，可因以下因素上调：
- 影响金额、销量、预算、价格或库存规模扩大；
- 动作更难恢复或不可逆；
- 处于BD/LD、大促、旺季等关键经营窗口；
- 数据不足或专业Agent证据重大冲突；
- 涉及参考价、促销资格、平台政策；
- 涉及账户、合规、资质、知识产权、产品安全；
- 当前库存、利润、现金或策略链处于高风险状态。

影响等级上调只意味着更严格的授权/风险检查，**不直接替代FinalDecision的approval判断**。

## 自动执行前置条件
任何允许自动执行的动作必须同时满足：
1. 身份权限允许；
2. FinalDecision没有requires_approval/pending_approval阻断；
3. 数据完整且新鲜；
4. Option已通过S06 eligibility；
5. required_controls已传递；
6. 存在stop condition/rollback方式；
7. 不违反S10 hold/StrategyChain约束；
8. S07已生成合法Task；
9. 执行后有验证计划；
10. 全过程可追溯。

任一条件不满足时，应进入request_approval_context、pending_approval、blocked、needs_information或其他正式非执行路由，而不是简单“自动升级到某个L等级后继续”。

## 最小权限原则
Agent-1始终使用完成目标所需的最低权限和最低影响动作。能通过分析、观察、小范围可逆测试解决的问题，不直接采用更高影响或不可逆动作。
