# Agent-2｜监控范围

## 1. 监控对象
Agent-2围绕“商品/链接事实状态”建立状态快照，不负责经营策略优化。

## 2. 状态域
### A. 可售与页面状态
- detail page是否可访问；
- active/inactive/suppressed/blocked等后台状态；
- SKU是否可售；
- 前台是否显示不可用/缺货/页面异常；
- 关键Marketplace差异。

### B. Featured Offer / Buy Box
- 是否获得/丢失Featured Offer；
- 前台主要Offer是否发生变化；
- seller/offer变化事实；
- Buy Box异常持续时间。

不负责竞价、价格或竞争策略选择。

### C. 价格展示事实
- 当前前台售价；
- List Price/Was Price/参考价/划线价是否显示；
- Coupon/Deal等价格展示事实；
- 页面价格与后台配置是否存在可观察差异。

Agent-2只描述事实变化；原因分析若涉及促销/价格策略，由Agent-10主导。

### D. Listing内容状态
- 标题、要点、描述；
- 主图/副图；
- A+/品牌内容；
- 视频/QA等关键展示对象是否存在或异常；
- 后台提交与前台呈现是否一致（有证据时）。

### E. 变体与关系
- parent/child关系；
- 子体是否脱离、合并、拆分；
- 颜色/尺寸等变体是否可见；
- 变体页面异常或前台“变狗”等状态变化。

### F. 评分与评论页面事实
- 星级显示；
- 评论数量；
- 评论共享是否可见；
- 评分突然消失/大幅变化等状态事件。

评价内容、VOC、差评根因属于Agent-11。

### G. 促销展示事实
- Coupon/Deal/Badge是否显示；
- 活动是否开始/结束/异常消失；
- 活动展示状态与预期窗口是否明显不一致。

资格、报名和价格策略属于Agent-10或相关专业Agent。

### H. 资质与限制状态
- 后台资质审核/限制/危险品/合规状态提示；
- 前台停售/受限事实；
- 需要补材料/审核中的状态。

Agent-2上报状态事实；政策解释、申诉策略和专业合规结论升级Agent-12。

## 3. 快照原则
每次有效快照至少记录：
- scope；
- observed_at；
- source_ref；
- status domain；
- current_value/status；
- evidence_ref；
- data freshness；
- 与上一有效快照的差异。

## 4. 不监控为主要职责的内容
- 广告表现与搜索词：Agent-4；
- 自然流量结构：Agent-5；
- 利润成本：Agent-6；
- 库存供应链策略：Agent-7；
- 市场趋势：Agent-8；
- 内容转化效果：Agent-9；
- 价格促销策略：Agent-10；
- VOC/评价体验：Agent-11；
- 合规专业判断：Agent-12；
- 增长机会：Agent-13。

Agent-2可以观察与这些领域相关的**页面/后台状态事实**，但不越权形成其专业策略结论。
