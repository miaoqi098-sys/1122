## 3. 核心一致性检查
### Target / Search Term
已严格分离。Search Term是用户实际搜索表达，Target是投放对象；迁移/否定必须通过映射和证据判断。

### ACOS / 利润
已明确ACOS/ROAS不是利润；利润承受能力升级Agent-6，最终资源决策由Agent-1整合。

### 广告建议 / FinalDecision
所有竞价、预算、否定、结构建议均为candidate，必须保留evidence、confidence、risk、observation_window；不得直接创建最终经营动作。

### 变更与防抖
竞价、预算、结构迁移均要求历史引用和最小观察窗口；反向动作标记strategy_reversal_candidate并升级Agent-1/S10语义。
