# Agent-5｜历史证据与观察窗口

## 1. 需要保存的历史
- 来源结构快照；
- Query/关键词可见性、排名和份额快照；
- 流量异常/机会事件及状态；
- 关键跨Agent上下文：广告调整、价格促销、Listing变化、商品可售状态、竞品变化；
- Agent-1决策与后续验证引用。

## 2. 窗口
至少区分current_window、baseline_window、pre_change_window、post_change_window。发生重大活动、断货、价格变化、广告结构调整或Listing变更时，要标记change_at与confounders。

## 3. 基线选择
优先使用口径一致、业务环境可比的历史窗口。不可因为“上周同期”存在就机械使用；若同期有Deal/断货/重大价格差异，应降低可比性或选择替代基线。

## 4. 观察规则
短期流量脉冲不等于稳定增长；短期下降也不等于结构性损失。必须结合来源结构、Query持续性和外部变更判断。

## 5. 事件复用
同一scope与同一原因链上的持续事件优先更新，不重复创建；恢复后可resolved，之后新周期重新出现时引用历史事件。

## 6. 边界
真实持久化属于R06长期记忆数据库；本目录只定义Agent-5需要保存什么、如何做可比和如何引用。
