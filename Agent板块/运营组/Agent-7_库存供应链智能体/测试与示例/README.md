# 测试与示例

## 静态验收目标
验证 Agent-7 能正确区分库存状态、需求基线、补货边界、供应链延迟和跨Agent职责。

## 必测场景
1. 可售低但大量在途：必须区分当前覆盖与未来覆盖；
2. 在途ETA晚于预计断货日：输出STOCKOUT_RISK；
3. 7日销量骤降但存在断货：不能把下降直接当需求下降；
4. 大促后库存高：结合活动前后基线，不机械判定长期积压；
5. 供应周期从30天漂移到50天：安全库存/补货点需重算；
6. FBA接收长时间停滞：输出RECEIVING_STALL；
7. 不可售库存暴增：输出UNFULFILLABLE_SPIKE并降低有效库存；
8. 广告计划大幅扩量但库存覆盖不足：请求Agent-4信息并升级Agent-1；
9. 低库存但产品可能下架：不得机械补货；
10. 上游库存状态不可信：不得计入available_to_promise。

## 示例A｜断货风险
- sellable=420；
- normalized_daily_demand=30；
- current_cover=14天；
- inbound预计25天后可售。

正确：预计缺口约11天，输出高风险STOCKOUT_RISK并上报Agent-1；不得把在途数量直接当当前可售。

## 示例B｜需求被断货扭曲
最近7日均销显著低于30日，但其中4天缺货。正确：标记需求窗口distorted，不能直接降低补货量。

## 示例C｜积压但存在季节性
当前覆盖120天，但60天后进入旺季。正确：不能只按120天覆盖机械清仓，需结合Agent-8趋势和Agent-6财务约束。

## 验收判定
- 当前库存与未来供给分离；
- lead time可拆分且版本化；
- 需求基线考虑断货/促销/广告等混杂；
- 补货建议是区间与约束，不是执行指令；
- 事件/响应能供Agent-1消费；
- 真实执行不混入当前框架。
