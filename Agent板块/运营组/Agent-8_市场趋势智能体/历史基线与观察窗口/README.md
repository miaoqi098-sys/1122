# 历史基线与观察窗口

## 目的
趋势判断必须基于足够长度的历史窗口，并区分同比、环比、季节性和事件周期。

## 标准基线
- 短期：7/14/30日，用于异常发现；
- 中期：60/90日，用于趋势持续性；
- 长期：半年/一年，用于季节和结构变化；
- 同比：同月、同周、同节日前后；
- 事件基线：活动前/中/后；
- 类目生命周期基线：成熟类目与新兴类目分开。

## 观察窗口原则
趋势越高影响，所需观察和证据越严格。突发事件可以短期形成event-driven事件，但不能直接升级为长期结构趋势。

## 基线失效
- 数据源口径变化；
- 类目定义变化；
- 重大政策/平台规则改变；
- 市场结构明显重构；
- 新品类快速形成导致旧历史缺乏可比性。

## 冲突历史
历史中若存在多个相似事件但结果不同，应保留差异条件，不允许只选择支持当前结论的案例。

## 输出要求
趋势结论必须引用baseline_ref、window、seasonality_context与data_version，便于Agent-1判断当前趋势证据是否足够。
