# 工具与数据需求

## 目标
定义 Agent-8 判断市场趋势所需的数据与未来工具能力；当前只完成框架接口，不接真实外部数据源。

## 核心数据
- 搜索趋势：关键词/主题热度、查询量、增长率；
- 类目趋势：类目流量、销量、排名分布或可替代市场规模信号；
- 价格趋势：主流价格带、折扣密度、价格分布；
- 竞品结构：竞品数量、上新、促销密度，由Agent-3提供；
- 消费者偏好：评价/VOC/内容主题，由Agent-11/9提供相关证据；
- 季节与节日：地区日历、平台活动；
- 外部信号：天气、政策、媒体/社会事件等；
- 店内流量辅助：Agent-5流量趋势用于验证市场变化是否传导到当前产品。

## 标准字段
- source；
- signal_type；
- subject；
- marketplace/region；
- observed_at；
- time_window；
- value；
- baseline；
- freshness；
- confidence；
- evidence_ref。

## 新鲜度
突发事件与搜索热度需要较高频；季节/节日日历可低频维护；历史同比数据允许低频但必须标记完整周期。

## 降级规则
- 只有单一信号源：只能形成candidate趋势；
- 无同比数据的季节性类目：降低趋势置信度；
- 外部事件来源不可靠：不得升级confirmed；
- 类目/搜索口径变化：历史比较需重建基线；
- 数据窗口过短：只能输出短期异常，不给长期结构结论。

## 未来工具能力
- 搜索/类目趋势采集；
- 外部事件和日历读取；
- 多源时间序列聚合；
- 趋势分解、季节性对比；
- 主题/信号聚类；
- Schema验证和历史持久化。

## 运行依赖
复用R03 Schema Validator、R06长期记忆数据库。若后续需要独立的市场趋势/外部数据采集连接器，应在运行依赖待办中新建或扩展对应依赖，不在Agent框架内实现。
