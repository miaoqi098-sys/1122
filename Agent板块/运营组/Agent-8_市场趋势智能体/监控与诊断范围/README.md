# 监控与诊断范围

## 监控对象
- 市场需求上升/下降；
- 关键词与搜索主题扩散/收缩；
- 类目热度迁移；
- 主流价格带变化；
- 新兴产品属性/使用场景；
- 季节性进入/退出；
- 外部事件冲击；
- 市场供需结构变化。

## 标准趋势状态
1. `EMERGING_UPTREND`：新兴上升趋势；
2. `CONFIRMED_UPTREND`：多源确认持续上升；
3. `EMERGING_DOWNTREND`：新兴下降；
4. `CONFIRMED_DOWNTREND`：多源确认持续下降；
5. `SEASONAL_RISE`：季节性上升；
6. `SEASONAL_COOLDOWN`：季节性回落；
7. `STRUCTURAL_SHIFT`：需求/价格带/偏好发生结构性迁移；
8. `EVENT_DRIVEN_SPIKE`：事件驱动短期峰值；
9. `EVENT_DRIVEN_DROP`：事件驱动短期下滑；
10. `NOISY_SIGNAL`：证据不足或冲突，不形成趋势结论。

## 诊断要求
每个趋势判断至少检查：
- 当前变化幅度；
- 持续时间；
- 覆盖广度；
- 同比/环比基线；
- 季节因素；
- 多来源一致性；
- 是否由单一促销/竞品事件造成；
- 是否存在外部驱动；
- 对当前产品/库存/价格/广告计划的潜在影响。

## 输出
必须给出趋势方向、强度、持续性、来源、冲突证据、置信度、预计持续窗口和需要其他Agent确认的事项。

## 边界
趋势判断描述市场环境，不直接输出最终经营动作。
