# 趋势指标与口径

## 核心指标
- `growth_rate`：相对基线增长/下降幅度；
- `acceleration`：增长速度是否继续加速/减速；
- `persistence`：趋势持续窗口；
- `breadth`：趋势覆盖多少关键词/子类目/价格带；
- `seasonality_index`：当前相对季节基线的位置；
- `volatility`：波动程度；
- `signal_consistency`：不同来源方向一致程度；
- `trend_strength`：综合强度；
- `trend_confidence`：综合置信度。

## 口径原则
1. 所有增长率必须绑定基线窗口；
2. 同比、环比、移动平均不得混用而不标注；
3. 季节性产品优先使用同比/同周期基线；
4. 短期峰值需结合持续性和扩散度；
5. 单个关键词爆发不能直接代表整个类目；
6. 类目排名变化不能直接等同真实需求规模变化。

## 趋势强度
框架建议将趋势强度拆为：
`magnitude × persistence × breadth × source_consistency`

不要求固定数学公式，但必须保留各组成项，防止黑箱分数。

## 置信度降级
以下情况必须降低置信度：
- 数据源单一；
- 样本窗口过短；
- 与季节性高度重合但缺同比；
- 外部事件尚未确认持续；
- 搜索热度上涨但销量/类目证据不支持；
- 多来源方向冲突。

## 输出边界
指标用于判断趋势是否存在、强弱与持续性，不直接形成库存、广告、价格或新品动作。
