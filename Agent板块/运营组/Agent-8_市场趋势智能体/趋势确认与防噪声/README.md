# 趋势确认与防噪声

## 目的
避免把短期波动、单一数据源异常或一次性事件误判成可持续市场趋势。

## 候选趋势
任何新变化默认先进入 `candidate`，只有满足确认条件后才能升级为 `confirmed`。

## 确认条件
至少综合以下维度：
- 持续性：不是单日/单周孤立峰值；
- 广度：不只集中于一个词/一个ASIN；
- 多源一致性：搜索、类目、竞品、消费者等信号方向相符；
- 基线偏离：相对合理同比/环比基线有显著变化；
- 季节解释：已排除正常季节性；
- 事件解释：已识别是否由一次性事件驱动；
- 数据质量：来源新鲜且口径稳定。

## 趋势生命周期
`candidate → confirmed → persistent → weakening → ended`

事件型趋势可走：
`candidate → event_driven → cooldown → ended`

## 防抖规则
- 同一趋势短期正负切换时不得频繁反转结论；
- 没有新证据时不重复创建等价趋势事件；
- 单一来源异常先标记 `NOISY_SIGNAL`；
- 多源冲突时保留冲突证据并降低confidence；
- 确认趋势失效必须记录失效原因。

## 最低证据
高影响趋势建议至少2类独立信号支持；若只有一个高质量来源，也只能输出“候选”并说明限制。

## 与Agent-1关系
Agent-8只确认趋势事实和潜在影响，不决定是否扩广告、补库存、降价或推出新品。
