# Agent-1 至 Agent-13 职责覆盖矩阵 V1.0

## 1. 总原则
- Agent-1：唯一最终经营决策出口，负责多目标权衡、硬约束、最终方案选择与任务编排。
- Agent-2 至 Agent-12：专业事实、诊断、约束和候选建议提供者，不拥有 FinalDecision。
- Agent-13：跨域增长机会聚合与验证设计，不替代专业 Agent 主诊断，也不拥有 FinalDecision。

## 2. 主责矩阵

|---|---|---|
| Agent-1 运营总控 | 目标、冲突、优先级、FinalDecision、任务编排、验证学习闭环 | 不替专业Agent持续采集领域事实 |
| Agent-2 商品状态 | Listing/商品前后台状态、可售性、Featured Offer、展示状态、变体/资质状态事实 | 价格机制解释→A10；合规资格判断→A12；内容转化诊断→A9 |

## 3. 高频交叉区域的主从规则
### 广告 vs 流量
- A4 主责“广告系统内部发生了什么、可有哪些广告候选动作”。
- A5 主责“整个流量结构发生了什么、付费与自然流量如何互相解释”。
- 若问题是“Broad 61点击0单是否降价/否词”，A4主责；若问题是“自然排名和广告流量占比整体变化”，A5主责。

### 商品状态 vs 价格促销
- A2 负责“前台/后台当前展示和状态事实”。
- A10 负责“价格历史、参考价机制、促销资格、叠加与活动节奏解释”。
- A2观察到划线价消失，应形成状态事件并请求/触发A10解释，不自行决定价格策略。

### 竞品 vs 市场趋势
- A3 负责具体竞争对象及其动作。
- A8 负责类目、需求、季节、价格带和外部驱动趋势。
- “某竞品降价”归A3；“整个类目价格带下移”归A8，可引用A3样本证据。

### 内容转化 vs 评价体验
- A11 负责消费者说了什么、评分/退货/体验问题怎样聚类。
- A9 负责这些信号如何映射到Listing内容、表达、素材和转化承接。
- A11不得直接替A9下内容修改结论；A9不得替A11伪造VOC证据。

### 价格促销 vs 利润
- A10负责活动/价格机制与可选方案。
- A6负责每个方案的利润、盈亏平衡和财务承受边界。
- 最终是否降价/上Deal由A1结合库存、流量、风险等决策。

### 增长机会 vs 各专业Agent
- A13只对已经存在证据的跨域机会做组合、去重、可行性与验证设计。
- 单域问题先由对应专业Agent诊断；A13不得成为“万能第二总控”。

## 4. 空白区检查
已覆盖的核心经营域：
- 商品状态与可售性：A2
- 竞争环境：A3
- 广告：A4
- 流量：A5
- 利润：A6
- 库存供应链：A7
- 市场趋势：A8
- 内容与转化：A9
- 价格促销：A10
- 消费者评价体验：A11
- 风险合规：A12
- 增长机会：A13
- 多目标最终决策：A1

当前未发现必须新增 Agent 才能覆盖的一级运营问题。订单运营、客服执行、财务会计记账、物流承运执行、广告/价格真实操作等属于数据/工具/执行层，而不是新的经营决策 Agent 空白。

## 5. 冲突升级规则
当两个Agent对同一事实有不同结论：
1. 不以Agent编号决定谁赢；
2. 区分事实冲突、口径冲突、时效冲突、目标冲突；
3. 专业事实优先回到主责Agent及其证据；
4. 跨域目标冲突统一交Agent-1；
5. 风险/资格硬约束由A12提供资格状态，但最终业务对象状态与决策仍由A1按规则处理。

## 6. 新职责准入
未来发现新问题时，先判断是否为：
- 现有Agent的新子域；
- 多Agent协作场景；
- 数据/工具/执行能力；
- 真正长期独立的专业经营领域。

只有最后一种且现有Agent长期无法合理承接时，才考虑新增Agent，避免Agent数量无限膨胀。
