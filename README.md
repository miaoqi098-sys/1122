`.github/` 与根 `README.md` 属于仓库支撑文件，不计入 10+1+1 板块。

## 恢复原则

- 不再把运行、工具、执行、数据接口、调度等基础设施机械地作为根级板块。
- 所有原有二级、三级、四级及更深内容按职责归入上述 12 个正式一级板块。
- 已有真实工程内容尽量原样保留，仅调整其所属路径；不因目录恢复而丢失成果。
- 历史中已经确认的运营二级结构与产品三级结构直接恢复；尚未确认的结构不擅自扩展。
