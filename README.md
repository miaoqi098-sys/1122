# 亚马逊智能体架构

本仓库作为亚马逊运营智能体系统的新主工程仓库。

## 项目定位

以 A1 中枢智能体为唯一决策出口，逐步构建亚马逊运营多智能体架构，包括数据层、事件层、任务执行层、知识层、工具层和各专业智能体。

## 当前原则

- 本仓库作为后续“亚马逊智能体架构”工程的主施工仓库。
- 原 `amazon-agent-command-center` 仓库暂不继续修改，作为旧版本参考。
- 后续所有新增目录、工程规格、Skill、规则、数据结构与执行模块，优先落到本仓库。

## 计划中的核心智能体

- A1：中枢决策与任务调度
- A2：产品本体监控
- A3：竞品情报监控
- A4：广告数据分析
- A5：流量结构分析
- A6：利润与成本核算

## 工程状态

当前仓库已完成初始化，下一步开始建立 A1 工程化骨架。
