连接建设原则

安全优先
凭据不进入网页前端
Token、Secret、Cookie、密钥等不能写入公开 GitHub Pages 或浏览器 JavaScript。
状态由后端连接层提供
网页只展示经过后端整理的状态、数据和可执行动作，不直接携带敏感凭据访问第三方平台。
统一连接状态模型
后续所有连接统一使用：未配置 / 待授权 / 建设中 / 已连接 / 异常 / 停用。
