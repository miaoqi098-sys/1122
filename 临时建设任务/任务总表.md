---

## 3. 执行与续接原则

每次只推进一个最小可验收单元：

```text
分析
→ 动态生成/调整任务
→ 同步本表
→ 执行一个任务
→ L1回顾
→ 必要时做L2/L3/L4/L5回顾
→ 自动推导下一唯一任务
→ 停止，等待下一轮
```

下一任务优先级：阻塞任务 → 当前子模块下一任务 → 子模块回顾 → 当前模块下一任务 → 模块回顾 → 当前Agent下一模块 → Agent回顾 → 下一Agent启动分析 → Agent库总回顾。
