## 一、与旧施工线隔离

以下自动施工保持暂停，不由本队列恢复：
- `Agent库持续自动施工`
- `总工程蓝图自动施工`

本队列不得读取旧任务总表作为当前施工指针。

## 二、正式实现范围

第一批只读真实实现按照 P1 → P8 推进：

```text
P1 基础工程骨架
→ P2 ProductIdentity Store / Resolution
→ P3 Amazon只读Connector
→ P4 MetricSnapshot事实层
→ P5 最小BusinessState + Signal/Event
→ P6 ProductStateAggregator + HomeCommandCenterAggregator
→ P7 只读UI接口
→ P8 机器验收
```

第一批明确不建设：
- Executor；
- Amazon Ads生产写操作；
- 自动审批；
- 全部Agent Runtime；
- 多产品/多站点扩容。

## 三、文件夹施工规则

1. 只有当前功能文件夹可以进入 `🟦 执行中`。
2. 下一功能文件夹在当前文件夹通过验收前不得提前批量创建空目录。
3. 每个功能文件夹至少要有：职责README、真实实现文件、测试或可验证检查、依赖/Secret边界、L1验收记录。
4. 真实代码、配置或CI必须写入 `真实实现工程/`，不能只写施工文档。
5. 任何Secret只允许引用，不允许写入Git、Prompt或普通日志。
6. 第一阶段所有Amazon能力默认只读；任何写能力直接阻塞并等待独立授权阶段。
7. 每个功能完成后记录真实路径、commit、验收结果，再移动指针。

## 四、技术栈V1

仓库此前没有既定代码技术栈。第一批后端实现采用最小可替换基线：
- Python 3.12+
- FastAPI
- Pydantic v2
- pytest

数据库/ORM、部署平台、消息队列不在第一个文件夹预先绑定；进入对应功能文件夹时再基于真实需求确定。
