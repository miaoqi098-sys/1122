### P3 当前施工目标｜REAL-P3-03
Ads API 只读能力必须：
- 固定 semantic read operation allowlist；
- Sponsored Products list/read 可使用官方要求的 HTTP POST，但不得因此开放写语义；
- 固定 NA / EU / FE Amazon Ads API host；
- `ads.campaigns.list` → `/sp/campaigns/list`；
- `ads.ad_groups.list` → `/sp/adGroups/list`；
- `ads.keywords.list` → `/sp/keywords/list`；
- OAuth access token 仅通过 SecretProvider + SecretRef 临时注入；
- client id 作为受控配置；profile id 通过 AdsProfileResolver 解析；
- 401/403 → auth fail closed；429 → rate-limit；timeout → timeout；
- request id / rate-limit / status 写入 source trace；
- pytest 使用 fake HTTP client，不调用生产 Amazon Ads API；
- 机器 CI PASS 后才进入 `04_认证刷新与限流集成`。
