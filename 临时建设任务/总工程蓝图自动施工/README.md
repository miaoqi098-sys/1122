# 总工程蓝图自动施工

> 状态：已启动
> 作用：为“系统总工程蓝图”建立独立无人值守施工队列。
> 重要边界：旧 `Agent库持续自动施工` 保持暂停，本队列不得读取旧 `临时建设任务/任务总表.md` 作为当前施工指针，也不得自动恢复 Agent-1 逐项排查。

## 1. 继承规则

本队列继承父级 `临时建设任务/` 的以下机制：
- 先分析、后施工；
- 任务指纹去重；
- 阻塞池与绕行；
- L1/L2/L3 分层回顾；
- 高影响变更保护；
- 真实 Git 写入证据；
- 施工日志与断点续跑；
- 真实运行/API/数据库/生产执行继续只做需求定义，不擅自实施。

## 2. 针对总工程的适配

旧规则中的 `Agent编号-正式路径-任务主题-序号` 改为：

`总工程-正式路径-任务主题-序号`

任务指纹改为：

`工程域 + 正式路径 + 问题类型 + 目标对象`

正式施工证据不再限定必须写回 `Agent库/`，而是必须真实写回当前总工程任务对应的正式路径，例如：
- `系统总工程蓝图/`
- `UI界面设计板块/`
- 未来确认后的业务系统、任务中心、执行系统、数据系统等正式目录。

## 5. 运行边界

允许无人值守：
- README、规则、Schema、对象关系、状态机、接口、示例、静态验收；
- 新建必要且可逆的小型正式目录；
- 修复明确的字段、引用和边界冲突；
- 建立总工程公共 Contract。

默认阻塞：
- 大规模迁移/批量重命名；
- 删除正式一级模块；
- 推翻 Agent-1 唯一决策出口；
- 真实 Amazon API 接入；
- 数据库/Runner/Scheduler/Executor 实现；
- 生产经营写操作；
- 任何高影响、不可逆架构变更。

## 6. 自动续跑

每次定时唤醒必须：
1. 读取本目录 `任务总表.md`、`阻塞任务池.md`、`施工进度日志.md`；
2. 读取父级 `任务管理规则.md`、`任务模板.md`、`验收门禁规则.md`；
3. 读取当前任务对应正式路径与上下游；
4. 任务指纹去重；
5. 先写队列，再施工；
6. 完成后做 L1 回顾并记录 commit；
7. 保存下一任务指针；
8. 继续执行不依赖阻塞项的任务，直到本次预算结束。
