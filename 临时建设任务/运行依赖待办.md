# 运行依赖待办

## 定位
本文件只记录在完善 Agent库 框架时发现、但当前明确不进入实现的运行层依赖。

这些事项不会自动成为当前建设主任务，也不会阻塞一个模块达到“框架层完成”，除非它们导致接口定义本身无法成立。

## 当前已知运行依赖

### R01｜Skill Runner
来源：Agent-1 技能模块统一接口。
未来作用：加载并按路由执行 S01-S09，并支持S10横向介入。
当前状态：暂不建设。

### R02｜Agent Runner
来源：Agent-1与专业Agent协作。
未来作用：装载Agent定义、上下文、Skill与工具调用。
当前状态：暂不建设。

### R03｜Schema Validator
来源：Event、DecisionItem、FinalDecision、Task、ExecutionResult、ValidationResult等统一对象。
未来作用：运行时做结构验证。
当前状态：暂不建设。

### R04｜Amazon SP-API Connector
来源：商品、订单、库存、价格、报告等数据需求。
未来作用：真实数据接入。
当前状态：暂不建设。

### R05｜Amazon Ads API Connector
来源：广告、Search Term、预算、竞价等数据与执行需求。
未来作用：真实广告数据与动作接入。
当前状态：暂不建设。

### R06｜长期记忆数据库
来源：产品历史、决策历史、任务历史、验证历史、S09经验沉淀。
未来作用：真实持久化、索引和版本管理。
当前状态：暂不建设。

### R07｜调度器
来源：S07任务计划、监控任务、观察窗口和复核节点。
未来作用：定时/事件驱动调度。
当前状态：暂不建设。

### R08｜执行器
来源：广告、价格、库存、Listing等变更任务。
未来作用：真实调用API或人工执行流。
当前状态：暂不建设。

### R09｜ExecutionResultNormalizer
来源：技能模块统一接口。
未来作用：把不同API/人工执行结果统一为ExecutionResult。
当前状态：暂不建设。

### R10｜LearningWriteExecutor
来源：S09 memory_writes计划。
未来作用：将学习结果真正写入记忆层并返回written/failed回执。
当前状态：暂不建设。

### R11｜StrategyChain持久化与更新
来源：S10策略防抖。
未来作用：长期维护strategy_chain、调整次数、反转次数和替代关系。
当前状态：暂不建设。

## 新增规则
后续执行任何任务时，如发现新的真实运行依赖：
1. 编号为 `R12 / R13 / ...`；
2. 写清来源模块、未来作用和当前框架需要的接口；
3. 默认状态为“暂不建设”；
4. 不打断当前 Agent库 施工顺序。

## 核心原则
先把“未来怎么接”设计清楚，不因为“现在还不能真正跑”就把整个建设主线切去做基础设施。
