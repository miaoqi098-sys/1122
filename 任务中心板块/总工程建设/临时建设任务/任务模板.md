## 11. 施工证据

完成任务必须登记：
- 正式修改路径；
- 修改内容摘要；
- Git commit SHA；
- L1结论；
- 任务总表状态；
- `施工进度日志.md` 批次记录。

无正式施工证据不得标记 ✅。

---

## 12. 下一任务推导

优先级：
1. 有新证据且可解除的阻塞任务；
2. 当前子模块下一任务；
3. L2；
4. 当前模块下一任务；
5. L3；
6. 当前 Agent 下一模块；
7. L4；
8. 下一 Agent 启动分析；
9. L5。

如果当前链被阻塞，则从不依赖阻塞项的任务中选最高优先级任务。
