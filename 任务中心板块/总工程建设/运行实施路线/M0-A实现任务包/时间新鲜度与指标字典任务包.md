# 时间、新鲜度与指标字典实现任务包 V1

> 覆盖：R-GP-005、R-GP-006

## 1. 目标
统一全系统“今天是什么时候”“这个数字有多新”“这个指标究竟怎么算”。

## 2. 时间服务最小职责
- marketplace_timezone 注册；
- business_date 计算；
- window_start/window_end 生成；
- collected_at/effective_at 区分；
- 跨日与夏令时处理；
- 所有窗口使用明确时区，不接受裸本地时间。

## 3. Freshness最小职责
每个数据源维护 SLA/期望延迟，并输出：
```text
fresh
lagged
partial
stale
error
unknown
```
Freshness 是数据事实，不由 UI 或 Agent 自由描述。

## 4. Metric Registry最小字段
- metric_code
- canonical_name
- description
- value_type
- unit
- currency_semantics
- aggregation_rule
- calculation_type (raw/calculated)
- calculation_ref/version
- allowed_windows
- source_preferences
- effective_from/to

## 5. 禁止项
- 同一 metric_code 在不同模块存在不同口径；
- 用展示名称作为指标唯一ID；
- 更新公式后覆盖旧版本而不留 calculation_version；
- 数据过期仍显示 fresh；
- 不同时区的数据直接相加形成“今日”。

## 6. 验收条件
- 同一 marketplace 的 business_date 全链一致；
- 每个首页核心指标可查 Metric Registry；
- 计算指标可定位公式版本；
- freshness_status 可由时间/SLA确定性计算；
- 变更指标定义不破坏历史快照解释。

## 7. 静态L1
时间窗口、新鲜度与指标定义的公共职责、字段与禁止项已明确。未实现时间服务或指标注册表。L1：PASS。
