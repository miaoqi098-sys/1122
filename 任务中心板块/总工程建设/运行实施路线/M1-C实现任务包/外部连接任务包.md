# 外部连接实现任务包 V1

> 覆盖：R-GP-023

## 1. 连接范围
第一阶段只需：
- Amazon SP-API 只读；
- Amazon Ads API 只读；
- 后续受控写权限必须独立授权并由Executor调用。

## 2. 凭证边界
敏感Secret与非敏感Connector Profile分离保存。静态配置只保存：seller/account标签、marketplace、Ads profile、能力范围、连接状态、secret_ref，不保存明文secret。

## 3. Connector职责
- auth/token refresh；
- rate limit；
- request id / trace；
- retry/backoff；
- raw source ref；
- capability discovery；
- read/write scope明确分离；
- 错误标准化。

## 4. 数据链边界
Connector只负责“可靠获取平台数据/执行被授权平台调用”，不做BusinessState、利润判断、Agent决策。

## 5. 写权限
未来任何Ads写调用：
- 不向普通采集器开放；
- 仅Executor Adapter持有受控能力；
- 需要单独action allowlist和permission scope；
- 默认未配置即deny。

## 6. 验收条件
- read credential不能用于write；
- token/secret不进入日志；
- 每次数据读取产生source/trace引用；
- 限流和临时错误有界重试；
- 认证失败不会被当成“没有数据”；
- Connector无法绕过Identity/Data标准化链直接写UI事实。

## 7. 静态L1
连接职责、Secret/Profile、读写权限与数据边界已明确。未接真实API。L1：PASS。
