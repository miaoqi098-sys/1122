# 1122连接 Cloudflare

## 定位
1122 是网页版智能体。本目录负责记录和建设 1122 与 Cloudflare 之间的外部连接。

## 当前已知资源
- 域名：`sorilo-uk.com`
- 域名平台：Cloudflare
- 主要用途：域名、DNS、HTTPS、网页入口及后续与 1122 网页服务相关的 Cloudflare 配置。

## 建设边界
- 域名与 DNS 配置；
- HTTPS / SSL；
- 1122 网页入口与域名绑定；
- 后续如使用 Cloudflare Pages、Workers、Tunnel 等，应继续在本目录记录对应配置与接口契约。

敏感凭据、Token、密码不得直接提交到 GitHub 仓库。
