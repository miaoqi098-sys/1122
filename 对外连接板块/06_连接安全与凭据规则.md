# 连接安全与凭据规则

1122 的所有外部连接统一遵守以下原则：

1. GitHub 只保存非敏感的结构、接口契约、配置模板、字段映射、运行说明和状态记录。
2. 密码、信用卡、API Key、Client Secret、Refresh Token、Access Token、Cookie、私钥等敏感信息不得直接提交到仓库。
3. 真实凭据应存放在本地安全文件、环境变量或专用 Secret 管理系统中。
4. 读取类连接与执行类连接必须区分权限；涉及改价、广告、库存、订单、财务等真实写操作时，必须经过权限控制和人工审批规则。
5. 每个连接应记录授权主体、权限范围、失效/续期方式、调用额度、错误重试和审计日志。
