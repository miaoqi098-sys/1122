# 1122 外部连接建设状态

状态按“连接 / 数据 / 部署 / 鉴权 / 写权限”分别记录。连接成功不自动代表数据完整、新鲜、语义已验证，也不代表允许写入。

| 连接项 | 连接或运行状态 | 已验证数据 / 能力 | 部署、鉴权与写边界 |
|---|---|---|---|
| Web Console V2 | `SINGLE_ROUTER` | 一个入口、一个 Navigation Registry、一个 Hash Router | Cloudflare Pages 当前本地手工部署，不是 GitHub 自动发布 |
| Amazon SP-API | 真实连接已验证 | 自有商品等第一方经营数据只读链路 | 当前不开放生产写操作 |
| Amazon Ads API | `CONNECTED`，NA | Profiles = 4；当前真实 US Profile = 1 Campaign / 2 Ad Groups | 仅 Profiles、Campaigns、Ad Groups 只读；预算、竞价、状态、关键词等写操作关闭 |
| Amazon Ads OAuth | 可用 | 标准回调之外，支持紫鸟手工三步授权 | 授权码与 Token 不进入聊天、日志、GitHub 或浏览器持久存储 |
| Sif MCP | 真实连接与真实 ASIN 查询已验证 | 外部市场数据只读 | 不等于所有经营字段已落 D1 |
| Email | `AUTH_REQUIRED` | 尚未完成真实认证 | 认证完成前不记为健康连接 |
| Cloudflare D1 | `AVAILABLE` | 事实读模型可用 | D1 读取成功不替代 freshness 与业务语义验证 |
| Cloudflare KV | `AVAILABLE` | 当前状态 / 缓存层可用 | 可覆盖，不作为长期历史真值 |
| Cloudflare R2 | `NOT_ENABLED` | 无可用冷档案层 | 不得把规划或凭据名称误报为服务可用 |
| 1122连接卖家精灵 | 已建立工程入口 | 尚未记录真实连接验收 | 待核实授权方式、数据通道与字段 |
| GPT连接Codex | 已有历史工程 | 作为开发执行通道单独管理 | 不等于获得 Amazon 或其他生产写权限 |

## 访问控制状态

- 当前 CORS allow-list 只限制浏览器跨域访问，不是身份认证。
- Cloudflare Access 或等价会话鉴权尚未配置，因为允许访问的用户身份仍待用户确认。
- 在身份范围确认前，不擅自锁定站点；在会话鉴权完成前，也不把网页描述为已完成内部访问保护。
- 会话鉴权完成也不会自动开放写权限。真实 Amazon / Ads 写操作仍须另行完成 Task、审批、权限边界、Executor 与结果验证链路。

“已建立工程入口”只表示仓库结构已经建立；`CONNECTED`、`AVAILABLE`、`AUTH_REQUIRED`、`NOT_ENABLED` 和 `CLOSED` 必须依据各自维度单独判定。
