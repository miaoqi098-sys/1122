# 1122 对外连接总览

## 1. 板块定位

`1122` 是网页版智能体。本板块统一管理 1122 与外部平台、数据源、域名基础设施及开发执行通道之间的连接。

对外连接回答的是：**1122 接了什么外部系统、通过什么方式接、能拿到什么、能做什么、权限边界在哪里。**

## 2. 当前正式连接入口

1. `01_1122连接Cloudflare/`
   - 域名：`sorilo-uk.com`
   - 域名平台：Cloudflare
   - 承载域名、DNS、HTTPS、网页入口及后续 Pages / Workers / Tunnel 等能力。

2. `02_1122连接亚马逊API/`
   - Amazon SP-API
   - Amazon Ads API
   - Seller Central 相关授权与数据接口

3. `03_1122连接Sif/`
   - Sif 可授权的关键词、市场、竞品等外部数据能力

4. `04_1122连接卖家精灵/`
   - 卖家精灵可授权的关键词、市场、竞品、流量等外部数据能力

## 4. 统一安全规则

- 密码、信用卡、Client Secret、Refresh Token、Access Token、Cookie、API Key 等不得直接提交到 GitHub。
- GitHub 只保存结构、接口契约、字段映射、配置模板、运行说明和非敏感状态。
- 真实凭据应放入受控的本地安全文件、环境变量或专用 Secret 管理机制。
- 任何具备写入、下单、改价、改广告、改库存等真实执行能力的外部连接，必须再经过权限和审批边界控制。
