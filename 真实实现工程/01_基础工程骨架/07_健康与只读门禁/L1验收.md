## 已实现

- `/live` 只表示进程可响应，不冒充依赖健康；
- `/ready` 基于 HealthProvider 的真实 readiness；
- `/health` 返回 Runtime + dependency 健康快照；
- 未安装 HealthProvider 时 `/ready` 与 `/health` 均返回 503，不再无条件假绿；
- `RuntimeHealthProvider` 通过显式 `DependencyProbe` 汇总依赖状态；
- probe 异常 fail closed 为 `unavailable`，仅记录异常类型，不泄露异常消息；
- degraded / unknown / unavailable 均使 readiness=false；
- `ServiceHealth.write_capability` 使用 `Literal[False]`，构造阶段即禁止 true；
- `RuntimeContainer` 注入同一个 RuntimeHealthProvider，并传入 FastAPI Application；
- legacy health/version 测试已升级为新的运行时语义；
- 07 单元/集成测试已纳入 P1 统一机器 CI。
