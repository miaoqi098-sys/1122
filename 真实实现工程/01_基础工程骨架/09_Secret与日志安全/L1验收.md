- RuntimeContainer 不再暴露底层 `SecretProvider`；
- `SecretUseBroker.use()` 只在一次 callback 内提供明文，不缓存 Secret；

- 日志 message 对 Bearer、password/token/secret/access_key/refresh_token/client_secret 等常见凭据形式过滤；
- safe_context 对敏感 key 递归脱敏；
- `SecretStr` 即使处于非敏感 key 下也强制脱敏；
- nested list/tuple/mapping 均经过安全值递归处理；
- 所有测试只使用 dummy Secret；
