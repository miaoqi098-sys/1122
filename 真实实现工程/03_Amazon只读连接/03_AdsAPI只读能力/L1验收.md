## 已实现

- Amazon Ads API NA / EU / FE 固定官方 endpoint allowlist；
- `AdsProfile / AdsProfileResolver / StaticAdsProfileResolver`；
- seller + marketplace → profile + region 的受控解析；
- `ads.campaigns.list` → Sponsored Products `POST /sp/campaigns/list`；
- `ads.ad_groups.list` → Sponsored Products `POST /sp/adGroups/list`；
- `ads.keywords.list` → Sponsored Products `POST /sp/keywords/list`；
- 明确采用“semantic read allowlist”：上述 HTTP POST 仅作为官方 list/read 查询传输方式，不开放创建、修改、归档或删除语义；
- OAuth access token 每次请求通过 `SecretProvider + SecretRef` 临时 resolve；
- client id 作为受控运行配置注入；
- profile id 由 resolver 注入 `Amazon-Advertising-API-Scope`；
- 解析 Ads request id、rate-limit 与 HTTP status 并进入共享 `SourceTrace`；
- 401 / 403 → `ConnectorAuthError`；
- 429 → `ConnectorRateLimitError`；
- timeout → `ConnectorTimeoutError`；
- 其他非 2xx → sanitized `AdsApiHttpError`，异常不携带响应 body / Secret；
- P3-01 + P3-02 + P3-03 联合回归测试纳入同一 GitHub Actions 门禁。
