## 只读边界复核

- `ReadOperation` 当前全部成员均属于 `READ_ALLOWLIST`；
- allowlist 不包含 create / update / delete / archive / bid / budget 等经营写语义；
- SP-API Transport 仍为 GET-only；
- Ads API 的 POST 仅用于显式 semantic-read list operations；
- 未实现 Amazon / Ads 经营写能力；
- 未实现自动审批、Executor 或生产动作执行器。

## Secret边界复核

- `ConnectorRequest`、`TransportRequest`、`SourceTrace` 不承载 Secret value；
- refresh token / client secret 通过 `SecretRef + SecretProvider` 临时 resolve；
- access token 使用 `SecretStr` / dynamic provider 生命周期；
- 无真实 Secret 写入 Git、普通日志、SourceTrace 或任务文件；
- OAuth/HTTP error 使用 sanitized message，不附带响应 body 或 credential。

## 限流与重试边界复核

- `RetryPolicy.max_attempts` 最大 5；
- Retry-After 有 max-delay 上限；
- timeout / 429 指数退避有界；
- 最终失败后不额外等待；
- 无无限重试。
