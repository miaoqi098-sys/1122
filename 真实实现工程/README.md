# 真实实现工程

> 分支：`implementation/real-v1`
> 定位：承载从静态总工程蓝图进入真实代码、服务、存储、Connector、读模型与机器验收后的正式实现。

## 第一批实现顺序

```text
01_基础工程骨架
02_ProductIdentity身份服务
03_Amazon只读连接
04_MetricSnapshot事实层
05_最小状态与事件链
06_读模型聚合服务
07_只读UI接口
08_机器验收
```

注意：当前只创建并施工 `01_基础工程骨架`。后续功能目录在前一阶段达到门禁后再创建，禁止一次性铺设空目录。

## 全局边界
- 第一批系统只读；
- 不实现Amazon经营写操作；
- 不实现自动审批/Executor；
- Secret只通过安全引用进入运行环境；
- 静态蓝图中的Canonical Schema仍是上位Contract；
- 真实实现发现Contract冲突时必须记录并回到架构层处理，不能暗改语义。
