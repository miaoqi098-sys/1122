# 用户运营经验

当前状态：**空**。

本目录只接收用户明确、主动录入的运营经验。

固定规则：

- 不从历史聊天自动推断“这是用户本人经验”。
- 不把同一账号下其他操作者的内容归因给当前用户。
- 不把助手建议、系统推导、公开资料自动写成“用户经验”。
- 只有用户明确说“这条录入我的运营经验/知识库”或等价指令时，才建立用户经验 KnowledgeItem。
- 用户明确录入时，保留原始表述、适用条件、案例数据和来源时间；需要归纳时，归纳内容与原始表述分开保存。
- 用户经验不能替代 Amazon 官方政策证据。
- 删除/撤回用户经验时，仓库索引与 D1 运行库必须同步清除。

当前无已录入的用户运营经验知识项。
