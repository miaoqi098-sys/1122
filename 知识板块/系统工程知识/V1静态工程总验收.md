## 2. 当前Canonical原则
- `product_id` 是跨模块产品稳定主键。
- Event复用Agent-1既有Canonical体系，不另造第二套核心Event。
- Agent-1保持唯一最终经营决策出口。
- Agent ≠ Skill ≠ Tool ≠ Connector。
- Task ≠ Approval ≠ Action ≠ ExecutionResult ≠ ValidationResult。
- UI读模型不承担业务事实写入。
- 执行成功不等于经营效果成功。
- 高风险/权限不明默认fail closed。
- 静态完成不得冒充真实运行完成。
