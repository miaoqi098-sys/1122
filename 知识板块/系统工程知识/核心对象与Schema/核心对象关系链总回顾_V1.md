# 核心对象关系链总回顾 V1

## 1. Canonical 主链
```text
SellerAccount / Marketplace
        ↓
ProductIdentity
        ↓
MetricSnapshot
        ↓
BusinessState / ProductStage
        ↓
Event
        ↓
DecisionItem → Option → FinalDecision
        ↓
Goal
        ↓
TaskPlan → Task
        ↓
Approval / HumanActionRequest（适用时）
        ↓
Action
        ↓
ExecutionResult
        ↓
ValidationResult
        ↓
LearningRecord
        ↓
Memory / StageSummary
        ↓
ProductStatusCardView / HomeCommandCenterView
```

## 2. 主键原则
- 产品跨模块主键：`product_id`。
- Event 主引用：`event_id`。
- 决策链：`decision_item_id / option_id / decision_id`。
- 任务链：`task_plan_id / task_id`。
- 执行链：`action_id / execution_result_id / validation_id`。
- 历史链：`learning_id / memory_id / stage_summary_id`。

外部 ASIN/SKU/Campaign 等只能作为外部标识或目标对象引用，不替代内部稳定 ID。

## 3. 生命周期禁止联动误判
以下状态不能自动等价：
- Task completed ≠ Goal achieved
- ExecutionResult success ≠ Validation passed
- ExecutionResult success ≠ Event resolved
- Event resolved ≠ Goal achieved
- Action executed ≠ Task completed

每个对象维护自己的生命周期，只通过显式引用和规则推进。

## 4. Agent 边界
- 专业 Agent 生产领域分析、Domain Event/Response。
- Canonical Event 进入 Agent-1。
- Agent-1 仍是跨域最终经营决策出口。
- 系统级 Contract 不重写 Agent-1 的目标选择、事件处理、决策或任务编排逻辑，只提供跨系统可引用对象。

## 5. UI 读模型
UI 不直接拼接多个 Agent 自然语言结果。

推荐读取：
- `ProductStateAggregator → ProductStatusCardView`
- `HomeCommandCenterAggregator → HomeCommandCenterView`
- `TaskCenter → HumanTasks`
- `AgentActivity → Agent今日动态`

## 6. 审计链
任一重要真实操作应尽量可回溯：
```text
product_id
→ event_id
→ decision_id
→ task_id
→ approval_id（适用时）
→ action_id
→ execution_result_id
→ validation_id
→ memory_id
```
