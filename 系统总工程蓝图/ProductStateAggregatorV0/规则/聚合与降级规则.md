# ProductStateAggregator 聚合与降级规则 V0

## 1. 关联键
所有产品级输入首先以 `product_id` 对齐；ASIN/SKU 只用于展示和外部辅助定位。

## 2. 当前对象选择
- MetricSnapshot：选择业务日期/窗口匹配且最新可用快照；保留 freshness。
- BusinessState：选择当前有效状态记录。
- ProductStage：选择当前 active 阶段；必须保留阶段定义版本。
- Goal：选择当前 active primary Goal；没有主目标时不得临时由聚合器生成。
- Task：查询 TaskCenter 中该 product_id 未结束任务。
- Action：按业务日和 executed_at 查询真实今日动作。
- StageSummary：选择最近完成且与当前/最近阶段匹配的摘要。
- Event：选择重要且未关闭或仍需展示的事件投影。

## 3. 缺失与降级
聚合器不得用模型猜缺失字段。
- 非关键组件缺失：`view_status=degraded`，写入 missing_components。
- 无法识别 product_id 或产品不存在：`unavailable`。
- 事实数据延迟：保留原值并标记 lagged/stale/partial，不伪装 fresh。

## 4. 今日操作 vs 当前任务
- today_action_refs：真实 Action，按 executed_at 落入当前业务日。
- open_task_refs：未结束 Task。
两者不得互相替代。

## 5. 只读原则
Aggregator 只读源对象并生成 View，不修改 Goal/Event/Task/Action/Memory 的事实状态。

## 6. 缓存与一致性
未来运行时允许缓存，但 View 必须携带 generated_at/source_updated_at；关键写操作完成后应触发失效或重新聚合。当前不实现缓存。

## 7. UI
首页可读取该 View 的精简字段；产品详情页读取完整 View 并通过 refs 深入原业务对象。
