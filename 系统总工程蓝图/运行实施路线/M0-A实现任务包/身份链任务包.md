# 身份链实现任务包 V1

> 覆盖：R-GP-001、R-GP-002、R-GP-003

## 1. 目标
未来工程实现后，任一外部 Amazon 产品记录都能够：
1. 映射到唯一 `product_id`；
2. 无唯一结果时明确返回 unresolved/conflict，而不是猜测；
3. 保留 ASIN/SKU/FNSKU/parent/variation 的历史映射；
4. 为所有下游事实对象提供稳定身份。

## 2. 子任务

### ID-01｜ProductIdentity Store
输入：`ProductIdentity.schema.json`
能力：create/get/update-status/list-history。
约束：`product_id` 创建后不可变；不得因标题、ASIN或SKU变化重新生成同一经营实体身份。

### ID-02｜唯一性约束
至少保证：
- `product_id` 全局唯一；
- active identity 在 seller_account + marketplace + seller SKU 语境内不可产生冲突；
- 冲突必须进入 resolution 流程。

### ID-03｜IdentityResolution
输入：seller_account_id、marketplace_id、asin/sku/fnsku等外部标识。
输出：
```text
resolved(product_id)
unresolved
ambiguous(candidate_product_ids)
conflict(conflict_reason)
```
禁止模型自由猜 product_id。

### ID-04｜ExternalIdentifier Mapping
保存外部标识到内部 product_id 的版本化映射，至少含：
- source；
- effective_from/to；
- collected_at；
- confidence/source_quality；
- active/history 状态。

### ID-05｜身份迁移与合并保护
未来如需 merge/split product identity，必须是高影响受审计操作；不能由采集器自动静默重绑历史事实。

## 3. 接口契约建议

```text
resolveIdentity(context) -> IdentityResolutionResult
getProductIdentity(product_id) -> ProductIdentity
upsertExternalMapping(mapping) -> MappingResult
listIdentityHistory(product_id) -> IdentityHistory[]
```

## 4. 失败路径

- 缺 seller/marketplace：invalid_context
- 多个 active SKU 映射不同 product_id：identity_conflict
- 只有 ASIN 但存在多 seller SKU：ambiguous
- 外部记录缺少任何可用标识：unresolved
- 历史映射与当前映射冲突：requires_review

## 5. 验收条件

未来实现要至少通过：
- 同一产品重复导入保持相同 product_id；
- SKU变更不破坏旧历史；
- 多候选时 fail closed；
- 所有 MetricSnapshot 能通过 product_id 回查 ProductIdentity；
- 映射来源与时间可追溯；
- 不允许仅靠 ASIN 作为数据库外键贯穿全系统。

## 6. 静态L1
任务边界、接口、失败路径和验收条件已定义；未实施持久化或外部采集。L1：PASS。
