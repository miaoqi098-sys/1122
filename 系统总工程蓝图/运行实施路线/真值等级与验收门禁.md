# 真值等级与验收门禁 V1

> 对应任务：RI-04
> 目的：防止“文档完成、示例通过、接口可调用”被误报为真实经营系统已运行。

## 1. 真值等级

### L0 STATIC_CONTRACT_VERIFIED
证明：Schema、规则、示例和静态验收一致。
不能证明：有真实数据、服务或运行环境。

### L1 SERVICE_IMPLEMENTED
证明：对应服务/Repository/接口已有真实实现并通过本地/CI测试。
不能证明：已连接真实授权数据。

### L2 READ_MODEL_VERIFIED
证明：真实持久化对象可以通过 Aggregator 形成稳定读模型。
要求：机器可验证存储/接口证据、非手工拼JSON。

### L3 LIVE_DATA_VERIFIED
证明：真实授权外部数据进入对象链，来源、时间、身份映射可追溯。
要求：认证读取成功证据、source refs、freshness/quality。

### L4 AGENT_RUNTIME_VERIFIED
证明：专业Agent/Agent-1通过真实Runtime消费结构化输入并产生结构化输出。
要求：run_id、输入引用、输出对象、错误/重试记录。

### L5 HUMAN_APPROVAL_VERIFIED
证明：真实人工身份完成审批动作，审批记录与Task绑定且可审计。

### L6 EXECUTION_VERIFIED
证明：一个受授权、受控的真实经营动作通过Executor执行，并有Action + ExecutionResult。
不能证明：经营效果已成功。

### L7 VALIDATION_VERIFIED
证明：执行后在规定观察窗口内完成独立效果验证，生成ValidationResult。

### L8 BUSINESS_LOOP_VERIFIED
证明：至少一个授权产品完成真实：
`Data → Event → Agent/Decision → Task → Approval → Action → ExecutionResult → Validation → Memory → UI`。

## 2. 禁止跨级

- Git commit ≠ SERVICE_IMPLEMENTED。
- 单元测试通过 ≠ READ_MODEL_VERIFIED。
- 模拟数据 ≠ LIVE_DATA_VERIFIED。
- 模型输出文本 ≠ AGENT_RUNTIME_VERIFIED。
- 用户口头同意 ≠ HUMAN_APPROVAL_VERIFIED。
- API成功响应 ≠ VALIDATION_VERIFIED。
- 静态MVP示例 ≠ BUSINESS_LOOP_VERIFIED。

## 3. 证据最小集

每次晋级必须保存：
- maturity_level；
- verified_at；
- environment；
- exact version/commit；
- machine_evidence_refs；
- scope（seller/marketplace/product/action）；
- verifier；
- known_limitations。

## 4. UI展示规则

UI不得把“静态已设计”显示成“系统已连接”。
建议状态映射：
- L0：已设计
- L1：已实现/未接数据
- L2：读模型可用
- L3：真实数据已验证
- L4：Agent运行已验证
- L5：人工审批已验证
- L6：受控执行已验证
- L7：效果验证已完成
- L8：完整经营闭环已验证

## 5. 失效与降级

真值等级不是永久奖章。以下情况必须降级或标记 stale：
- 凭证失效；
- API权限被撤销；
- 数据长期过期；
- 部署版本与验收版本不一致；
- Schema破坏性升级但未重新验证；
- Executor策略或权限矩阵改变；
- 关键依赖不可用。

历史验证记录保留，但 current_maturity 必须反映当前事实。

## 6. BUSINESS_LOOP_VERIFIED最低证据

至少包括：
- 唯一 product_id；
- 真实数据 source refs；
- Event ID；
- FinalDecision引用；
- Task ID；
- Approval ID（若需要）；
- Action ID；
- ExecutionResult ID；
- ValidationResult ID；
- Memory/Activity引用；
- ProductStatusCard/HomeCommandCenter读取证据；
- exact deployed version。

## 7. L1结论

真值等级已从概念列表升级为分级门禁、证据要求、UI语义和降级规则。未声明任何当前运行等级高于真实证据。L1：PASS。
