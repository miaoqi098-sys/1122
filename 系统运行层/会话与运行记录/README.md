# 会话与运行记录

负责记录每一次 Agent 实际运行过程，使系统可以追踪、排错、复盘和比较历史决策。

## 规划模块
- 会话管理：管理一次连续分析过程的会话标识与状态。
- 运行记录：记录 Agent、任务、模型、上下文、工具调用和最终结果。
- 中间状态：保存等待工具、等待审批、待继续分析等中间状态。

## 每次运行至少记录
- 运行编号
- Agent编号
- 启动时间与结束时间
- 触发任务或事件
- 使用的模型
- 装载的上下文来源
- 工具调用记录
- 结构化结果
- 运行状态
- 错误信息
- 资源消耗（后续接入）

## 原则
运行记录与业务长期记忆不同：运行记录回答“程序这一次怎么跑的”，长期记忆回答“产品过去发生过什么、学到了什么”。
