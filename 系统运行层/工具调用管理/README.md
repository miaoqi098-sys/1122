# 工具调用管理

负责运行中的 Agent 如何发现、申请和调用工具层能力，是 Agent 与共享工具层之间的桥梁。

## 规划模块
- 工具注册器：让系统知道当前有哪些工具、输入输出和用途。
- 工具权限检查：检查当前 Agent 是否允许调用该工具。
- 工具调用路由：把 Agent 的工具请求发送到正确工具并接收结果。
- 工具结果标准化：把不同工具返回的数据整理成统一可供 Agent 使用的格式。

## 原则
- Agent 不直接操作底层接口。
- 工具能力统一从工具层注册进入运行系统。
- 高风险工具调用必须经过权限和审批检查。
- 工具返回结果应重新进入上下文，再由 Agent 判断下一步。
