# 系统运行层测试

本目录用于验证系统运行层是否真的能把一个静态 Agent 变成一次可执行运行。

## V0.1最小验收场景
1. 手动输入一个标准智能事件包。
2. 指定运行 Agent-1。
3. Agent装载器能够找到并读取 Agent-1 必要定义。
4. 上下文管理能够生成本次标准上下文包。
5. 提示词组装器能够形成模型输入。
6. 大模型运行时能够完成一次模型调用。
7. 返回结果能够被解析为结构化结果。
8. 会话与运行记录能够保存本次运行信息。
9. 任一关键步骤失败时，异常保护能够明确返回失败原因。

## 暂不纳入V0.1验收
- Agent-1自动调用Agent-2至Agent-13
- 真实Amazon API写操作
- 自动广告调价
- 多Agent并发运行
- 复杂长期记忆检索
- 无人审批的高风险执行
