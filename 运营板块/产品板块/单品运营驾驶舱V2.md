# 单品运营驾驶舱 V2

## 定位

产品页面不是普通商品详情页，而是每个 ProductIdentity（产品身份）的经营中枢。

打开任意产品后，页面必须在第一屏回答：

1. 这个产品现在处于什么经营阶段？
2. 当前阶段目标是什么？
3. 实际经营结果离目标还有多远？
4. 流量、转化、广告、库存、利润分别发生了什么？
5. 当前运营计划执行到哪里？
6. A1 认为现在最重要的动作是什么？

## Stage（经营阶段）建议枚举

第一版：

- `PRE_LAUNCH`：上线准备期
- `LAUNCH`：新品启动期
- `GROWTH`：成长期
- `SCALE`：放量期
- `STABLE`：稳定经营期
- `DEFENSE`：防守期
- `RECOVERY`：恢复期
- `CLEARANCE`：清库存期
- `PAUSED`：暂停经营

阶段不是根据销量自动拍脑袋判断。可以由人工设置，也可以由 Agent 提议，但阶段变更必须保存原因和时间。

## 阶段目标原则

目标必须可验证，避免“提高销量”“优化广告”这种不可验收描述。

例如：

```text
primary_goal: 核心词扩量并保持利润
metrics:
- daily_units: 20 → 35
- unit_session_percentage: >= 18%
- tacos: <= 12%
- core_keyword_rank: Top 10
- inventory_coverage_days: 45–60
```

## 数据状态规则

产品页面任何指标只能使用：

- `REAL`
- `PENDING_SOURCE`
- `PENDING_MODEL`
- `PENDING_PLAN`
- `STALE`
- `DEGRADED`
- `UNKNOWN`

禁止使用模拟销售额、模拟库存、模拟利润填充页面。

## 当前 Web 安全边界

Cloudflare Pages 当前尚未完成用户身份认证，因此第一版页面：

- 可以展示产品组合数量、数据链状态和驾驶舱结构；
- 可以为每个 ProductIdentity 创建受保护的产品槽位；
- 不在未认证接口中直接返回真实 SKU / ASIN / 价格 / 库存 / 销售金额；
- 完成 Cloudflare Access / Authentication 后，将产品槽位替换为真实商品身份和完整经营指标。
