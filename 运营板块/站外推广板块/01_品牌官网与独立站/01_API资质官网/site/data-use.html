Data Use

数据使用说明

本页面说明公司在获得授权后如何使用亚马逊及其他平台接口提供的经营数据。

1. 数据来源

数据仅来自公司拥有或被明确授权访问的业务账户，以及平台提供的正式接口。公司不通过未经授权的抓取方式获取其他卖家的私有账户数据。

2. 主要数据类别

根据实际获批权限，可能包括商品信息、库存信息、价格信息、广告活动、广告组、关键词、搜索词、曝光、点击、广告花费、广告归因销售和其他经营指标。

3. 使用目的

  • 公司内部商品和库存经营监控；
  • 广告表现汇总和趋势分析；
  • 经营异常与机会识别；
  • 内部报表、运营复盘和决策支持；
  • 在权限允许的情况下优化内部运营流程。

4. 权限原则

公司按照最小权限原则申请接口权限。当前不因读取数据的需要而默认获得账户写入、自动审批或资金相关操作权限。

5. 凭证保护

客户端密钥、刷新令牌、访问令牌和账户密码仅应保存在受控的密钥存储或运行环境中，不进入公开代码仓库、网站页面、普通日志、公开文档或分析报表。

6. 外部处理

平台原始数据不会在未经评估和授权的情况下直接发送给无关第三方。若未来使用外部技术服务处理数据，公司将依据实际数据类型、必要性、平台政策和适用法律更新数据流及本说明。
