数据与平台接口使用原则

我们仅在获得相应账户授权和平台许可的前提下访问业务数据。平台接口数据仅用于本公司内部经营管理、分析和决策支持，不向其他卖家提供账户代管或数据服务。

重要：公司不会在公开网站、代码仓库或普通日志中披露平台访问密钥、刷新令牌、访问令牌或账户密码。
