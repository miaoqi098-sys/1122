# API资质官网部署说明

## 当前正式目标

- 正式域名：`https://sorilo-uk.com`
- 域名与 DNS 平台：Cloudflare
- 托管方式：Cloudflare Pages
- GitHub 仓库：`miaoqi098-sys/1122`
- 生产分支：`website/api-qualification-v1`
- 网站根目录：`运营板块/站外推广板块/01_品牌官网与独立站/01_API资质官网/site`

## Cloudflare Pages 对接配置

在 Cloudflare Dashboard 中进入 **Workers & Pages → Create application → Pages → Connect to Git**，授权 GitHub 后选择：

- Repository：`miaoqi098-sys/1122`
- Production branch：`website/api-qualification-v1`
- Framework preset：`None`
- Build command：留空
- Build output directory：`.`
- Root directory：`运营板块/站外推广板块/01_品牌官网与独立站/01_API资质官网/site`

该站点为纯静态 HTML/CSS/JS，不需要 Node、npm 或构建脚本。

## 自定义域名

Cloudflare Pages 项目首次部署成功后：

1. 先打开 Cloudflare 自动生成的 `*.pages.dev` 地址，确认首页、About、Privacy、Data Use、Contact 均可访问；
2. 进入 Pages 项目 → Custom domains；
3. 添加 `sorilo-uk.com`；
4. 可选添加 `www.sorilo-uk.com`，最终建议统一跳转到根域名；
5. 确认 Cloudflare 自动完成 DNS 记录与 HTTPS 证书签发。

## DNS / HTTPS 验收目标

正式上线后应满足：

- `sorilo-uk.com` 可解析；
- `https://sorilo-uk.com` 正常返回首页；
- HTTP 自动跳转 HTTPS；
- SSL/TLS 证书有效；
- `www.sorilo-uk.com` 如启用，应统一跳转到主域名；
- 不使用临时 IP 作为长期入口。

## 已加入的站点安全配置

`site/_headers` 已配置基础安全响应头：

- HSTS；
- 禁止 MIME 嗅探；
- 禁止第三方 iframe 嵌入；
- Referrer Policy；
- Permissions Policy；
- Content Security Policy。

同时已有：

- `robots.txt`
- `sitemap.xml`

两者均以 `https://sorilo-uk.com` 为正式域名。

## 正式审核前门禁

- 网站必须可通过 HTTPS 公开访问；
- 公司法定名称与 Amazon Ads API / SP-API 申请主体一致；
- 首页、公司介绍、隐私政策、数据使用说明、联系方式均可直接访问；
- 公开联系邮箱应为公司长期可用邮箱；
- 不出现 `[公司法定名称]`、`[COMPANY LEGAL NAME]`、`[公开联系邮箱]`、`[公司注册地址或城市]` 等占位符；
- 不公开 Client Secret、Refresh Token、Access Token、密码等敏感凭据；
- 页面描述必须与实际数据使用方式一致。

## 当前上线阻塞

当前页面仍存在公司主体信息占位符。因此可以先完成 Cloudflare Pages 技术部署和域名对接，但在提交 Amazon API 审核前必须完成：

1. 公司法定中文全称；
2. 正式英文名称（如使用）；
3. 公开联系邮箱；
4. 对外展示的公司地址或地区；
5. 页脚公司主体信息。
