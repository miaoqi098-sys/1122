# 品牌官网与独立站

## 归属

`运营板块 → 站外推广板块 → 品牌官网与独立站`

## 当前建设优先级

当前第一优先级不是做完整商城，而是先完成 **API 资质官网**，用于支撑 Amazon Ads API / SP-API 开发者资质审核，并作为未来品牌官网与独立站的基础。

## 当前子模块

### 01_API资质官网

目标：建立一个可公开访问、HTTPS、安全合规、主体信息一致、长期可运营的企业官网。

当前已包含：
- 首页
- 公司介绍
- 隐私政策
- 数据使用说明
- 联系方式
- robots.txt / sitemap.xml
- 基础安全响应头
- Cloudflare Pages 部署说明

正式域名目标：`https://sorilo-uk.com`

## 后续扩展原则

API 资质官网通过审核后，再逐步在同一官网体系增加：
- 品牌与产品内容；
- SEO 与内容中心；
- 广告落地页；
- 邮件订阅；
- 独立站交易能力；
- 站点流量与转化分析；
- 与 1122 站外推广、产品、任务、Agent 的数据联动。

## UI 管理原则

1122 网页中的“官网独立站管理中心”负责：
- 查看官网建设状态；
- 查看域名 / HTTPS / 部署状态；
- 跟踪 Amazon API 资质官网准备度；
- 管理页面清单与审核门禁；
- 进入官网预览、部署、内容维护等操作。

对外公司官网与 1122 内部管理系统必须分离：官网公开，1122 管理页仅作为内部运营入口。
