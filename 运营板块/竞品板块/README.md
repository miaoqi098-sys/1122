# 竞品板块

运营二级中心，负责竞品池、价格、Listing、关键词、流量、广告、评价与市场变化信号。

## 当前三级结构
- 竞品池
- 价格与 Listing 变化
- 关键词与流量
- 竞品广告
- 评价与市场信号

## 主要数据源
- Sif MCP
- 公开市场数据
- 后续竞品历史快照

## 主要 Agent
Agent-3 竞品情报智能体；跨域最终经营决策由 Agent-1 输出。

## 当前状态
Sif MCP 已完成真实 ASIN 数据读取验证，可以开始建设 `CompetitorIdentity / CompetitorSnapshot / CompetitorEvent` 标准链路。

## 页面入口
`运营驾驶舱 → 竞品中心 → 对应三级页面`
